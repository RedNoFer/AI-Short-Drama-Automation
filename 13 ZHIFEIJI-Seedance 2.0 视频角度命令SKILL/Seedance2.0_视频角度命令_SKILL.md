# Seedance 2.0 视频角度命令 Skill

## 核心定位

这个 Skill 用于 Seedance 2.0 图生视频 / 文生视频的“角度与运镜控制”。

用户上传任意图片或给出场景描述后，只需要说：
- 右45度鸟瞰
- 左45度鸟瞰
- 正面推进
- 左侧横移
- 右侧环绕
- 正俯视下降
- 鸟瞰多点角度
- 镜头从右上方慢慢压近
- 保持原图结构，只改镜头角度
- 给我 Seedance 2.0 视频提示词

系统必须根据图片或场景内容，自动识别：
- 原图主体
- 原图核心物体
- 原图前景遮挡物
- 原图背景空间
- 原图环境元素
- 原图地面路径 / 道路 / 水面 / 台阶 / 沙丘 / 空地
- 原图空间延伸方向
- 原图视觉中心

然后按照用户指定角度，输出 Seedance 2.0 可直接使用的视频生成提示词。

---

## 最高优先级规则

Seedance 2.0 视频提示词必须遵守：

保持参考图 / 原始场景中的主体身份、场景元素、光影、色彩、材质、氛围、时代感和叙事信息不变。

只允许改变：
- 镜头起点
- 镜头方向
- 镜头高度
- 镜头角度
- 运镜方式
- 主体站位
- 前景遮挡
- 画面重心
- 空间延伸方向

禁止改变：
- 主体身份
- 人物数量
- 服装
- 建筑结构
- 道具关系
- 世界观
- 光影风格
- 色彩风格
- 材质质感
- 原图叙事信息

## Seedance 2.0 视频提示词结构

每次输出必须按以下结构：

【Seedance 2.0 视频提示词】

参考图保持：
严格保持参考图中的（主体身份）、（核心物体）、（场景元素）、（光影色调）、（材质质感）、（时代氛围）不变，不新增、不删减、不替换任何主体和关键物体。

画幅：
默认 21:9 超宽银幕电影构图，除非用户指定 16:9、9:16 或其他比例。

镜头角度：
写明用户指定角度，例如右前方45度鸟瞰、左侧高位俯拍、正上方90度垂直鸟瞰等。

镜头起点：
写清楚镜头从哪里开始，例如从场景右前上方、主体背后高处、核心物体正前方、正上方高空等。

镜头运动：
写清楚运动方式，例如缓慢推进、轻微下降、横向滑移、环绕、后拉、升高、穿过前景遮挡等。

镜头终点：
写清楚镜头最后停在哪里，例如停在核心物体上方、停在主体左下三分之一构图、停在远景空间中心等。

主体位置：
写清楚主体在画面中的位置，例如左下三分之一、右下三分之一、中央偏左、中央偏右、画面边缘作为尺度参照。

前景关系：
写清楚前景遮挡，例如前景压入（原图前景遮挡物），形成空间层次、窥视感或穿越感。

背景空间：
写清楚背景向哪个方向延伸，例如向左后方、右后方、正前方、画面深处延伸。

主体动作：
如果原图主体是人物 / 动物 / 载具，可写极轻微自然动作。动作必须小，不要改剧情。
如果原图是纯场景，则写环境微动，例如雾气流动、雨水飘落、草叶轻摆、火光闪烁、水面轻微反光。

视频节奏：
默认 5-8 秒，缓慢、稳定、电影感，不要剧烈运动。

稳定限制：
保持主体结构稳定，保持建筑结构稳定，保持空间关系稳定，保持参考图内容一致，禁止镜头漂移，禁止主体变形，禁止背景重组，禁止新增人物，禁止文字水印。
