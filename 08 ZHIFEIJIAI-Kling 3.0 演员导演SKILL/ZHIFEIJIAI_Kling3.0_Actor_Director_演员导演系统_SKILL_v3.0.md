# ZHIFEIJIAI｜Kling 3.0 Actor Director 演员导演系统 SKILL v3.0

> **用途：**把用户输入的一段大白话剧情、人物状态、对白、口语描述或参考图片要求，扩写成可直接用于 Kling 3.0 的影视级演员调度提示词。  
> **核心定位：**不是“情绪词库”，也不只是“口播模板”，而是“演员调度 + 动作约束 + 对白导演 + 情绪弧线 + 镜头表演合成器”。  
> **默认输出：**一段完整、可直接复制给 Kling 3.0 的中文 Actor Blocking Prompt。  
> **适用范围：**爱情、亲情、友情、暧昧、重逢、诀别、背叛、审讯、冲突、喜剧、黑色幽默、生活对白、方言对白、无台词反应戏、人物独白、产品口播，以及任何依赖演员表演完成的戏份。  
> **系统升级重点：**除了判断“人物为什么这么演”，还必须明确“动作做多大、做多慢、走什么轨迹、做几次、何时开始、何时停止、如何回收”。  

---

## 00. 强制执行名称

当用户要求调用本系统时，必须严格按以下名称执行：

```txt
ZHIFEIJIAI｜Kling 3.0 Actor Director 演员导演系统 SKILL v3.0
```

不得替换为 Seedance、Sora、MJ 或其他视频模型的提示词体系，不得混入无关的分镜拆解格式。

---

## 01. v3.0 升级目标

v1.0 主要解决：

```txt
抽象情绪
→ 可拍摄的眼神、微表情和身体反应
```

v3.0 继续升级为：

```txt
用户大白话
→ 人物与关系识别
→ 初始生活状态
→ 情绪触发点
→ 外显情绪 / 内藏情绪
→ 视线、眸光、微表情与身体反应
→ 对白前、对白中、对白后的演员调度
→ 方言、停顿、语气和潜台词
→ 镜头与环境配合
→ Kling 3.0 完整成品提示词
```

这次升级的重点不是增加华丽形容词，而是让模型知道：

```txt
人物什么时候开始演
为什么产生变化
先做什么
后做什么
说话时看哪里
说完后如何反应
最后把情绪停在哪里
```

## 02. 系统输入方式

用户可以只输入一句大白话：

```txt
她看见前男友，先装作无所谓，后来眼神还是有点难过，但不能哭。
```

也可以输入对白：

```txt
宝宝，石家庄最近好闷热，你身体燥热吗宝宝？
```

也可以输入人物与情绪：

```txt
一个中年男人从轻松带笑慢慢变得凝重坚定。
```

也可以配合参考图片：

```txt
根据这张人物图，让她用陕西话问老板这瓜保甜吗，感觉要有江湖式黑色幽默。
```

系统必须自动补齐可执行的演员调度，但不得擅自增加新的剧情事件。

## 03. 最终任务

系统必须完成以下步骤：

```txt
1. 识别主要表演者
2. 识别人物关系与交流对象
3. 识别场景、环境和镜头条件
4. 识别人物表演前的生活状态
5. 识别情绪触发点
6. 识别外显情绪与内藏情绪
7. 判断情绪强度与变化速度
8. 设计视线目标和眼神动作
9. 设计眸光变化
10. 设计微表情、呼吸与身体反应
11. 设计对白前、对白中和对白后的停顿
12. 设计最终情绪落点
13. 合成 Kling 3.0 可直接执行的完整提示词
```

最终必须输出成品，不得默认输出分析过程。

# v3.0 核心升级｜从情绪导演到演员运动控制

## 04. v3.0 升级本质

v2.0 已经解决：

```txt
用户大白话
→ 情绪判断
→ 眼神、眸光、微表情、身体反应
→ 对白前中后调度
```

v3.0 继续升级为：

```txt
用户大白话
→ 情绪与潜台词
→ 人物初始姿态
→ 动作预算
→ 动作约束
→ 动作起势
→ 动作运行
→ 动作停顿
→ 动作收势
→ 动作轨迹
→ 动作目的
→ 动作禁止项
→ Kling 3.0 Actor Blocking Prompt
```

v3.0 的本质是：

```txt
不是只告诉演员“要悲伤”
而是告诉演员：
从什么姿态开始
哪一秒开始变化
头转几度
身体前倾多少
手移动多远
一句话中何时完成
停顿多久
最后如何回到稳定状态
```

---

## 05. v3.0 新增八层动作控制结构

每个表演段落除情绪层外，必须尽量判断以下八层：

```txt
1. 初始姿态 Initial Pose
2. 动作预算 Motion Budget
3. 动作幅度 Motion Range
4. 动作速度 Motion Speed
5. 动作轨迹 Motion Path
6. 动作生命周期 Motion Lifecycle
7. 动作目的 Performance Intent
8. 动作黑名单 Motion Guard
```

这八层不是要求每次机械地全部写出数值，而是要求系统始终用“动作可控”的方式写提示词。

# 第一篇 A｜动作控制总则

## 06. 初始姿态必须先锁定

每段人物表演开始前，必须明确：

```txt
头部方向
下巴高度
肩颈松紧
上半身倾斜
身体重心
双手位置
视线目标
嘴角状态
呼吸状态
```

合格示例：

```txt
开场保持参考图中的初始姿态：头部向人物右侧轻微倾斜约3度，下巴自然收住，肩颈放松，身体重心略偏左，双手在腰腹前自然交叠，视线稳定看向镜头，嘴角只有很轻的笑意。
```

不合格示例：

```txt
她自然站着。
```

如果用户提供参考图，必须优先继承参考图姿态，不得擅自换姿势。

---

## 07. 动作预算 Motion Budget

动作预算用于防止 Kling 在短时间内生成过多无意义动作。

### 07.1 默认预算

#### 5秒以内

```txt
头部动作：最多1次
视线动作：最多1次
手部动作：0—1次
身体重心动作：最多1次
明显眨眼：最多1次
```

#### 6—10秒

```txt
头部动作：1—2次
视线动作：1—2次
手部动作：最多1次完整动作
身体重心动作：最多1次
明显眨眼：1—2次
表情主变化：最多1条完整情绪弧线
```

#### 11—15秒

```txt
头部动作：最多2次
视线动作：最多3次
手部动作：1—2次
身体重心动作：1—2次
明显眨眼：最多2次
表情主变化：最多2个节点
```

### 07.2 动作预算原则

```txt
宁可少，不可乱
宁可慢，不可跳
宁可一次完整，不可三次碎动作
宁可停住，不可持续晃动
```

禁止在8秒内同时安排：

```txt
歪头
点头
挑眉
抿嘴
摸头发
抬手
挥手
前倾
后退
连续眨眼
```

动作过密会导致：

```txt
换脸
手部崩坏
姿态漂移
口型不稳
情绪不连贯
```

---

## 08. 动作幅度 Motion Range

### 08.1 头部

默认范围：

```txt
轻微倾斜：2—5度
轻微抬头：2—4度
轻微低头：2—4度
明确转头：5—15度
口播类不建议超过15度
```

禁止：

```txt
突然大幅度歪头
左右反复摆头
快速点头
连续摇头
超过20度的无剧情转头
```

### 08.2 上半身

默认范围：

```txt
轻微前倾：1—3厘米
轻微后撤：1—3厘米
重心转移：小幅完成，不改变人物画面中心
肩膀打开：只做轻微自然变化
```

禁止：

```txt
突然坐直
突然弯腰
大幅靠近镜头
身体左右摇摆
肩膀连续起伏
```

### 08.3 手部

默认范围：

```txt
口播手势移动：3—8厘米
手肘保持靠近身体
手掌高度不超过胸口
非必要不超过肩宽
一次手势只表达一个意思
```

禁止：

```txt
反复挥手
连续甩腕
手指频繁乱动
手掌突然翻转
手肘大幅张开
无目的指镜头
```

### 08.4 视线

默认范围：

```txt
镜头 → 产品 → 镜头
镜头 → 画外人物 → 镜头
对方眼睛 → 短暂低眼 → 对方眼睛
```

一次视线移动只完成一个明确目标。

禁止：

```txt
眼球连续乱飘
无目的左右扫描
看镜头又同时看远处
视线目标频繁跳跃
```

---

## 09. 动作速度 Motion Speed

动作不能只写“慢慢”，必须尽量明确它在多长时间内完成。

推荐写法：

```txt
在整句台词中缓慢完成
用0.5秒轻轻抬眼
在1秒内把头部从倾斜状态摆正
动作从句首开始，到最后一个字时完成
停顿开始后再启动手部动作
```

### 09.1 默认速度等级

```txt
极慢：1.5—3秒完成
缓慢：0.8—1.5秒完成
自然：0.4—0.8秒完成
短促：0.2—0.4秒完成
```

情绪戏默认使用：

```txt
缓慢
自然
短促停顿
```

除非动作戏，不默认使用快速动作。

---

## 10. 动作轨迹 Motion Path

每个明显动作要尽量有起点、路径和终点。

### 10.1 头部轨迹

```txt
轻微右倾
→ 缓慢摆正
→ 最后回到2度右倾
```

### 10.2 视线轨迹

```txt
镜头
→ 产品
→ 镜头
```

```txt
对方眼睛
→ 地面
→ 重新抬眼看对方
```

### 10.3 手部轨迹

```txt
腰腹
→ 胸口下方
→ 向前送出5厘米
→ 回到腰腹
```

### 10.4 身体轨迹

```txt
重心略偏左
→ 说关键句时向前1—2厘米
→ 停顿后回到中立
```

禁止用模糊句：

```txt
她做了一个手势。
他身体动了一下。
```

---

## 11. 动作生命周期 Motion Lifecycle

每个重要动作尽量包含：

```txt
准备
→ 启动
→ 进行
→ 停止
→ 回收
```

### 11.1 示例：抬手

错误：

```txt
她抬手强调。
```

正确：

```txt
停顿开始后，右手才从腰腹位置缓慢抬起；手肘始终靠近身体，手掌抬到胸口下方后停止。说到关键词时，右手向前送出约5厘米，随后手腕放松，手掌缓慢回到腰腹位置，不能停在半空。
```

### 11.2 示例：笑容

错误：

```txt
她慢慢笑起来。
```

正确：

```txt
笑意从眼神先出现，嘴角在整句台词中缓慢上扬，到最后一个字时才形成完整浅笑；停顿后笑容保持半秒，再自然收回到轻微笑意。
```

### 11.3 示例：低头再抬眼

```txt
先垂眼停住半秒
→ 下巴轻轻收住
→ 呼吸稳定
→ 用0.8秒缓慢抬眼
→ 最后重新锁定镜头
```

---

## 12. 动作目的 Performance Intent

每个明显动作要说明“为什么做”，防止模型误演。

推荐格式：

```txt
这个动作不是……
而是……
```

示例：

```txt
轻轻偏头，不是刻意卖萌，而是表达认真倾听。
```

```txt
下巴轻微下压，不是训斥，而是表达边界感和确定性。
```

```txt
嘴角单侧短暂上提，不是开心，而是对现实荒谬感的一点冷淡讽刺。
```

```txt
身体轻微前倾，不是逼近镜头，而是进入认真表达状态。
```

```txt
抬手掌心向上，不是指责，而是把结论平静地摆出来。
```

动作目的必须服务于：

```txt
潜台词
人物关系
权力状态
情绪落点
```

---

## 13. 动作黑名单 Motion Guard

### 13.1 头部黑名单

```txt
连续点头
连续摇头
快速歪头
左右反复摆动
突然仰头
无理由低头抬头循环
```

### 13.2 面部黑名单

```txt
连续挑眉
频繁抿嘴
夸张撇嘴
挤眉弄眼
无原因皱眉
嘴角左右跳动
表情瞬间切换
```

### 13.3 眼部黑名单

```txt
连续快速眨眼
眼球左右乱飘
无目标失焦
同时“死死盯住”和“完全涣散”
每句话都眨眼
```

### 13.4 手部黑名单

```txt
乱挥手
反复甩手
手腕高速抖动
连续指镜头
双手同时乱动
动作后手停在半空
```

### 13.5 身体黑名单

```txt
持续前后摇晃
突然坐直
肩膀连续耸动
身体大幅左右移动
脱离画面中心
```

# 第一篇 B｜时间轴演员调度

## 14. 时间轴必须写到“段”，不要求机械写到每一帧

v3.0 推荐：

```txt
0.0—1.0秒：初始状态
1.0—3.0秒：第一句台词与姿态变化
3.0—3.5秒：停顿
3.5—6.0秒：第二句台词与关键动作
6.0—7.0秒：动作回收
7.0—8.0秒：结尾停留
```

不建议无必要细分到：

```txt
0.1秒
0.2秒
0.3秒
```

除非用户明确要求极高精度动作控制。

---

## 15. 台词必须绑定动作节点

每句台词必须判断：

```txt
句首：动作从哪里开始
句中：动作如何推进
关键词：哪个动作落点
句尾：动作是否完成
停顿：身体是否收住
```

示例：

```txt
说“我没生气”时，人物不立刻抬眼。句首保持低眼，句中缓慢抬起视线，到“生气”两个字时才看向对方；说完后视线停住半秒，嘴角没有笑。
```

---

## 16. 停顿是动作，不是空白

每次停顿要说明：

```txt
嘴是否闭上
视线是否保持
身体是否完全收住
手是否开始下一动作
是否允许眨眼
呼吸如何变化
```

正确：

```txt
停顿0.5秒。嘴闭上，身体动作完全收住，视线继续停在镜头上，只保留自然呼吸，不立刻启动下一动作。
```

错误：

```txt
停顿一下。
```

---

## 17. 构图稳定约束

口播和情绪特写必须默认保持：

```txt
固定画幅
固定焦段
人物主体不漂移
人物始终处于画面中心或既定构图位置
动作不导致头顶、肩膀或手部出框
```

如果人物从头到腰入镜：

```txt
头部倾斜不超过5度
上半身前倾不超过3厘米
手部活动控制在腰腹至胸口下方
手肘不超过身体外轮廓过多
```

---

## 18. 自然口播动作原则

自然口播动作必须具备：

```txt
幅度小
速度慢
动作少
起势自然
停顿明确
收势完整
与台词有因果关系
```

不要让人物像：

```txt
演讲
直播叫卖
舞台表演
机械播报
手势教学
```

而要像：

```txt
真实聊天
认真解释
生活分享
安静回应
克制表达
```

---

## 19. v3.0 Actor Blocking 输出骨架

最终提示词可按以下骨架生成：

```txt
【参考图与角色锁定】

【镜头与构图锁定】

【动作总原则】
动作幅度、速度、预算、画面中心、禁止项。

【0.0—X秒 开场状态】
头部、肩颈、重心、双手、视线、嘴角、呼吸。

【X—X秒 第一段台词】
句首动作、句中推进、关键词落点、句尾收势。

【停顿】
嘴、眼、手、身体、呼吸的状态。

【下一段台词】
动作轨迹、动作目的、幅度和回收。

【结尾停留】
情绪落点、视线落点、姿态回归、动作停止。

【全局禁止项】
换脸、漂移、乱动、重复动作、夸张表演、手停半空等。
```

# 第一篇｜总执行原则

## 04. 情绪必须写成变化过程

错误：

```txt
她很委屈。
他非常生气。
她的眼神很复杂。
他变得坚定。
```

正确：

```txt
她先保持礼貌的笑，视线仍停在对方脸上；听完那句话后，嘴角没有立刻落下，眼底的光却慢慢弱了一点。她轻轻吸气，鼻翼绷住，眼眶泛起湿意，但始终没有让眼泪掉下来。
```

每个情绪段至少应具备：

```txt
起始状态
→ 触发
→ 第一反应
→ 情绪渗出
→ 明确转折
→ 收尾状态
```

---

## 05. 表演必须先有“未进入表演”的状态

Kling 容易在第一帧直接进入最终表情，因此必须先交代人物起始状态。

常用写法：

```txt
画面先完全保持开始时的状态。
人物暂时没有明显情绪，只保持自然呼吸。
摄影机已经开机，但人物还没有正式进入表演。
她先安静地看着镜头一秒。
他先维持原本放松的神情，没有立刻做出反应。
```

起始状态必须与后续情绪形成差异。

---

## 06. 情绪必须有触发点

人物不能无缘无故变脸。

触发点可能来自：

```txt
听到一句话
听见某个人的名字
看见对方
看见旧物
收到手机消息
察觉画外声音
对方突然沉默
意识到真相
看见对方转身离开
被对方触碰
被摄影机外的人提醒“开始”
```

用户没有明确给出触发点时，只能从原剧情中推断最自然的触发节点，不得添加新的角色、事件或道具。

---

## 07. 外显情绪和内藏情绪必须分层

系统必须判断两件事：

```txt
人物想让别人看见什么
人物真正压着什么
```

常见双层组合：

```txt
甜笑 / 悲伤
礼貌 / 失望
轻松 / 心虚
冷静 / 愤怒
冷漠 / 心痛
强硬 / 不舍
玩笑 / 试探
撒娇 / 关心
无所谓 / 嫉妒
麻木 / 崩塌
```

禁止用“百感交集”“眼神复杂”代替具体变化。

---

## 08. 眼神必须是动作，不是形容词

眼神至少包含：

```txt
视线目标
＋ 视线动作
＋ 聚焦状态
＋ 眸光变化
＋ 情绪转折
```

错误：

```txt
她悲伤地看着他。
```

正确：

```txt
她先把视线落到他的脸上，停住一瞬，随后轻轻移开；视线仍然保持聚焦，但眼底的光慢慢弱下去，像已经明白答案，却不愿意当场承认。
```

---

## 09. 微表演优先

除非用户明确要求强烈爆发，否则默认采用：

```txt
克制
缓慢
轻微
真实
不立刻
快失控但仍然压住
眼眶湿但不落泪
嘴角仍在维持
呼吸和面部肌肉发生细小变化
```

默认禁止：

```txt
突然痛哭
仰头嘶吼
大幅摇头
表情扭曲
反复挤眉弄眼
夸张喘息
网剧式崩溃
```

---

## 10. 情绪结尾必须有去向

每段表演最后必须明确：

```txt
情绪被重新压回去
情绪停在眼底
人物彻底释放
人物重新稳住呼吸
人物移开视线
人物重新锁定目标
人物转为冷漠
人物停在没有说出口的位置
```

禁止在情绪变化中途突然结束。

---

# 第二篇｜人物状态层

## 11. 表演前状态库

系统应根据剧情选择一种最自然的初始状态。

### 11.1 自然等待

```txt
安静站立
自然呼吸
眼神放松
等待对方开口
等待摄影机外的指令
```

### 11.2 生活聊天

```txt
面对熟悉的人
嘴角带一点自然笑意
身体松弛
像视频通话或日常聊天
并未刻意表演
```

### 11.3 认真倾听

```txt
目光停在对方脸上
嘴角自然收住
身体略微朝对方倾斜
没有急着回应
```

### 11.4 故意沉默

```txt
知道答案但不立刻说
视线稳定
表面平静
通过停顿给对方压力
```

### 11.5 疲惫状态

```txt
呼吸略沉
眼睑稍低
肩膀自然下垂
不是悲伤，只是精神消耗明显
```

### 11.6 炎热状态

```txt
皮肤有轻微汗光
呼吸比平时略重
鼻翼随呼吸轻微动作
眼神被强光压得稍微眯起
动作仍然自然
```

### 11.7 运动后状态

```txt
呼吸尚未完全平稳
胸口轻微起伏
额头有汗
说话前需要先调整气息
```

### 11.8 喝醉后的克制状态

```txt
视线略慢
反应有轻微延迟
情绪更容易漏出来
但身体仍努力保持稳定
```

---

## 12. 人物关系识别

表演强度和语气必须服从人物关系。

### 12.1 恋人

```txt
视线停留更久
说话更柔软
会等待回应
可能包含宠溺、心疼、试探或撒娇
```

### 12.2 暧昧关系

```txt
不直接表达
停顿比普通聊天更长
会先看一眼再躲开
话里有试探，表情有保留
```

### 12.3 夫妻

```txt
熟悉感强
动作不必刻意甜
关心常藏在埋怨、打趣或沉默里
```

### 12.4 亲子

```txt
关心更直接
情绪可能强撑
长辈常把担心藏在命令或唠叨中
孩子常把委屈藏在回避中
```

### 12.5 朋友 / 闺蜜 / 兄弟

```txt
更生活化
允许打趣
语气和身体姿态更松弛
重要情绪通常在玩笑之后才露出
```

### 12.6 敌对关系

```txt
视线控制权重要
停顿带压力
动作幅度减少
表面越平静，潜在冲突越强
```

### 12.7 上下级

```txt
一方控制节奏
另一方观察反应
回避、停顿与称呼体现权力关系
```

### 12.8 陌生人

```txt
保持距离
先观察再回应
微笑更礼貌而非亲密
```

---

# 第三篇｜触发层

## 13. 触发类型

### 13.1 声音触发

```txt
听到一句话后才开始反应
听到名字后眼神停住
听见门外声音后转移视线
```

### 13.2 视觉触发

```txt
看到对方后怔住
看见物件后沉默
看见对方回避后失望
```

### 13.3 触碰触发

```txt
被碰到手后短暂僵住
对方靠近后呼吸变化
```

### 13.4 记忆触发

```txt
一个词让她想起过去
某个动作让他短暂停顿
```

### 13.5 对白结束触发

```txt
不是在对方说话时变化
而是在对方说完后才明白含义
```

### 13.6 无回应触发

```txt
等待太久没有得到回答
对方的沉默本身成为答案
```

```txt
营业式笑容

强撑笑
似笑非笑
冷静

故作轻松
故作强硬
礼貌克制
故意冷淡
开玩笑
撒娇
```

---

## 15. 内层情绪类型

```txt
难过
委屈
愧疚
压怒
心虚
怀疑
嫉妒
害羞
想念
心疼

恐惧
失望
麻木
疲惫
决绝
信念感
被看穿后的慌乱
看透后的冷静
```

---

## 16. 双层情绪合成规则

### 16.1 微笑掩饰悲伤

```txt
先自然笑
→ 笑容维持
→ 眼神先变弱
→ 面部肌肉开始撑不住
→ 眼眶湿但不落泪
→ 把情绪压回去
```

### 16.2 礼貌掩饰失望

```txt
先认真等待答案
→ 听完后仍保持礼貌
→ 嘴角轻轻收住
→ 眸光慢慢熄下去
→ 移开视线，不再期待
```

### 16.3 冷静压住愤怒

```txt
先沉默
→ 低眼压住
→ 缓慢抬眼
→ 眸光转冷
→ 下颌轻轻咬紧
→ 身体不动
```

### 16.4 玩笑包裹试探

```txt
表面轻松
→ 带笑开口
→ 在关键词前停顿
→ 说完后不移开视线
→ 等待对方暴露反应
```

### 16.5 撒娇包裹关心

```txt
先温柔看镜头
→ 轻轻叫对方称呼
→ 用软语气问候
→ 说完后等待回答
→ 眼神持续停留
```

### 16.6 无所谓掩饰嫉妒

```txt
先轻笑
→ 说得像不在意
→ 视线短暂躲开
→ 嘴角收紧一点
→ 再看回去确认对方反应
```

### 16.7 强硬掩饰不舍

```txt
说话干脆
→ 不看对方
→ 手部动作停顿
→ 对方转身后才抬眼
→ 最终没有挽留
```

# 第五篇｜眼神与眸光系统

## 17. 视线目标库

```txt
镜头
对方的脸
对方的眼睛
对方的嘴
对方的手
对方手中的物件
地面
远处
门口
窗外
画外声源方向
镜子中的自己
手机屏幕
手中旧物
空处
逃离方向
```

---

## 18. 视线动作库

```txt
慢慢转向
快速看一眼
停住半秒
停留两秒
轻轻垂下
重新抬起
看一眼后立即躲开
先避开再重新直视
跟随对方动作移动
在对方脸上反复确认
视线停在空处
先锁定目标，随后轻微失焦
从物件移回对方脸上
```

---

## 19. 聚焦状态库

```txt
稳定聚焦
短暂失焦
无法保持稳定聚焦
重新锁定
像在确认身份
像在等待答案
像已经看穿对方
像明白了却不愿承认
```

---

## 20. 眸光轨迹库

### 20.1 由亮到暗

```txt
眸光稳定
→ 眼底的光轻轻晃动
→ 眸光慢慢变弱
→ 眼里的光停在疲惫状态
```

### 20.2 由软到冷

```txt
眼神最初柔和
→ 视线保持不变
→ 眸光温度逐渐退去
→ 眼底变得清醒而锐利
```

### 20.3 由空到坚定

```txt
目光短暂发空
→ 呼吸重新稳定
→ 视线重新聚焦
→ 眸光重新聚起
```

### 20.4 由怀疑到确认

```txt
快速观察
→ 瞳孔轻微收紧
→ 视线停住
→ 眸光进入警戒状态
```

### 20.5 泪意含住

```txt
眼底出现轻微湿意
→ 眼眶慢慢泛红
→ 泪意停在眼睑边缘
→ 不允许眼泪滑落
```

---

## 21. 眼部微细节库

```txt
眼睑轻微发颤
瞳孔轻微放大
瞳孔微微收紧
眨眼速度变慢
眨眼频率稍微增加
几乎不眨眼
眼眶泛红
眼底湿润
眼白出现细微血丝
泪意含住但不落下
眸光被雨水或风沙反光打散
眸光重新聚起
```

---

## 22. 眼神冲突保护

禁止：

```txt
涣散地死死盯住对方
一边移开视线一边牢牢锁定对方
一边完全麻木一边眼神炽热
```

改为时间顺序：

```txt
先盯住对方，随后目光轻微失焦。
先移开视线，停顿后再抬眼直视。
眼神先空掉，随后在做出决定后重新聚起。
```

---

# 第六篇｜面部微表情与身体反应

## 23. 嘴角动作库

```txt
嘴角自然放松
嘴角柔和上扬
笑意慢慢浮现
嘴角仍在笑，但已经有点撑不住
嘴角轻轻收住
嘴角绷紧
轻轻抿嘴
张口前先吸气
嘴唇微张却没有发声
下唇轻微发颤
```

---

## 24. 鼻翼、下颌和喉咙动作库

```txt
鼻翼随呼吸轻轻动一下
鼻翼轻微绷紧
下颌轻轻咬住
下颌线逐渐收紧
喉咙像咽下一口气
说话前轻轻吞咽
呼吸被截住一瞬
```

---

## 25. 眉眼动作库

```txt
眉梢轻轻抬起
眉心轻微收紧
眉毛没有明显动作，只让眼神变化
眼睑稍微压低
强光下自然眯眼
```

不得频繁使用夸张挑眉。

---

## 26. 呼吸动作库

```txt
自然呼吸
轻轻吸气后再开口
呼吸短暂停顿
呼吸慢慢变浅
缓慢呼出一口气
说完后重新调整呼吸
胸口起伏逐渐恢复平稳
```

---

## 27. 手部与身体动作库

```txt
手指轻轻收紧
指尖轻微发抖
手停在半空
手指无意识摩擦物件
肩膀轻轻收紧
肩膀慢慢放松
身体微微前倾
身体轻轻后撤
重心改变但不迈步
身体短暂僵住
身体强行稳住不动
头部轻轻偏向一侧
下巴微微抬起
```

动作应少而准，不得每句话都配一个动作。

# 第七篇｜对白导演系统

## 28. 对白不是朗读

对白必须包含：

```txt
说话前的状态
说话前是否停顿
说话时看向哪里
关键词如何强调
语速和音量
说完后的眼神与呼吸
听者如何反应
```

错误：

```txt
她说：“你是不是早就知道了？”
```

正确：

```txt
她没有立刻开口，先看了他两秒，像在确认自己是否还需要问。随后她用很轻、很平稳的声音说：“你是不是……早就知道了？”“是不是”之后停顿半秒。说完后她仍然看着他，嘴角没有变化，只有眼底的光慢慢弱下去。
```

---

## 29. 对白前调度

常用方式：

```txt
先看镜头一秒
先看对方的反应
先轻轻笑一下
先吸一口气
先把视线移开
先低眼再抬眼
先停顿，不急着开口
```

---

## 30. 对白中调度

系统必须判断：

```txt
哪一个词需要停顿
哪一个词需要放轻
哪一句需要带笑
哪一句表面轻松、实际试探
是否拖尾音
是否压低声音
是否说到一半改变眼神
```

不能给所有台词平均用力。

---

## 31. 对白后调度

对白说完后必须有反应：

```txt
继续看着对方等待回答
轻轻移开视线
嘴角慢慢收住
呼吸恢复平稳
轻轻眨眼
不说话，用沉默施压
表面仍笑着，眼神却变冷
```

---

## 32. 生活感对白导演

生活对白不能像主播念稿。

应具备：

```txt
自然停顿
口语节奏
称呼前后留白
说完等待回应
表情和语气不过度甜腻
```

示例输入：

```txt
宝宝，石家庄最近好闷热，你身体燥热吗宝宝？
```

转译逻辑：

```txt
先温柔看镜头
→ 轻轻叫“宝宝”
→ 说第一句时像分享近况
→ 停顿观察
→ 第二句转为关心
→ 问完继续等待回答
```

对白不得被机械拆得太碎，必须保持自然可说。

---

## 33. 恋爱聊天模板

```txt
人物先自然看着镜头，像正在和恋人视频通话。嘴角带一点轻松笑意，眼神停留时间比普通聊天更长。开口前轻轻眨眼或吸气。说称呼时语气放软，但不要刻意夹声。问完后保持视线，像真的在等待对方回应。
```

---

## 34. 暧昧试探模板

```txt
先表现得若无其事
→ 说话时带一点笑
→ 关键词前停顿
→ 说完后观察对方
→ 对方未回应时轻轻移开视线
```

---

## 35. 夫妻生活对白模板

```txt
语气自然熟悉
不必始终看对方
可以一边做生活动作一边说话
关心可以藏在埋怨里
说完仍继续原来的动作
```

---

## 36. 亲子对白模板

```txt
长辈：嘴上克制，眼神持续关注。
孩子：嘴上说没事，视线可能回避。
重要情绪通过停顿和动作表现，不依赖哭喊。
```

---

## 37. 朋友打趣模板

```txt
先笑着说
→ 关键词稍微加重
→ 说完观察对方
→ 确认对方不介意后笑意放松
```

---

## 38. 江湖式黑色幽默模板

当用户提出“江湖式、荒诞、黑色幽默、表面闲聊但有压迫感”时，不直接复制任何影视作品台词或表演，而是转译为：

```txt
对白表面轻松
停顿具有审视感
嘴角带一点若有若无的笑
视线始终锁定对方
关键词说得更慢
问完后不急着移开视线
潜台词像在判断对方是否说谎
```

禁止夸张模仿具体演员。

---

## 39. 方言处理规则

用户指定方言时：

```txt
保留原意
使用自然、易理解的轻方言
口型应尽量清晰
不要堆砌生僻方言词
不要因方言改变人物身份和剧情
```

如果用户只说“陕西话”，默认使用较自然、易听懂的关中口语感。

如果不确定具体方言表达，优先保持普通话句式，只在语气词、尾音和节奏上体现地域感。

---

## 40. 对白长度控制

### 5 秒

```txt
建议 8—16 个汉字
最多一个停顿
一个情绪变化
```

### 8—10 秒

```txt
建议 18—35 个汉字
可分两句
允许一次等待和一次情绪转折
```

### 15 秒

```txt
建议 30—55 个汉字
允许两到三句
必须留出表演和反应时间
```

对白过长时，优先压缩台词，不得牺牲表演过程。

---

# 第八篇｜双人对手戏

## 41. 双人戏必须区分表演职责

需要识别：

```txt
谁先说话
谁先看对方
谁在等待
谁回避
谁掌握节奏
谁是主要情绪承受者
最后镜头停在谁身上
```

禁止：

```txt
两人眼神复杂。
两人互相看着。
两人都很激动。
```

正确：

```txt
女人先看着男人，像在等一个解释；男人只和她对视一瞬就移开目光。女人嘴角原本还留着一点期待，看到他回避后，眼底的光慢慢暗下去。男人的手停在身侧，指尖轻轻收紧，却始终没有重新抬眼。
```

---

## 42. 双人对白时间链

```txt
A 的起始状态
→ B 的一句话或动作
→ A 的第一反应
→ A 回答
→ B 观察 A
→ 两人视线关系变化
→ 结尾停在最有信息量的人物上
```

---

## 43. 反应镜头优先原则

情绪戏中，有时听者比说话者更重要。

系统必须判断：

```txt
台词是谁说的
真正发生情绪变化的是谁
```

不得始终把镜头和描写放在说话者身上。

# 第九篇｜无对白表演

## 44. 沉默不是没有动作

无对白戏必须写清：

```txt
视线落在哪里
眨眼是否变化
呼吸是否变化
嘴角是否收紧
手是否停住
身体是否后退
眸光是暗下去还是重新聚起
```

示例：

```txt
他没有回答。视线先停在她的脸上，随后慢慢落到地面。下颌轻轻咬住，胸口起伏短暂变小，手指在身侧慢慢握紧。整个过程没有大动作，但回避已经代替了回答。
```

# 第十篇｜环境参与表演

## 45. 环境只做情绪放大器

可使用：

```txt
风吹动发丝
雨水沿脸侧滑落
窗帘轻轻移动
远处车辆经过
背景人影虚化移动
灯光轻微变化
衣角被风带动
空气中的热浪
```

环境必须和人物反应发生关系。

正确：

```txt
风把几缕头发吹到她脸前，她没有整理，像已经没有多余力气顾及。
```

错误：

```txt
天空壮丽，云层翻涌，远山雄伟。
```

除非剧情需要，不得让环境抢走人物情绪焦点。

---

## 46. 炎热环境表演

当剧情出现“闷热、燥热、盛夏”时，可使用：

```txt
皮肤保留轻微汗光
鼻翼随呼吸自然变化
发丝贴近脸侧
人物轻轻呼气
眼神在强光下自然稍微眯起
```

禁止把炎热演成夸张喘息或痛苦表情。

# 第十一篇｜参考图锁定

## 47. 有参考图时必须首帧锁定

自动加入：

```txt
画面先完全保持参考图片开始时的状态。
必须保持同一人物五官、脸型、肤色、年龄、发型、服装、首饰、身体比例、姿态与场景一致。
第一帧不要突然改变表情、头部角度和镜头位置。
摄影机已经开始记录，但人物尚未正式进入表演。
```

---

## 48. 参考图表情处理

如果参考图已经微笑：

```txt
从原有笑容开始变化
不能先重置成面无表情
```

如果参考图已经凝重：

```txt
从现有凝重状态继续推进
不能突然改成灿烂笑容，除非剧情明确要求
```

---

## 49. 角色一致性保护

必须保持：

```txt
同一人物
同一张脸
同一年龄感
同一发型
同一服装
同一妆容
同一饰品
同一光线方向
同一背景空间
```

禁止因表情变化导致换脸、变年龄、妆容跳变或服装变化。

# 第十二篇｜镜头导演

## 50. 情绪戏优先镜头

```txt
面部特写
近景
中近景
85mm 中长焦感
50mm 自然观察感
浅景深
轻微手持呼吸感
极慢推进
固定机位
```

镜头必须服务表演。

## 51. 镜头运动限制

默认禁止：

```txt
高速环绕
夸张推拉
频繁甩镜
无意义升格
突然跳轴
镜头大幅抖动
快速切换多个景别
```

只有用户明确要求强冲突或动作戏时才允许增强运动。

---

## 52. 镜头与眼神关系

如果人物看镜头：

```txt
明确为直视镜头或视频通话视角
```

如果人物看画外对象：

```txt
明确对象位于画外左侧或右侧
保持视线方向稳定
```

禁止视线方向在帧间随机漂移。

# 第十三篇｜时间节奏

## 53. 默认时长

用户未指定时，默认按 8—10 秒设计。

---

## 54. 5 秒结构

```txt
0—1 秒：起始状态
1—2 秒：触发
2—4 秒：主要情绪变化或一句对白
4—5 秒：收尾动作
```

只允许一个主要转折。

---

## 55. 8—10 秒结构

```txt
0—2 秒：人物自然状态
2—4 秒：触发和第一反应
4—7 秒：对白或情绪渗出
7—10 秒：眸光变化与结尾收口
```

---

## 56. 15 秒结构

```txt
0—3 秒：环境和人物初始状态
3—6 秒：触发与表层反应
6—10 秒：对白或内层情绪出现
10—13 秒：明确情绪转折
13—15 秒：结尾余韵
```

不得为了填满时长添加无意义动作。

# 第十四篇｜核心情绪弧线模板

## 57. 微笑掩饰悲伤

```txt
自然笑
→ 前两秒看不出悲伤
→ 笑容保持
→ 眸光逐渐变弱
→ 鼻翼和喉咙出现轻微反应
→ 眼眶湿但不落泪
→ 低眼再抬眼，把情绪压回去
```

---

## 58. 平静到坚定

```txt
起始放松
→ 想起某件事
→ 笑意慢慢收住
→ 视线重新聚焦
→ 下颌轻轻收紧
→ 呼吸变稳
→ 眸光重新聚起
```

---

## 59. 惊恐到僵住

```txt
看见危险
→ 视线停住
→ 瞳孔轻微放大
→ 目光开始不稳定
→ 嘴唇微张
→ 呼吸变浅
→ 身体后撤后僵住
```

---

## 60. 怀疑到确认

```txt
听见异常
→ 快速看向声源
→ 视线搜寻
→ 短暂停顿
→ 瞳孔微收
→ 视线重新锁定
→ 身体进入警戒状态
```

---

## 61. 回避到面对

```txt
先看一眼后躲开
→ 视线落地
→ 呼吸调整
→ 缓慢抬眼
→ 重新直视
→ 眸光逐渐稳定
```

---

## 62. 失望到心冷

```txt
先等待解释
→ 听完仍然保持平静
→ 嘴角轻轻收住
→ 眸光慢慢熄下去
→ 移开视线
→ 不再期待
```

---

## 63. 麻木到崩塌

```txt
听到真相
→ 没有立刻反应
→ 视线停在空处
→ 眸光暗下去
→ 呼吸变浅
→ 身体像被抽空
→ 保持沉默
```

---

## 64. 重逢后的克制激动

```txt
先怔住
→ 不敢确认
→ 在对方脸上反复确认
→ 眼底的光重新亮起来
→ 嘴角想笑但没有立刻笑
→ 呼吸变乱
→ 最后露出很轻的笑
```

---

## 65. 心虚被看穿

```txt
表面自然
→ 先笑着回应
→ 对方持续注视
→ 眨眼频率变化
→ 视线短暂躲开
→ 手指或嘴角出现不自然反应
→ 重新看回去维持镇定
```

---

## 66. 轻松到试探

```txt
先像闲聊一样开口
→ 关键词前停顿
→ 嘴角仍有笑
→ 眸光变得清醒
→ 问完持续看着对方
→ 用沉默等待答案
```

---

## 67. 温柔关心

```txt
先自然看着镜头
→ 轻轻叫对方称呼
→ 第一段像分享近况
→ 停顿观察
→ 第二段转为关心
→ 问完保持温柔视线等待回答
```

# 第十五篇｜风格转译规则

## 68. 用户给影视风格参考时

不直接复刻具体作品的独特台词、镜头或演员表演，而是提炼为可执行特征。

例如：

### 现实主义生活剧感

```txt
自然表演
低强度情绪
生活化停顿
不刻意煽情
真实环境声
```

### 江湖黑色幽默感

```txt
表面闲聊
潜台词施压
停顿带审视
似笑非笑
问完不移开视线
```

### 都市暧昧感

```txt
话不说满
视线停留与回避交替
呼吸和嘴角变化细微
```

### 诗意克制感

```txt
减少对白
延长沉默
让环境动作参与情绪
情绪停在没有说出口的位置
```

```txt

当【触发点】发生后，【人物】才开始产生反应。她 / 他先【视线动作】，随后【第一表层反应】。前一两秒，人物仍表现得【外显情绪】，暂时看不出真正的【内藏情绪】。

接着，【外在表情或姿态】仍然保持，但【真实情绪】开始从眼神里慢慢露出来。【眸光变化】，【眼部微细节】；【嘴角、鼻翼、下颌、喉咙变化】；【呼吸、肩膀、手指或重心变化】。所有动作保持轻微、缓慢和真实，不要突然爆发。

【有对白时】人物在开口前先【对白前动作】，随后用【语气、语速、音量、方言要求】说：“【原台词】”。在“【关键词】”前后停顿【时长】，说话时视线【方向】，说完后【对白后反应】，像在【潜台词意图】。

最后两秒，【人物仍维持的外在状态】，但【内层情绪留下的痕迹】已经能够被看见。她 / 他最后【低眼 / 抬眼 / 移开视线 / 重新锁定 / 稳住呼吸】，让情绪【压回去 / 停在眼底 / 转为坚定 / 彻底放下】。

```

## 74. 生活对白模板

```txt
【Kling 3.0 导演表演提示词】

画面先保持人物开始时的自然状态，人物像正在和熟悉的人进行真实聊天，没有主播感和表演痕迹。镜头采用面部近景和极轻微手持呼吸感。她 / 他先自然看着【镜头 / 对方】，嘴角带一点【自然笑意 / 松弛状态】，停顿一秒后才开口。

最后保持视线，轻轻眨眼或偏头，像真的在等待对方回答。全程口型清晰自然，语气生活化，不朗诵，不夹嗓，不夸张撒娇，不新增台词。
```

## 75. 黑色幽默试探模板

```txt
【Kling 3.0 导演表演提示词】

人物先保持放松、似笑非笑的状态，像只是在随口聊天。她 / 他先观察画外对方，再把视线短暂落到相关物件上，随后重新看回对方。第一句对白说得轻松自然，关键词稍微放慢，嘴角仍有笑意。

说完后停顿半秒，不急着移开视线。第二句对白语速更慢，声音略低，在关键问题前留出短暂停顿。嘴角依然带笑，眼神却逐渐清醒、锐利，问完后持续看着对方，用沉默等待答案。表面是闲聊，潜台词是在判断对方是否说谎。不要夸张挑眉，不要模仿具体演员，不要做成搞笑短剧。
```

## 77. 禁止事项

12. 禁止网剧式挤眉弄眼。

14. 禁止把“克制”写成完全没有变化。  
15. 禁止把“生活感”写成主播口播。  
16. 禁止把“撒娇”写成刻意夹声。  
17. 禁止把“黑色幽默”写成纯搞笑。

19. 禁止因情绪变化导致换脸、变年龄、变服装。

23. 禁止在用户要求“不哭”时生成眼泪滑落。  
24. 禁止在用户要求方言时堆砌难懂方言词。
