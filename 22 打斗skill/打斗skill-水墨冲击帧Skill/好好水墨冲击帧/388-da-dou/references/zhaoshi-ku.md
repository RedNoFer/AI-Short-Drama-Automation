# 武器招式库 · 拔刀斩起手 · 镜头语言 · 特写与对话（388打斗 · 随用随查）

> 源自《高燃打斗视频提示词 Skill》第七、八、十一、十三、十四章。设计连招、起手式、特写穿插与台词时读取本库。连招铁律：一个连招 = 一个镜头，1.0–1.2 秒一气呵成；连招内部必须包含复合运镜、TimeRamp 快慢结合、特写穿插、台词穿插、攻防对招结果、环境反馈。

## 七、武器招式库（连招一镜到底）
### 7.1 连招写法核心规则
一个连招 = 一个镜头，在1.0-1.2秒内一气呵成完成全部动作。
禁止把七连斩拆成七个镜头，禁止一个镜头只写一个动作。
每个连招镜头内部必须包含：
1. 复合运镜：跟拍、甩摇、螺旋环绕、越肩、贴地仰拍等组合运镜。
2. TimeRamp 快慢结合：第一击命中瞬间慢放，随后加速连续快击，最后一击重击再慢放。
3. 特写穿插：连招过程中穿插武器特写、手部特写、碰撞特写。
4. 攻防对招：每一击写明命中/格挡/闪避/拆招/反击结果（见 7.1.1）。
5. 台词穿插：连招中可穿插短促台词（嘲讽、蓄力单字、热血台词）。
6. 环境反馈：招式对地面、碎石、花瓣、水面的影响（见范例 jiezou-shili.md）。
#### 7.1.1 对招与攻防互动强制规则（新增，解决打空气）
每一击都必须有明确结果，禁止打空气。每一刀、每一刺、每一拳、每一箭、每一次突进，都必须写明以下至少一种结果：
命中：击中对方哪个部位，对方如何受击、如何流血、如何后退、如何硬直。
格挡：对方用什么武器、什么角度格挡，格挡后火花、冲击波、双方后退距离、手臂颤抖、武器嗡鸣。
闪避：对方如何侧闪、后仰、翻滚、瞬移、下蹲、跃起，闪避后头发、衣摆、皮肤被擦过的细节。
拆招：对方如何用武器拨开、架住、压制、反绞、锁拿、震开攻击。
反击：对方格挡或闪避后，立刻打出什么反击招式，反击打向哪里，攻方如何应对。
连招中必须体现“你来我往”：
角色A出招 → 角色B格挡/闪避/拆招 → 角色B反击 → 角色A拆招/格挡 → 角色A继续连招。
禁止一方全程输出，另一方全程挨打或毫无反应。
禁止招式打向空气、对手站着不动、对手无格挡无闪避无受击。
禁止只写“刀光闪过”“剑气炸开”却没有写对手如何应对。
每一镜连招中，对手至少要有2–4次有效格挡/闪避/拆招/反击。
每一个大招命中后，受击方必须有受击反馈（见9.2.1）。
每一个大招对轰后，双方必须有硬直、喘息、后退、跪地、武器脱手等状态，禁止无征兆继续打。
#### 7.1.2 招式密度与速度强化规则（新增，解决招式少、慢）
每0.2秒至少一次攻防交换。
每镜连招中，双方招式总数不低于镜头秒数 × 5。例如1.2秒七连斩镜头，双方合计招式数不低于6次攻防交换。
五连斩、七连斩、九连斩、七连刺、九连刺中，对手必须有2–4次有效格挡、闪避、拆招、反击。
每个连招镜头中，至少穿插1次对手反击、1次对手拆招、1次对手格挡。
快节奏：出招即收招，收招即变招，招式与招式之间不拖沓。
禁止慢吞吞摆姿势、禁止站桩蓄力、禁止一招打完停半秒。
双方以超高速闪转腾挪，每0.2–0.3秒完成一次换位，招式密布如暴雨倾盆。
### 7.2 剑术通用
起手式：
· 剑诀上挑
· 零帧拔剑
· 时间骤降拔剑

中段连招（每个连招必须在一个镜头内完成，1.0-1.2秒）：
五连斩（一个镜头内五下连击一气呵成）：
斜撩 → 横削 → 直刺 → 逆斩 → 回旋斩。
七连斩（一个镜头内七下连击一气呵成）：
斜劈 → 横砍 → 直刺 → 逆斩 → 回旋斩 → 上挑 → 下劈。

十三连斩（一个镜头内十三下连击一气呵成）：
在九连斩基础上增加反手斩、转身斩、跃劈、落地斩。

刺面门 → 刺喉 → 刺胸 → 刺腹 → 刺肩 → 刺腕 → 刺膝。
九连刺（一个镜头内九下连刺一气呵成）：

十三连刺（一个镜头内十三下连刺一气呵成）：
在九连刺基础上增加转身刺、跃刺、回旋刺、终结刺。
其他中段连招：

## 八、拔刀斩起手
### 8.1 拔刀斩核心原理
拔刀斩不是“把刀拔出来再砍”，而是拔刀的动作本身就是斩击。出鞘与斩击一气呵成，没有停顿。刀出鞘的瞬间就是斩击的瞬间。
### 8.2 动作拆解（五步）
按鞘：左手按住刀鞘，右手握刀柄，拇指推开刀锋。
沉腰：身体微微下沉，重心压后脚。
拔斩一体：右手沿鞘口直线拔刀，刀身出鞘瞬间借助惯性斩击。
出鞘半寸：鞘口有光/特效从缝隙喷涌，花瓣与水珠悬停空中。
收势：斩完后刀身顺势停在斩击终点，或顺势纳刀。
### 8.3 适用条件
武器为剑或唐刀时，开头均可使用拔刀斩作为起手式。
武器为竹刀时，可改为“竹刀从腰间爆射而出”。
武器为双刀流时，可改为“双刀交叉拔刀斩”。
武器为重剑时，可改为“重剑从背后抽出，顺势劈斩”。

## 十三、特写镜头库
### 13.1 人物特写
面部特写：瞳孔骤缩/金色光晕/冷灰色寒光；手部特写：握武器手背青筋暴起/指节泛白；眼部特写：瞳孔中倒映对方/武器/环境；发丝特写：断发被冰晶冻结/被墨色染黑。
### 13.2 武器特写
武器出鞘半寸（TimeRamp慢放，特效从缝隙喷涌）；武器尖端微距（粒子汇聚，光点越聚越亮）；武器入鞘（收武器入鞘，发出一声轻响）。
### 13.3 碰撞特写
武器碰撞处（墨雾与风刃交织成旋涡）；穿刺点（能量粒子与碎屑混合喷射）；盾牌碎裂（碎片如花瓣向两侧倒塌）。
### 13.4 福利镜头
低机位仰拍：从腿部缓缓上摇，掠过腰线；慢放：风衣被气浪掀起，露出内衬轮廓；踢击：脚尖接触胸口的瞬间，布料被压出凹陷。
## 十四、对话插入规则
| 时机 | 类型 | 示例 |
|---|---|---|
| 蓄力时 | 单字 | "凝""起""斩" |
| 大招前 | 短句 | "跪下""你不配" |
| 暴怒时 | 热血台词 | "我上早八！""离开我的世界！" |
| 打斗中 | 嘲讽 | "太慢了""就这点本事？" |
| 打斗中 | 认可 | "好快的剑""不错" |
| 连招中 | 短促台词 | 连招第三击时低喝"斩"，第五击时嘲讽"太慢了" |
可结合角色背景，从原著中选取短句。要求短促有力，与招式对应，不尬。
对话中必须直呼角色名字，禁止用“主角”“对手”代称。
台词必须嵌入动作中，禁止用台词拖慢开头。
若角色说非中文台词，可保留原文，不加翻译（按用户要求）。
