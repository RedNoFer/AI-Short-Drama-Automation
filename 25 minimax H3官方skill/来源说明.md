## 官方安装命令（供需要独立安装时使用）

```bash
# 列出全部 Skill
npx skills add https://github.com/MiniMax-AI/MiniMax-H3 --list

# 安装全部 Skill
npx skills add https://github.com/MiniMax-AI/MiniMax-H3 --skill '*'

# 只装提示词 Skill
npx skills add https://github.com/MiniMax-AI/MiniMax-H3 --skill h3-prompt-writing
```

## 本目录的使用方式

官方 `h3-prompt-writing` 本身**不做路由，也不做本目录资产 ID 的映射**。本地分支见
[.agents/skills/minimax-h3-adapter/SKILL.md](../.agents/skills/minimax-h3-adapter/SKILL.md)，
索引条目为 E27，组合流程为 W17（见 `zhifeiji-workflow-router/references/workflows.md`）。

- 用户说「用 minimaxh3 / H3 结构 / 海螺 H3 的提示词」时，走 E27＋W17 分支。
- 8 个风格 Skill 面向 MiniMax Hub 的 canvas 工作流（`hub_generate_video` 等），不是通用 agent 流程；只在用户明确点名该风格时读取对应 `SKILL.md` / `SKILL.cn.md`。
