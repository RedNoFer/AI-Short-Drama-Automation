# ZHIFEIJI 电影感多视角资产

把一次图片上传变成一条完整资产流水线：先洗出电影感编辑提示词并编辑原图，再以通过验收的电影感主图为唯一视觉母版，生成三画面、五画面和九宫格三张多视角资产板。

## 必读资料

- 每次执行出图或提示词任务前，读取 [references/prompt-library.md](references/prompt-library.md)。
- 用户询问自定义 GPT 创建、名称、描述、对话开场、命令或上传文件时，读取 [references/gpt-setup.md](references/gpt-setup.md)。
- 需要理解内置演示的目标布局和验收结论时，读取 [references/demo-manifest.md](references/demo-manifest.md)；需要复查四张演示图实际使用的完整提示词时，读取 [references/demo-prompts.md](references/demo-prompts.md)。

## 默认交付

用户上传一张图片且没有限定模式时，默认执行 `/全套`：

1. 输出实际使用的电影感编辑提示词。
2. 基于上传原图生成一张电影感主图。
3. 输出三画面资产板提示词，并生成一张三画面资产板。
4. 输出五画面资产板提示词，并生成一张五画面资产板。
5. 输出九宫格资产板提示词，并生成一张九宫格资产板。

最终交付 `4张图 + 4条实际提示词`。三张资产板必须共同继承电影感主图，不得分别从原图重新设计。

如果用户说“只要三张”，解释为只生成三种多视角资产板；若当前对话还没有通过验收的电影感主图，先在内部完成电影化，但只展示用户要求的三张资产板。

## 命令

- `/全套提示词`：用户先上传场景原图并匹配本 Skill 后使用。先建立源图锁定卡，依次输出电影感主图、三画面、五画面和九宫格四套提示词，不实际出图。此时三套多视角提示词属于预制版；电影感主图真实生成并确认后，必须重新上传最终主图并使用 `/三种多视角提示词` 刷新后再正式出图。
- `/全套`：电影感主图 + 三画面 + 五画面 + 九宫格，默认模式。
- `/只洗提示词`：只输出电影感编辑提示词，不生成图片。
- `/只出电影主图`：输出提示词并只编辑一张电影感主图。
- `/三种多视角`：基于当前已确认主图生成三张多视角资产板。
- `/三画面`、`/五画面`、`/九宫格`：只生成指定版式。
- `/轻度`：只调曝光、色彩、材质、空气层次和克制成像，默认。
- `/标准`：额外允许调整景深、焦点层和局部环境反射。
- `/深度`：用户明确允许后才可改机位、天气、环境或叙事光线。
- `/隐藏提示词`：生成前不展示实际提示词。
- `/重做 电影主图|三画面|五画面|九宫格`：只重做失败项，其余成品和锁定卡不变。

用户使用 `/全套提示词` 时，严格按下面的意图执行：

```text
图1是场景事实原图。请先建立源图锁定卡，再依次输出：

1. 电影感主图编辑提示词
2. 三画面多视角提示词
3. 五画面多视角提示词
4. 九宫格多视角提示词

保持建筑拓扑、主体数量、地标位置、时刻、天气、材质和综合色不变。多视角阶段只允许改变摄影机位置，不要实际出图。
```

## 工具与执行规则

- 默认使用内置图片生成/编辑能力，不要求 API Key。
- 一致性出图必须垫图。电影感主图必须把场景原图作为编辑参考；三画面、五画面和九宫格每次调用都必须重新附上已经确认的电影感主图；修正漂移必须同时附上正确母版和失败图。
- 不能只发送提示词并依赖模型回忆上一张图。即使仍在同一对话，每个新的出图请求也要重新附上当前阶段的正确参考图。只贴提示词适用于风格构思，不适用于需要锁定主体、拓扑、地标、构图和材质的一致性资产生产。
- 在 ChatGPT 自定义 GPT 中，真实出图只能调用“图片生成 / 创建图片”能力。不得用 Code Interpreter、Python、PIL、Markdown 链接、附件路径或纯文本模拟图片生成结果。
- 每张成品必须单独发起一次图片生成或图片编辑调用，并等待聊天中实际出现可见图片后，才可标记该张完成；仅出现文件名或路径不算生成成功。
- 严禁把 `/mnt/data/*.png`、`sandbox:/mnt/data/*`、本地路径、虚构下载链接或四行文件名当作图片交付。遇到这类输出立即判定失败，不得重复发送同一批路径。
- 若当前会话没有可调用的图片生成能力，必须明确说明“图片生成能力未启用或不可用”，停止出图阶段并只交付提示词；不得声称已经生成图片。
- `/全套` 必须按“电影感主图 → 三画面 → 五画面 → 九宫格”串行执行。上一张可见图片尚未生成或未通过锁定验收时，不得继续下一张。
- 本地图片先用 `view_image` 按原始细节检查，再通过 `referenced_image_paths` 传入。
- 没有本地路径的会话图片使用最小必要的 `num_last_images_to_include`。
- 两种输入机制不得同时使用。
- 四张成品是四种独立资产；每张使用一次独立图片生成调用，不用一次调用代替四种资产。
- 每次生成后检查结果，再继续下一阶段。电影感主图未通过锁定检查时，不得用它继续制作三张资产板。
- 项目任务把最终成品复制进项目，使用版本化文件名，不覆盖旧结果。
- 当前环境不能出图时，仍按相同顺序交付四条可复制提示词，并明确说明未实际生成；不得输出任何虚构图片路径。

## 阶段一：检查原图

把上传图定义为 `SOURCE IMAGE` 和编辑底图，不是松散灵感图。建立源图锁定卡：

```text
SUBJECT LOCK：主体身份、数量、脸、身体、动作、服装、机械/产品结构。
OBJECT LOCK：道具、文字、Logo、损伤、污渍和状态。
SCENE LOCK：建筑、地形、主要地标、物体位置、时代和天气。
COMPOSITION LOCK：构图、透视、机位、裁切、画幅和主体比例。
ALLOWED CHANGES：本次电影化允许改变的项目。
FORBIDDEN CHANGES：其余全部不可改变。
```

只诊断真正影响电影感的 2–4 项：光源关系、曝光层次、综合色主次、材质真实性、空间纵深、焦点和成像克制。不要把电影感等同于黑边、青橙、蓝灰、死黑、重颗粒、强 Bloom 或 HDR。

## 阶段二：洗电影感提示词

默认使用轻度电影化。只执行以下允许项：

- 建立可解释的主光源和自然环境反射。
- 改善高光滚降、暗部可读性和曝光层次。
- 从场景、服装、天气和材质中提取主色、辅色和唯一强调色。
- 提升皮肤、布料、岩石、金属、玻璃、水面或建筑材料的真实响应。
- 增加克制的空气透视、局部景深、自然颗粒和非均匀锐度。
- 保留真实的不完美、轻微遮挡和局部失焦，降低摆拍、广告和 CG 概念图感。

必须在提示词开头明确：`Edit Image 1 directly. Image 1 remains the factual base.`

不得无授权换脸、换装、换动作、增减人物、替换背景、移动地标、改字、改 Logo、改比例、扩图、裁切或重新构图。

调用前默认先展示最终提示词；用户明确 `/隐藏提示词` 时才省略。

## 阶段三：验收电影感主图

对照原图检查：

- 主体、人数、脸、动作、服装和结构是否保持。
- 地标、物体位置、透视、裁切和画幅是否保持。
- 是否只改变已授权的电影摄影变量。
- 光源是否有来源，色彩是否来自环境，暗部是否仍可读。
- 是否降低塑料、过锐、游戏 CG、广告棚拍和统一滤镜感。

任一不可变项漂移时，回到原图作为编辑输入，只缩小失败变量重做；不要在错误结果上连续重绘。

## 阶段四：建立场景拓扑账本

从通过验收的电影感主图提取：

```text
SCENE IDENTITY：地点类型、尺度、时代、主要建筑或地形。
PRIMARY ANCHOR：最重要地标及位置。
SECONDARY ANCHORS：左、右、前景和背景地标。
GROUND PLAN：道路、圆环、通道、墙、平台和高差。
SUBJECT DISTRIBUTION：人物、雕像、车辆、机器的数量级、比例和区域。
SURFACE STATE：干湿、破损、烧灼、碎片、植被和反射。
LIGHT/WEATHER：光向、天气、雾、雨、雪、闪电和实景灯。
COLOR REGISTER：主色、辅色、强调色和曝光基线。
UNCERTAIN GEOMETRY：主图看不到的区域。
```

多视角是基于单图的保守空间推断，不是真实 3D 重建。对隐藏空间只作一个最小、可信的补全，并在三种资产板中复用同一补全。

## 阶段五：生成三张多视角资产板

三张资产板都把电影感主图写成 `sole scene master and geometry authority`。只改变摄影机位置，不改变时间、天气、灯光、综合色、材质、损伤、地标或固定主体分布。

### 三画面版

- 左上：忠实主视角。
- 左下：真实反向或对侧 3/4 视角，不是镜像。
- 右侧大图：高位斜俯全景，展示完整拓扑。
- 布局：左侧上下两张，右侧一张跨两行大图，黑色细分隔。

### 五画面版

- 左上：主视角。
- 左中：主轴升高广角。
- 左下：左侧高位 3/4。
- 右上大图：严格 90° 顶视，近正交。
- 右下大图：右侧高位或真实反向斜俯。
- 布局：左三右二，黑色细分隔。

### 九宫格版

- 主视角、真实反向、左 3/4、右 3/4。
- 左高位、右高位、贴地低机位、严格顶视、空中全景。
- 布局：准确 3×3 九个等尺寸格子，黑色细分隔。

禁止文字、编号、标签、Logo、水印、装饰拼贴、镜像地理、重复地标、随机增员和色调漂移。

## 质量门槛

最终交付前检查：

- 已交付一张电影感主图和三张多视角资产板，共四张。
- 每张图之前已展示对应实际提示词，除非用户要求隐藏。
- 电影感主图是对原图的编辑，不是相似重生成。
- 三张资产板只引用通过验收的电影感主图，不重新引用原图。
- 三、五、九格数量和非对称布局准确。
- 三种资产板描绘同一地点、同一时刻、同一综合色和同一隐藏空间推断。
- 主视角格可辨认地忠实于电影感主图。
- 反向视角不是水平镜像；顶视与斜俯、平视拓扑相容。
- 固定主体数量级、区域、地标顺序和距离没有明显漂移。
- 无额外人物、文字、标签、水印、装饰边框或多余面板。
- 所有项目成品已复制到项目内，原始生成文件未被删除。
