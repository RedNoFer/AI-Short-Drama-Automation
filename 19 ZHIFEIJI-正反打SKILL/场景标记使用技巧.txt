# 场景分角度标记法

### 适用场景

**当正反打两个角度看到的背景完全不同时**，必须分开标记：
- 例子1：女性面对大门 vs 男性背靠大门（看到的是门内侧）
- 例子2：A在室内看窗外 vs B在窗外看室内
- 例子3：A在台阶下仰视 vs B在台阶上俯视

### 操作步骤

#### 第一步：【参考图标记】分场景声明

```
【参考图标记】
@p1 = 正面场景(女性看到的背景：大门外侧+台阶向上+院子地面)
@p2 = 反打场景(男性看到的背景：大门内侧+台阶向下+院子向外)
@p3 = 现代女性(白色风衣...)
@p4 = 中年男性(灰色中山装...)
```

**命名规则**：
- `@p1/@p2` = 场景（环境/建筑）
- `@p3/@p4` = 人物
- `@p5/@p6` = 道具/武器（如果有）

#### 第二步：动作正文明确指定背景

```
镜头一(0-5s)正打女性:
@p3女性站在地面,背景@p1三级灰色石台阶从地面逐级升高,
台阶顶部是深色木质大门紧闭居中...

镜头二(5-10s)反打男性:
【反打锁定】@p4男性站在台阶顶部,背景@p2深色木质大门内侧木纹清晰,
@p2台阶的三级结构向下延伸...
```

**核心原则**：
- 正文里每次提到背景元素，都贴对应的`@p1`或`@p2`标签
- 确保空间逻辑一致（都是三级台阶，只是视角不同）
