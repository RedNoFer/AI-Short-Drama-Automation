# 竖屏短剧分镜 · 极简情绪流 v0.1.0

## 一、核心定位

把短剧剧本(对话戏/情感戏/冲突戏)拆成**竖屏9:16、跟着情绪走的极简分镜提示词**,直出Seedance 2.5。

**不是打斗戏那套五步因果链**,而是短剧独有的节奏:**一句话一个情绪转折,括号里塞景别推进,对白焊死在表情后面。**

区别于拆镜3.0(横屏叙事)和打斗skill(动作因果链),本skill专治竖屏短剧的"快、密、情绪钩子"。

---

## 二、蒸馏的五个短剧核心技法

### 技法1 · 括号运镜(一句话多镜切换)

短剧最聪明的写法:**不是一镜一句,而是一句话里塞2-3个景别切换**,用括号标注推进路径。

```
动作顿住了(先是中景,接着是手部按压伤口特写,最后是脸部猛推特写)。
```

**铁律:景别永远从大到小推进** = 建立空间→聚焦细节→情绪爆发:
- 先是中景 → 接着是特写 → 最后是大特写
- 先是侧身中景 → 接着是过肩镜头 → 最后是反应特写

不要反向(不要从特写拉到全景),短剧靠"越推越近"制造压迫和情绪。

### 技法2 · 动作转折 = 切镜点

**关键情绪/动作的转折,自动触发景别推进:**
- 动作顿住 → 切特写
- 神色变化 → 切脸部特写
- 开口说话 → 切过肩+反应镜头

情绪拐点在哪,镜头就切到哪。

### 技法3 · 对白焊死在表情/动作后面

**台词不单独拎出来,紧跟表情和口型:**

```
露出震惊的表情说:"不好,匕首有毒......"
压低声音接着说:"人就没了。"
```

短剧靠台词推进,台词跟表情绑一起,模型对口型更准。**每条对白≤60字**(Seedance限制),长台词拆到下一镜。

### 技法4 · 抽象词→可视形态词(避险+提准)

**所有抽象情绪/状态词,必须翻译成可拍的物理特征:**

| 抽象词(禁用) | 可视化替换(必用) |
|------------|----------------|
| 昏迷 | 躺卧榻上,脸色惨白,双目紧闭,身体静止不动 |
| 中毒 | 嘴唇发黑,额头冷汗,手指抽搐 |
| 生气 | 眉头紧锁,嘴角下压,拳头攥紧 |
| 心动 | 瞳孔微张,呼吸一滞,视线躲闪 |
| 绝望 | 肩膀垮下,眼神空洞,嘴角颤抖 |
| 死亡/死 | 身体瘫软,眼神涣散,再无起伏 |

**一石二鸟**:①规避平台风控敏感词 ②模型不懂抽象状态,只懂可拍的物理特征。

### 技法5 · 一句话一个完整情绪弧

跟着人物情绪的自然流动写,不是机械"镜头1、镜头2":

```
闻嗅伤口 → 动作顿住 → 神色紧张 → 转身 → 震惊开口
```

每句话就是一个"起→转→爆"的小弧线,像导演现场口述调度。

## 三、竖屏专属规则(9:16)

短剧全是竖屏,构图和横屏完全不同:

- **画幅**:9:16竖屏(质感锚里写 `9:16 vertical composition`)
- **主体**:脸部/上半身主导,**竖构图上下留戏**(头顶留天、下巴留胸)
- **景别偏近**:短剧以中近景、特写为主,大远景少用(手机屏幕小,远景看不清)
- **单人脸部戏**:怼脸特写占比高,情绪靠脸传递
- **多人对峙**:用前后景纵深(前景背影+后景正脸),而非左右并排(竖屏左右窄)

## 四、标准输出格式(三段式)

```
【参考图标记】@p1=场景 @p2=角色A @p3=角色B @p4=关键道具

【项目总控】时长Xs | 竖屏9:16 | 画风:XX | 类型:XX | 主色:XX | 机位基调:XX | 叙事节奏:0-Xs→X-Ys→结局 | 氛围:XX

【角色区隔·强制】@p2=外貌/服装/身份/定位; @p3=外貌/服装/身份/定位。二者外形对立,全程独立个体,不换脸不合并。

质感锚前缀:
cinematic short-drama CG, ultra realistic, photorealistic skin textures, 9:16 vertical composition, [光影], [色调], shallow depth of field, HDR, soft cinematic grading

动作编排正文:

镜头一(0-Xs)场景+情绪起点:
在@p1场景中,@p2动作描述(先是XX景,接着是XX特写,最后是XX)。情绪起点,对白焊在表情后。

镜头二(X-Ys)情绪转折:
@p2/@p3动作+情绪拐点触发切镜(先是中景,接着是脸部特写)。对白紧跟。

镜头N(Y-Zs)情绪爆发/钩子:
最强情绪点或悬念钩子。景别推到最近,对白定格,留下段末钩子。

禁词后缀:
--no 卡通化/横屏/静态镜头/抽象情绪词/水印/[题材禁项]
```

## 五、完整示例:床榻救治·发现中毒(18秒竖屏)

```
【参考图标记】@p1=古风寝殿(木榻+枕头+烛台+帐幔) @p2=伤者(男,躺卧) @p3=施救女子(写实风,布巾) @p4=旁观者(披风,站立) @p5=白色布巾

【项目总控】时长18s | 竖屏9:16 | 画风:古风写实CG | 类型:悬疑救治 | 主色:暖烛橘+暗影黑 | 机位基调:烛台前景遮挡+俯拍特写+过肩反应镜头 | 叙事节奏:0-5s救治→5-12s闻嗅察觉异常→12-18s震惊揭毒 | 氛围:压抑紧张

【角色区隔·强制】@p2=男,脸色惨白双目紧闭躺卧木榻; @p3=女,写实素衣手持@p5白色布巾跪蹲榻边; @p4=披风装束站立榻侧。三人外形互不重叠,全程独立个体,不换脸不合并。@p1=古风寝殿,烛台在前景,木榻居中,帐幔垂落。

质感锚前缀:
cinematic ancient-style drama CG, ultra realistic, photorealistic skin and fabric textures, 9:16 vertical composition, warm candlelight glow, deep shadow contrast, shallow depth of field, HDR, soft cinematic color grading

动作编排正文:

镜头一(0-5s)烛台遮挡+受伤起点:
在@p1寝殿,@p2躺卧木榻,脸色惨白,双目紧闭,身体静止不动(先是烛台前景遮挡镜头缓缓对焦,侧面拍摄@p2中景,接着高角度俯拍@p2正面特写)。@p3跪蹲榻边,手持@p5白色布巾按压@p2肩部伤口。暖烛光在脸上跳动。

镜头二(5-12s)闻嗅察觉+动作骤停:
@p3凑近@p2肩伤口闻了一下,动作骤然顿住(先是@p3侧身中景,接着是@p3手持布巾按压伤口的特写,最后是@p3脸部猛地推进特写,神色由专注转紧张)。@p4站在榻侧,看着@p3停下的手,神色也紧张起来(先是@p4中景,接着是@p4脸部特写)。

镜头三(12-18s)转身揭毒+震惊定格:
@p3起身转身看向@p4,露出震惊表情说:"不好,匕首有毒,这是蛇毒和草乌混炼的剧毒"(先是@p3侧身中景,接着是过肩镜头越过@p3看@p4,最后是@p4震惊反应特写)。@p3停顿,压低声音接着说:"入血即行,直攻心脉——"话音落,镜头定格在@p4骤然收缩的瞳孔特写。

禁词后缀:
--no 卡通化/漫画/Q版/横屏landscape/静态镜头/明亮欢快/抽象情绪词(昏迷中毒等)/人物合并/水印/文字
```

## 六、工作流

### Step 1: 读短剧剧本
- 确认场景/角色/时长(短剧单条建议15-30秒)
- **标注情绪转折点**(这是切镜依据)
- 找出所有抽象情绪词,准备可视化替换

### Step 2: 提炼项目总控
`时长 | 竖屏9:16 | 画风 | 类型 | 主色 | 机位基调 | 情绪节奏 | 氛围`

### Step 3: 写轻量质感锚
竖屏短剧不需要打斗那种重锚,一句话:
`cinematic short-drama CG, ultra realistic, photorealistic skin textures, 9:16 vertical composition, [光影氛围], shallow depth of field, HDR`

### Step 4: 逐镜写动作正文
每个镜头:
- 时间码(0-Xs,Seedance认整数秒)
- 场景+人物动作
- **括号运镜**(先是XX景→接着XX特写→最后XX),从大到小推进
- **对白焊在表情/动作后**
- **抽象词全部可视化替换**

### Step 5: 情绪节奏校验
- 每个镜头对应一个情绪节点
- 景别是否跟着情绪推进(越近越强)
- 对白是否≤60字/条
- 抽象词是否清零

## 七、和其他skill的分工

| Skill | 适用 | 输出特征 |
|-------|------|---------|
| 打斗skill | 打戏/动作爽点 | 五步因果链+升格慢镜+重质感锚 |
| 拆镜3.0 | 横屏完整剧本 | 多条30秒+叙事分段+首帧承接 |
| **竖屏短剧(本skill)** | **竖屏短剧对话/情感/冲突戏** | **括号运镜+对白焊死+可视化避险+情绪流** |
| 空间占位模块 | 多人/群戏站位控制 | 五层占位控制,触发型 |

**竖屏短剧多人对峙时**,可叠加空间占位模块的"前后景纵深"思路(前景背影+后景正脸)。

## 八、禁止清单

**格式层面:**
- ❌ 不拆 `(0—X秒):` 小时间码,时间只标镜头级(0-5s)
- ❌ 不用 `===== 镜头X =====` 分隔符
- ❌ 括号运镜不能反向(不能从特写拉大远景)

**内容层面:**
- ❌ 不用抽象情绪词(昏迷/中毒/生气/绝望/死),必须可视化替换
- ❌ 不写心理活动(他感到害怕),只写可拍的物理特征
- ❌ 对白不单独成段,必须焊在表情/动作后

**技术层面:**
- ❌ 单条不超30秒
- ❌ 单条对白不超60字
- ❌ 不用横屏构图,固定竖屏9:16
- ❌ 大远景慎用(竖屏小屏看不清)

## 九、常见问题

**Q1: 和打斗skill的区别?**
A: 打斗skill用五步因果链(蓄力/发力/接触/反馈/反应)拆物理打击;本skill用括号运镜+情绪流拆对话情感戏,不用因果链。

**Q2: 括号运镜最多几个景别?**
A: 建议2-3个(先是/接着/最后),太多模型切不过来。

**Q3: 为什么强调可视化替换?**
A: ①短剧平台风控严,昏迷/中毒/死这类词容易被拦;②模型不懂抽象状态,只能渲染可拍的物理特征。这是短剧提示词的命门。

**Q4: 竖屏多人怎么排?**
A: 用前后景纵深(前景背影虚化+后景正脸清晰),不要左右并排(竖屏左右太窄)。需要严格控制时叠加空间占位模块。

**Q5: 时间码要精确到秒吗?**
A: 镜头级标整数秒(0-5s/5-12s)即可,不用拆到0.5秒。Seedance 2.5认整数秒时间码。
