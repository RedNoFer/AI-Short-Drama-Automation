ZHIFEIJI 模型三视图设定板 SKILL v1.2
使用说明

一、用途

本 Skill 用于把用户上传的一张或多张模型参考图，整理并生成一张专业的“模型三视图技术设定板”。

适用主体包括：

- 科幻机甲、机器人
- 载具、飞船、武器、装甲
- 怪兽、生物模型、雕塑
- 产品模型、游戏模型、影视道具
- 建筑、机械设备和其他可展示结构的实体模型

本 Skill 的输出是技术设定板，不是普通概念图，也不是战斗场景图。

重要边界：

- 人物、类人角色、异形人物或机械人体，如果用户要求“左侧脸部特写 + 右侧正面/侧面/背面”的干净人物身份板，应改用人物三视图模式。
- 不要把人物身份板套用本 Skill 的尺寸标尺、五个细节框和规格表版式，除非用户明确要求技术设定板。

二、最简单的用法

1. 上传一张或多张模型参考图。
2. 不需要重复描述图片中的结构，系统会自动识别主体。
3. 直接说“做三视图”“生成模型设定板”或只上传图片即可。
4. 系统按标准版式生成三视图技术设定板。

推荐用户指令示例：

- “按这个模型做一张三视图技术设定板。”
- “直接生成正面、侧面、背面和细节框。”
- “把这个飞船做成技术蓝图风格三视图。”
- “按原图做，不要改结构，不要战损。”
- “武器单独展示，保留原模型颜色和材质。”

三、默认输出内容

标准设定板默认包含：

1. FRONT 正视图
2. SIDE 侧视图
3. BACK 背视图
4. HEIGHT 高度或比例尺区域
5. 5 个局部细节放大框
6. 底部基础规格表
7. 标准人形或比例物体参照
8. 简洁技术蓝图背景

默认画幅为 16:9 横向。用户要求宽幅时可以改为 21:9。推荐最终分辨率为 3840 x 2160。

四、三视图的严格要求

FRONT 正视图：

- 展示完整正面。
- 镜头与主体中心或胸口结构等高。
- 保持中性、静止、无夸张动作。
- 主体底部落在统一基准线上。
- 武器、盾牌和背包不能遮挡主体主要结构。

SIDE 侧视图：

- 默认使用左侧视图。
- 用户明确要求右侧时才改成右侧视图。
- 必须是真正的 90 度侧面，不能是三分之二角度。
- 展示主体厚度、前后结构、背包、尾翼和附件挂载关系。

BACK 背视图：

- 完整展示背部结构。
- 保留推进器、背包、机械骨架、尾翼和武器挂点。
- 与正视图使用同一高度、同一比例和同一材质。
- 不能减少、增加或替换核心零件。

三个视图必须像同一个实体模型在同一摄影棚转台上拍摄：

- 等高
- 等比例
- 底部对齐
- 颜色一致
- 材质一致
- 零件一致
- 武器和附件位置逻辑一致

五、隐藏结构怎么处理

当参考图只显示一个角度时，按以下原则补全：

1. 优先依据可见结构进行保守推导。
2. 左右对称机体按对称逻辑补全。
3. 非对称装备必须保留在对应一侧。
4. 不凭空增加大型武器、翅膀、炮管、推进器或装甲。
5. 背部不可见时，只根据肩部、腰部、侧面和连接结构合理延伸。
6. 推导部分必须服从原模型的设计语言、材质和结构层级。
7. 不得把原模型改成另一款机甲、车辆、角色或产品。
8. 不确定的区域宁可简化，也不要虚构复杂结构。

六、标准版式

左侧主展示区约占画面 80%，依次排列：

- FRONT
- SIDE
- BACK

左上角设置 HEIGHT 区域：

- 用户提供真实高度时，严格使用用户数据。
- 用户没有提供尺寸时，使用 ESTIMATED SCALE、N/A 或视觉比例。
- 禁止编造精确高度、重量、功率和射程。

右侧细节栏约占画面 20%，竖向排列 5 个放大框：

1. 头部、驾驶舱或前端传感器
2. 胸部、核心结构或主动力区域
3. 盾牌、徽章、纹章或最具辨识度的装甲
4. 武器、机械手、轮组、引擎或功能组件
5. 背包、推进器、尾部或动力结构

细节框使用编号 1 至 5，并在框下使用简洁英文功能标签。所有细节框必须保持与主视图相同的颜色、材质和灯光。

底部规格表分为左右两组：

左侧字段：

- MODEL NUMBER
- TOTAL HEIGHT
- WIDTH
- WEIGHT
- MATERIAL

右侧字段：

- POWER OUTPUT
- PROPULSION
- SENSOR RANGE
- ARMAMENTS
- SPECIAL EQUIPMENT

未知数据统一填写 N/A。不要为了让表格看起来完整而虚构精确军用参数。

底部加入一个标准人形剪影或比例物体，用于说明模型尺寸关系。

七、材质和状态

自动识别并保留参考图中的真实材质，例如：

- 金属、塑料、树脂、陶瓷
- 布料、生物皮肤、木材、石材
- 玻璃、碳纤维和其他复合材质

默认模型状态为：

- 完整
- 干净
- 无战损
- 无严重刮痕
- 无锈蚀
- 无污泥
- 无火花
- 无烟雾
- 无战斗场景

只有用户明确要求战损、旧化、锈蚀或损坏时，才添加这些效果。

八、装甲表面完整性

这是本 Skill 的强制要求。

默认规则：

- 单块装甲板内部必须连续、平滑、完整。
- 大面积装甲使用干净的大形面、柔和渐变和克制高光。
- 细节集中在真实零件边界、关节、铰链、通风口、紧固件、推进器开口和发光骨架开口。
- 参考图中的裂纹、草图线、旧化笔触和随机细线，默认视为画面噪声，不继承为模型结构。

允许保留的结构线必须满足：

1. 位于两块独立零件之间。
2. 有明确的凹槽、厚度或前后层级。
3. 合理终止于零件边缘、关节、开口或连接点。
4. 在 FRONT、SIDE、BACK 中位置和走向一致。

必须删除的缺陷线包括：

- 单块装甲内部的斜线
- 分叉线、交叉线和蜘蛛网状线
- 无结构目的的随机折线
- 从装甲中部开始或结束的悬空细线
- 密集平行微分件线
- 陶瓷龟裂、干涸泥土、龟裂漆面和玻璃裂纹
- 为了增加细节而生成的高频刻线和假接缝

一块大装甲面默认不添加内部刻线。只有参考图明确显示且具备结构功能时，最多保留一条简洁功能分件线。

九、摄影和渲染要求

- 平视正交视图感
- 85mm 至 120mm 等效长焦
- 中性摄影棚灯光
- 柔和顶部主光
- 两侧轮廓光
- 适度金属高光
- 稳定阴影
- 三个视图全部清晰
- 局部细节框内结构清晰
- 不使用夸张广角
- 不使用低角度英雄仰拍
- 不使用景深虚化
- 不使用动态姿势

整体风格应接近高端影视美术、游戏工业设计部门或实体模型开发部门的正式技术板。

十、文字和排版

画面文字必须：

- 清晰
- 简洁
- 使用统一英文技术标签
- 无乱码
- 不遮挡模型
- 不出现平台 Logo
- 不出现水印
- 不出现无关品牌

推荐使用 condensed sans serif、technical grotesk 或工业 UI 风格字体。

如果图像模型无法稳定生成大量文字，优先保证三视图、编号、版式和模型结构正确；文字区域保持简洁，不要生成乱码。

十一、常用修改指令

用户说“重新生成”：

- 保持主体、材质、颜色和结构不变。
- 只修正版式、视图一致性、文字、细节框或角度问题。

用户说“不要战损”：

- 恢复完整、干净、无锈蚀、无裂痕的模型表面。

用户说“不要皲裂”：

- 删除单块装甲内部的斜线、分叉线、交叉线、随机刻线和密集微分件。
- 只保留真实独立零件之间的结构边界。

用户说“改成 21:9”：

- 只调整画幅和版式比例，不改变主体结构。

用户说“右侧视图”：

- 将 SIDE 改为严格右侧视图，其余视图和结构不变。

用户说“不要规格表”：

- 删除底部规格信息区，保留三视图和细节框。

用户说“细节框改成 6 个”：

- 将右侧细节栏改为 6 个框，编号连续，其余版式保持稳定。

用户说“加身高 25.6m”：

- 只在 HEIGHT 或 TOTAL HEIGHT 区域写入 25.6m。

用户说“武器单独展示”：

- 将武器加入局部细节框或附件展示区。
- 不改变主体持握关系和三个主视图的身份一致性。

十二、质量检查清单

出图后逐项检查：

[ ] 是否只有一个主体模型
[ ] 是否严格参考用户上传图片
[ ] FRONT、SIDE、BACK 是否为同一模型
[ ] 三个视图是否等高、等比例、底部对齐
[ ] SIDE 是否为真正侧面
[ ] BACK 是否保留背部主要结构
[ ] 武器、盾牌和附件位置是否一致
[ ] 是否有 5 个细节框
[ ] 是否有尺寸或比例区域
[ ] 是否有底部规格表，或按用户要求删除
[ ] 是否有比例参照
[ ] 是否无未经要求的战损、锈蚀、污泥和烟雾
[ ] 每块大装甲面是否连续、平滑、完整
[ ] 是否没有装甲板内部随机斜线、裂纹和蜘蛛网状线
[ ] 分件缝是否只位于真实独立零件之间
[ ] FRONT、SIDE、BACK 的结构边界是否一致
[ ] 是否无多余人物、背景物和场景
[ ] 是否无乱码、无水印、无平台 Logo
[ ] 是否清晰、干净、专业

任何一项不合格，都应先修正再交付。发现装甲板内部裂纹状线条时，只清除裂纹、随机刻线和过密微分件，其他造型、配色、视图和版式全部锁定。

十三、推荐执行话术

用户只上传图片时：

“已识别模型，正在按标准三视图技术设定板生成。”

用户要求提示词时，输出：

1. 主体识别摘要
2. 完整可复制出图提示词
3. 标准禁止词
4. 推荐画幅和分辨率

用户要求出图时，直接生成，不反复追问。尺寸未提供时，不编造精确数据，使用 N/A、ESTIMATED 或视觉比例。

十四、文件管理建议

- 原始 Skill 文件：ZHIFEIJI_模型三视图设定板_SKILL_v1.2.md
- 本使用说明：ZHIFEIJI_模型三视图设定板_使用说明.txt
- 生成图片建议使用连续编号和清晰文件名。
- 不覆盖已有成图；重做版本使用新的编号或 v2、v3 后缀。
- 最终文件应保存到项目指定的输出文件夹，而不是只留在临时预览或浏览器缓存中。

十五、一句话记忆

上传模型图，锁定原始结构，生成 FRONT / SIDE / BACK 三视图，加尺寸区、5 个细节框、规格表和比例参照；不确定的数据写 N/A，不要擅自改设计，不要用裂纹和随机刻线制造“高细节”。
