# ZHIFEIJI 小说转剧本：Skill 使用说明

## 功能定位

`adapt-novel-to-short-drama` 用于把用户提供或有权使用的小说、章节、故事梗概改编为竖屏短剧。它支持故事档案、分集规划、剧情梗概、可拍摄剧本、AI视频分镜和格式质检。

## 默认行为

- 改编模式：忠实改编。
- 输出模式：拍摄剧本。
- 单集时长：1–2分钟。
- 单集场景：最多5场，优先2–3场。
- 台词：短、直接、可表演；15字是节奏建议，不是绝对上限。
- 心理描写：优先转成动作、表情、道具、环境反应或台词。
- 结尾：设置能自然启动下一集的因果钩子。

## 调用方法

在 Codex 中显式调用：

```text
使用 $adapt-novel-to-short-drama，把我提供的小说改成10集竖屏短剧拍摄稿。
```

也可以直接提出符合描述的任务，Codex 会自动判断是否调用 Skill：

```text
把这段小说改成一集90秒的竖屏短剧。
先分析这部长篇小说的人物、主线和伏笔，再规划60集。
把第3集拍摄稿转换成AI视频分镜。
检查这份短剧是否存在场序、闪回和长台词问题。
```

## 两种改编模式

### 忠实改编 `faithful`

保留核心人设、人物关系、主线冲突、情感走向、关键反转和用户指定名场面。允许合并重复支线、提前冲突、压缩场景以及把心理描写影视化。

### 重构改编 `reimagined`

只保留用户指定的主题、情感内核或高层故事机制，重建人物、关系、时代、地点、世界规则、冲突路径和结局。该模式不等于对无侵权或平台过审作法律保证。

## 四种输出模式

| 模式 | 用途 | 主要格式 |
|---|---|---|
| `synopsis` | 单集纯剧情梗概 | 默认650–800个非空白字符，不带场序和人物前缀 |
| `episode-plan` | 多集结构规划 | 核心事件、目标、阻碍、升级、反转、钩子、场景、伏笔 |
| `shooting-script` | 演员排练和直接拍摄 | 场序、`△`动作、人物台词、字幕、必要的OS和闪回 |
| `ai-storyboard` | 文生视频或图生视频 | 拍摄剧本结构加景别、主体、动作、情绪和连续性 |

## 推荐输入模板

```text
任务：小说改竖屏短剧
改编模式：忠实改编 / 重构改编
输出模式：分集规划 / 剧情梗概 / 拍摄剧本 / AI分镜
计划集数：
单集时长：
题材与情绪：
必须保留：
允许调整：
目标平台：
原文或附件：
```

没有填写的项目按默认参数执行。会显著改变结果的信息缺失时，助手应先询问。

## 长篇小说推荐流程

```text
读取小说
→ 建立人物、关系、时间线和伏笔档案
→ 确定全剧主线与阶段
→ 输出分集规划
→ 审核分集
→ 逐集生成拍摄稿
→ 每集完成后回写连续性状态
→ 完稿质检
```

不要要求模型一次性输出几十集完整剧本。推荐先审核故事档案和分集规划，再按5–10集一批生成。

## 剧本格式摘要

```text
场3-2日/内 体育馆 主要人物：张三、李四
△张三推门进入体育馆，停在李四身后。
张三（压低声音）：你为什么骗我？
```

- 动作或环境描述以 `△` 开头。
- 台词使用“人物名：台词”。
- 闪回使用成对的 `【闪回】`、`【闪回结束】`。
- 人物首次或第二次出现时使用身份字幕。
- 普通拍摄稿不强制写镜头标签；AI分镜模式才添加景别和运镜。

## 格式校验

需要 Python 3.10 或更高版本。项目内运行示例：

```powershell
python ".agents/skills/adapt-novel-to-short-drama/scripts/validate_screenplay.py" "output.txt" --profile shooting-script
```

外部包中运行示例：

```powershell
python "Codex-Skill/adapt-novel-to-short-drama/scripts/validate_screenplay.py" "output.txt" --profile shooting-script
```

可选模式：`synopsis`、`episode-plan`、`shooting-script`、`ai-storyboard`。错误必须修复；长台词警告需要结合剧情判断。

## 注意事项

- 只处理用户提供、自有、获授权或公共领域素材。
- 不承诺“100%原创”“绝对过审”或“完全无侵权”。
- 用户指定具体平台及“最新规则”时，应查询该平台当前官方规范。
- 自动脚本只能检查确定性格式，人物动机、反转质量和情绪强度仍需语义审查。
