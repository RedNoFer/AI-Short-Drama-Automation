# ZHIFEIJI 小说转剧本：ChatGPT 配置说明

## 配置总览

### 名称

```text
ZHIFEIJI 小说转剧本
```

### 描述

```text
将小说、章节或故事梗概改编为高节奏、强冲突、可拍摄的竖屏短剧，支持忠实改编、深度重构、故事档案、分集规划、拍摄剧本和AI视频分镜。
```

### 指令

复制 `03-ChatGPT完整指令.txt` 的全部内容，粘贴到 GPT 编辑器的 Instructions 字段。

### 开场对白

ChatGPT 的 GPT 编辑器把这类入口称为 Conversation starters。复制 `04-开场对白与快捷命令.md` 中的“对话开场建议”。助手欢迎语已经写入完整指令，会在用户打招呼或未提供任务时使用。

## 创建步骤

1. 在 ChatGPT 网页端打开 GPTs 区域并选择“创建”。
2. 进入直接配置视图。
3. 填写名称和描述。
4. 把 `03-ChatGPT完整指令.txt` 粘贴到 Instructions。
5. 添加4条 Conversation starters。
6. 上传 `ChatGPT知识库` 文件夹中的6份Markdown文件。
7. 如需自动格式检查，再上传 `可选工具/validate_screenplay.py`。
8. 开启建议能力并在预览区执行测试。
9. 保存为“仅自己可见”先试用，验证稳定后再按需共享。

OpenAI 当前把名称、描述和对话开场建议定义为用户可见字段，把行为和工作流放在 Instructions，把参考材料放在 Knowledge。配置完成后应在预览区测试。[OpenAI 官方说明](https://help.openai.com/en/articles/8554397-use-advanced-data-analysis-in-chatgpt)

## 建议能力

| 能力 | 建议 | 用途 |
|---|---|---|
| Web Search | 开启 | 用户要求具体平台最新审核规则时查询官方来源 |
| Code Interpreter & Data Analysis | 开启 | 读取长文本、统计字数、运行可选校验脚本 |
| Canvas | 可选 | 编辑长篇分集规划和剧本 |
| Image Generation | 默认关闭 | 小说改剧本本身不需要；制作角色图时再开启 |
| Apps / Actions | 不需要 | 当前版本不依赖外部服务 |

## Knowledge 上传清单

上传以下文件：

1. `adaptation-modes.md`：忠实改编、重构改编和故事档案。
2. `short-drama-rules.md`：单集结构、冲突、台词和影视化原则。
3. `output-profiles.md`：四种输出模式的边界。
4. `screenplay-format.md`：场序、动作、台词、字幕、OS和闪回格式。
5. `quality-rubric.md`：完稿质量量表。
6. `compliance-baseline.md`：来源、内容和发布前检查基线。

规则、优先级和工作流程已经写进 Instructions；这些知识文件用于补充细节，不应代替 Instructions。

## Conversation starters

建议填写：

```text
把我上传的小说按忠实改编模式规划成60集竖屏短剧。
把这段小说改成一集90秒、可直接拍摄的剧本。
先为这部长篇建立人物档案、主线、时间线和伏笔表。
把这份拍摄稿转换成逐镜头AI视频分镜。
```

## 预览测试

至少测试以下情形：

1. 未指定参数：应采用忠实改编、拍摄剧本、1–2分钟默认值。
2. 明确选择重构：应重建人物动力、世界环境、冲突路径或结局中的至少三个层面。
3. 要求纯剧情梗概：不得输出场序、人物名前缀和镜头标签。
4. 要求拍摄稿：动作必须以 `△` 开头，台词必须使用人物名加冒号。
5. 长篇小说：应先建立故事档案和分集规划，不应直接一次性生成全部剧本。
6. 要求某平台最新规则：应先搜索该平台官方来源，并说明检索日期。

## 外部使用限制

- 创建或编辑自定义 GPT 通常需要支持该功能的付费方案或工作区权限；使用和共享范围也可能受工作区策略限制。
- GPT 不应声称已经获得小说授权，也不能保证绝对过审或完全无侵权。
- 自定义 GPT 的对话不会自动继承其他会话中的故事档案。长篇项目应在同一会话持续工作，或让助手导出并在新会话重新上传故事档案。
