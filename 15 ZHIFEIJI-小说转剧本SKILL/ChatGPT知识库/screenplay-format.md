# 拍摄剧本格式

## 场序

每个拍摄场景使用：

```text
场[集数]-[场号][时间]/[内外] [地点] 主要人物：[人物1]、[人物2]
```

时间使用 `日`、`夜`、`晨` 或 `昏`；空间使用 `内` 或 `外`。

```text
场3-2日/内 体育馆 主要人物：张三、李四、王五
```

一集最多5场，场号从1连续递增。地点变化或明显时间跳跃通常需要新场；同一空间内的连续动作不要无意义拆场。

## 动作与场景描述

除台词、场序和独立控制标记外，每条动作或环境描述以 `△` 开头：

```text
△沈知初攥紧病例报告，推开天台铁门。
△她咳嗽两声，掌心沾着血。
```

同一行如果主体内容是动作后接短字幕，仍以 `△` 开头。不要在动作描述中夹入带引号的完整对白。

## 台词与表演提示

使用人物名加全角冒号：

```text
医生：检查结果出来了。
沈知初（压住咳嗽）：还有多久？
```

把与说话同步且必要的动作或情绪放在人物名后的全角括号中。复杂动作另写为 `△` 动作行。避免“愤怒地、伤心地”等空泛提示，优先写能表演的行为。

## 人物首次出场字幕

在人物首次或第二个画面出现时标注：

```text
△沈知初推门进入诊室。【字幕：沈知初，厉家夫人】
```

不要为已经介绍过的人物重复添加身份字幕，除非剧情需要揭示新身份。

## OS

优先把心理活动转成动作或台词。确有必要时使用：

```text
沈知初内心OS：原来他早就知道。
```

OS不得重复观众已经从画面和台词明确得知的信息。

## 闪回

闪回必须成对，并在内部使用独立场序：

```text
【闪回】
场1-2日/内 诊室 主要人物：沈知初、医生
△医生把病例报告推到沈知初面前。
医生：情况不乐观。
【闪回结束】
```

## AI分镜标签

仅 `ai-storyboard` 模式使用独立镜头标签，例如：

```text
【特写】沈知初指节发白，病例纸边被捏皱。
【近景·缓慢前推】她抬眼看向紧闭的诊室门。
```

景别和运镜必须服务信息强调；普通拍摄剧本不强制添加镜头标签。
