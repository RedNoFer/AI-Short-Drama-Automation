# 快速档机检与合评契约

## 一条命令

```bash
python3 .agents/skills/fast-drama-workflow/scripts/fast_gate.py <作品目录>/精简制作包.md [--novel <小说原文>] [--json]
```

内部串联三个完全体校验器（不复制其逻辑），任何一个环节自身报错（脚本缺失/参数错）都算硬错，先修环境：

1. `validate_compact_package.py <包> --model wan30`——结构硬错：时间轴、绑定、字符上限、四段结构、`【参数】`拦截、声线锁定缺失、**单段固定 30 秒**（继承 [model-branch-matrix](../../short-drama-workflow/references/model-branch-matrix.md) 2026-11-06 用户指令硬规范，非快速档自有规则）等；
2. `audit_wan30_antipatterns.py <包> --json`——反例模式：站排/五人同框、静物/空镜超时、字条可读风险、慢镜、暖光词；
3. `validate_novel_coverage.py <包> <小说>`——原文覆盖（未给 `--novel` 时标 SKIP 并在交付说明里注明）；
4. **站位交叉校验**（2026-11-07 起必跑）：包旁 `内部/04b-站位图` 存在时自动挂 `--space-dir` 核对站位增量与正文；命中风险闸门却未建站位目录且输入单未登记「站位层：豁免」＝硬错——站位类穿帮（站位错/重复/分身）第一道门。

本地预检（fast_gate 第 0 步）：实现已登记规则的存在性机检——
1. R39／TEXT-03：含台词或心声的提示词块缺 `画面文字纪律：` 统一句即为硬错；
2. **否定写法纪律**（[wan30-adapter §4.2 第 7 块](../../short-drama-workflow/references/wan30-adapter-v1.0.md)）：视频/图片提示词正文出现「不在画面／不入画／不出镜／未出镜」类具象名词否定句即为硬错（改正向白名单；被排除物来自参考图时改图不改字）。
3. **美术推导门**（2026-11-08 用户指令）：包旁输入单存在时，缺「美术推导」登记行即为硬错——C0 前置门的机器闸口（规范见 [art-direction-derivation](../../short-drama-workflow/references/art-direction-derivation.md)）；输入单不存在则 SKIP 并在交付说明注明。
误报以合评裁定，规则本体仍归完全体（待其校验器回填后移除本预检）。

输出两栏：

- **硬错**：必须修复，修完重跑整条命令，秒级迭代；硬错清零前不得合评、不得交付；
- **风险**：按类型合并为一句话结论（如 `group_shot_budget ×2`）；改了就跑，不强制清零，合评第 10 项核对处置理由。

## 合评清单（硬错清零后，1 个评审员通读 1 遍）

| # | 检查项 | 一行结论要求 |
|---|---|---|
| 1 | 剧情忠实 | 关键事件/责任/结果/线索逐段在场；台词逐字不改 |
| 2 | 人物进出 | 画内外声明与参考绑定一致；没有无绑定出场 |
| 3 | 空间连贯 | 相机侧/朝向/出入口逐段接上段【收尾】；正文内嵌三行站位与相邻段不打架；站位增量与正文经交叉校验（已建站位目录时） |
| 4 | 道具链 | 获取点先于出现、状态连续、去向有交代；**出镜即绑定——入口/正文出镜的可移动商品必须已绑 PROP 参考并与资产口径一致（出镜未绑＝产品不一致/变形第一根因）；固定陈设与纯台词提及除外** |
| 5 | 台词与声音 | 归属正确、声线锁定只列实际发声者、画外/听筒标注一致 |
| 6 | 表演层 | 微表情线索 1–2 个/镜不堆砌；抽象情绪词换成可见线索 |
| 7 | 一致性 | 三锚跨段逐字一致；服装变体/状态变体绑定正确 |
| 8 | 节奏观感 | 通读一遍：切点不突兀、无超长静态拍（机检已拦结构，人看观感） |
| 9 | 资产口径 | 同一角色/道具/服装跨段不冲突（CHAR_06 类三类口径错配） |
| 10 | 导入字段与风险处置 | 绑定行正确、正文无 `@ImageN`、无 `【参数】`；每个未清零风险有处置理由 |
| 11 | 美术推导核对（2026-11-08 新增） | 着装规范/场景符号与题材一致，资产卡服装/饰件/场景元素逐条回指 `内部/01-美术推导.md`；题材带着装规范时统一元素与对照变体已先设计（实机反例：校园题材漏校服） |
| 12 | 密度抽查（2026-11-08 新增） | 逐镜五要素覆盖、对标逐镜 600–900 字符、单段不超 18000 上限；空泛修饰与"堆细节"同属不合格 |

判定引用 [prompt-review 严重度口径](../short-drama-workflow/references/prompt-review.md)；**合评结论直接落成正文修订，不写评审批次文档、不落逐项 JSON**。第 3 空间连续与第 4 道具链是快速档相对完全体最弱的环节——多线并行、5 集以上长剧或道具链复杂的项目别用快速档（2026-11-07 起站位经 SCENE_JSON 交叉校验后已收口，道具链复杂仍建议完全体）。
