# 快速档机检与合评契约

## 一条命令

```bash
python3 .agents/skills/fast-drama-workflow/scripts/fast_gate.py <作品目录>/精简制作包.md [--novel <小说原文>] [--json]
```

内部串联三个完全体校验器（不复制其逻辑），任何一个环节自身报错（脚本缺失/参数错）都算硬错，先修环境：

1. `validate_compact_package.py <包> --model wan30`——结构硬错：时间轴、绑定、字符上限、四段结构、`【参数】`拦截、声线锁定缺失等；
2. `audit_wan30_antipatterns.py <包> --json`——反例模式：站排/五人同框、静物/空镜超时、字条可读风险、慢镜、暖光词；
3. `validate_novel_coverage.py <包> <小说>`——原文覆盖（未给 `--novel` 时标 SKIP 并在交付说明里注明）。

本地预检（fast_gate 第 0 步）：实现已登记规则 R39／TEXT-03 的存在性机检——含台词或心声的提示词块缺 `画面文字纪律：` 统一句即为硬错；误报以合评裁定，规则本体仍归完全体（待其校验器回填后移除本预检）。

输出两栏：

- **硬错**：必须修复，修完重跑整条命令，秒级迭代；硬错清零前不得合评、不得交付；
- **风险**：按类型合并为一句话结论（如 `group_shot_budget ×2`）；改了就跑，不强制清零，合评第 10 项核对处置理由。

## 合评清单（硬错清零后，1 个评审员通读 1 遍）

| # | 检查项 | 一行结论要求 |
|---|---|---|
| 1 | 剧情忠实 | 关键事件/责任/结果/线索逐段在场；台词逐字不改 |
| 2 | 人物进出 | 画内外声明与参考绑定一致；没有无绑定出场 |
| 3 | 空间连贯 | 相机侧/朝向/出入口逐段接上段【收尾】；正文内嵌的三行站位与相邻段不打架 |
| 4 | 道具链 | 获取点先于出现、状态连续、去向有交代 |
| 5 | 台词与声音 | 归属正确、声线锁定只列实际发声者、画外/听筒标注一致 |
| 6 | 表演层 | 微表情线索 1–2 个/镜不堆砌；抽象情绪词换成可见线索 |
| 7 | 一致性 | 三锚跨段逐字一致；服装变体/状态变体绑定正确 |
| 8 | 节奏观感 | 通读一遍：切点不突兀、无超长静态拍（机检已拦结构，人看观感） |
| 9 | 资产口径 | 同一角色/道具/服装跨段不冲突（CHAR_06 类三类口径错配） |
| 10 | 导入字段与风险处置 | 绑定行正确、正文无 `@ImageN`、无 `【参数】`；每个未清零风险有处置理由 |

判定引用 [prompt-review 严重度口径](../short-drama-workflow/references/prompt-review.md)；**合评结论直接落成正文修订，不写评审批次文档、不落逐项 JSON**。第 3 空间连续与第 4 道具链是快速档相对完全体最弱的环节——多线并行、5 集以上长剧或道具链复杂的项目别用快速档。

## 快速档自有规则（硬顶 10 条，增删需用户批准）

| # | 规则 |
|---|---|
| R-F1 | 流程 A→F 顺序不可跳；每阶段单遍完成；发现上游错当场修当前稿 |
| R-F2 | B/C/D 不落独立中间文档；中间产物就是最终包的草稿 |
| R-F3 | 写作规则零本地定义：一律引用完全体 reference；本 skill 文件不出现写作规范正文 |
| R-F4 | 机检一条命令、硬错即修即跑；风险一句话结论不强制清零 |
| R-F5 | 红线 6 项不可省（见 SKILL.md） |
| R-F6 | 合评：1 评审员 1 遍 10 项清单，每项一行结论，结论直接改正文 |
| R-F7 | `--sample-first` 默认关；开启时用 1–2 个代表段先行实际生成 |
| R-F8 | 交付格式唯一：完全体模板，不改字段 |
| R-F9 | 系统性生成失败→受影响段升级完全体重跑＋记失败指纹；连续两项目同指纹→建议回写完全体规则 |
| R-F10 | 自有规则总数 ≤10；每季度复扫，两轮未触发的降级为机检静默项 |
