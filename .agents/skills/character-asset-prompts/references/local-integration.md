## 模块职责与执行顺序

| 任务 | 组合方式 |
|---|---|
| 剧本提取并做人物资产 | S03提取事实与ID → 本技能补美工/造型及锁定卡 → 根据媒介需要选S01或S16 |
| 新人设/美型CG建模参考 | 本技能为主 → S01提供局部脸发结构方法 → 需要服装设计再选S10 → 需要跨角色定调再选S11 |
| 原插画转真人摄影可信资产 | S16为转换主流程 → 本技能补具体美术/建模可读性 → 已确认肖像后进入全身/三视图 |
| 已确认人物提升美工 | 本技能读取确认身份和当前造型 → 定位授权变量 → 同步正文与锁定卡；不重跑身份开发 |
| 商业美妆/写真 | S04为主 → 本技能提供身份、妆发、衣料设计；不强制建模四视图 |
| 仅换服装/服饰单品 | S10提供剪裁/材质；保留当前身份和版式；独立商品板不是人物基准板 |

只读与本轮有关的源段落。主格式只选一套，辅助模块传字段，不把各模块欢迎语、编号菜单和输出模板全叠进成品。

## 冲突决策

1. 用户当前要求与已确认合同优先；本地整合的任务适配优先于源文默认；源文明确规格只在用户选择该原版任务时继承。
2. 已有角色保持身份和媒介。S16只用于明确的高写实转换；美型CG优化不能添加“no CGI”，卡通或2D不能同时被禁止。
3. 本目录通用人物建模板为16:9白底、左正面身份特写、右完整正/左侧/背全身。明确调用S16时用其特写约40%版式与身份确认；明确调用S10原版时才用其竖版上脸/下无头身体布局。参考自有版式或用户指定版式优先。
4. 锁脸状态从会话和真实参考判断，已有确认不重复审批。文字草案不伪造“已锁脸”，实际生成按主模块阶段执行；用户明确授权探索方案时按其范围做草案，状态仍为候选。
5. 原文明确身体标记保留，污渍与暂态伤痕分开记录；不因S10“清洁面部”删除身份疤痕，也不因词库“真实细节”新增疤痕。
6. S03已有`@CH-001`则沿用；独立设计才用C001。服装版本附加到角色档案，不重建身份ID。S18/S21需要`@p1`时由实际附图建立映射，不能把文本ID当已上传图。
7. 本技能4000字符为默认写作预算，用户/目标平台规格优先；不宣称它是源文或图像平台统一限制。真实尺寸和参数只用实际工具支持项。
8. 提示词交付不会触发出图、视频、全局配置修改或供应商调用。实际图片、模型等只按用户明确要求继续。

## 交接最小内容

角色ID/名称、当前阶段、visualIdentity、造型/服装版本、固有色、身份不变量、参考职责及实际路径、允许修改项、未确定结构。项目已有字段时填回原字段，不另建不兼容格式。

用户只要正文时隐去交接说明；用户要资产库时将记录和可投喂正文分开保存，内部规则和来源分析不进入画面。
