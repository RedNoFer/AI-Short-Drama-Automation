# 人物建模参考与质量验收

用于建模参考提示词和资产设定板，不表示交付网格模型。实际模型、拓扑、UV、贴图、绑定与引擎导出属于另行明确的制作任务。

## 先确定产物阶段

| 阶段 | 当前可交付 | 进入后续阶段的条件 |
|---|---|---|
| 文字设计草案 | 身份/造型方案、可复制提示词、暂定项 | 不声称已验证脸部或图片 |
| 身份开发 | 正面身份肖像及针对性修改提示词 | 使用S16真实转换时遵循其确认状态 |
| 建模参考板 | 身份特写＋完整正侧背、结构补全说明 | 有足够外观信息；实际出图须核对一致性 |
| 服装细化 | 同一身体/身份上的服装版本、必要局部细节 | 仅当用户需要，保持主板身份与版式 |
| 已确认基准 | 实际图片路径、确认依据、角色ID和服装版本 | 图片确实存在并获确认，不将候选自动锁定 |

用户只要提示词时直接完成文字阶段，不以尚无生成图片为由阻止写作；但不能把下游基准写成已确认。S16的“未锁脸先肖像”约定仅用于该写实转换流程，不强加到2D、CG角色文字提案或用户明确授权的探索任务。

## 建模参考的画面要求

- **视角**：正面、严格90度左侧、背面；正交感/弱透视，平视，同等尺度。侧面头、胸廓、骨盆和脚都转向一致，不能头侧身正。背面不回头。
- **基线**：三个全身头顶、骨盆/膝部相对高度和鞋底一致；同一站姿、头身比与镜头尺度。身份特写允许放大，但不是第四个不同人物。
- **完整性**：完整头发、双手、鞋底和衣摆，有安全留白；双臂微离躯干，双腿不交叉，不插兜，不用手持物遮住关键服装。
- **轮廓**：发型外缘、颈肩、腰臀、袖口与下摆可读；身体不能被巨量烟雾、光效、长发或配饰全部遮住。既有长发保留，通过合理留缝和必要独立细节图解决，不擅自剪短。
- **服装层级**：领口、肩缝、门襟、腰带、衣层叠压、下摆、鞋履连接合理。真正需要的厚度、边缘与固定关系写清，不用“精美华服”代替。
- **材质**：形体可读优先，避免全身泛白、全脸油亮、均匀噪声或满身金属光；布、皮、金属、珠体、发丝能区分。
- **照明**：统一中性白平衡和曝光，主光/补光保留起伏，脚底轻接触阴影。作为拼版的每个机位可保持一致的相机相对布光，不要求每个方向复制一模一样的阴影。
- **清晰度**：全身足够景深，不虚化鞋、手、扣具和背部；微纹理强度服从风格与画面尺度。正文中的“4K/8K”不等于实际输出尺寸，设置以工具为准。

## 不可见结构的补全

1. 先检查用户是否已有同一版本的侧/背/全身参考，实际存在才引用。
2. 依据已见轮廓、材料、连接和对称逻辑补必要内容。半身交领可保守延续后领；不能凭空添加背部纹章、镂空或复杂铠甲。
3. 在设计说明记录推导，例如“后领、背发和鞋履为统一补全方案，非原图可见事实”。用户只要正文时内部保留来源状态，别把说明标签变成画面文字。
4. 多个方案未定时选一个明确标注的草案或保留待定，不把彼此矛盾的方案塞进同一提示词。新参考到来时替换补全部分，确认身份继续保留。
5. 只有眼前图片不能判断真实尺寸、网格拓扑、UV或材质数值，不能反推成精确测量。

## 最小角色锁定记录

根据任务保存可读短语即可；用户需要结构化交接时可映射为以下字段，不强制输出JSON。

| 字段 | 内容 | 避免混入 |
|---|---|---|
| 角色ID/名称 | 已有ID、身份、用途 | 新平行ID和新剧情 |
| visualIdentity | 年龄感、脸型、眉眼鼻唇、肤色、发际线、发型、确认标记 | 衣服、灯光、渲染质量词 |
| styling | 衣层、剪裁、闭合、鞋履、贴身配饰、材料 | 角色关系、动作、未确认武器 |
| colorPalette | 肤发与服饰的固有主色、辅助色、强调色 | 把灯光色当服装固有色 |
| consistencyRules | 脸部、比例、发束、标记位置的跨视图不变量 | 重复整份造型描述 |
| 服装版本/状态 | 同一角色的当前造型版本、草案/候选/确认 | 换装另起角色ID |
| 参考与待定项 | 实际图像路径或附图职责、背面补全来源、未解决项 | 虚构上传图和确认记录 |

没有用户定义字段时不要为了输出完整而生成空占位字段。已确认图和补充参考发生冲突时按职责处理：确认脸只管身份，服装参考只管衣服，风格图只管光色/媒介，不越权改脸。

## 验收与定向修复

| 项目 | 可观察达标标准 | 失败后怎么修 |
|---|---|---|
| 面部身份 | 特写与正面脸型、眼型/瞳距、鼻唇、发际线一致 | 保留母版，只编辑漂移部位，不重设整张脸 |
| 侧面结构 | 90度朝向、额鼻唇颏连续、头身体同向 | 仅修朝向或对应轮廓，不同时改衣服 |
| 身体比例 | 三视图肩宽、头身比、腰线、腿长和基线相容 | 固定正面比例校正侧背尺度 |
| 服装构造 | 同一领型、袖型、门襟、腰带、下摆与鞋款 | 用同一造型记录修错误部位 |
| 左右标记 | 身体自身左右一致，转向后按实体位置变化 | 纠正附着位置，不整图镜像 |
| 发型 | 同一分缝、体块、发长和发饰连接 | 固定主发束走向，减少无关碎发 |
| 材质与肤色 | 固有色稳定，材质不同而可辨，细节符合画风 | 调整粗糙度/纹理密度/高光，避免换媒介 |
| 可建模性 | 遮挡少，关键连接和背部合理，手脚清晰 | 局部编辑或按需求补独立细节图 |
| 版式 | 单张指定比例、四种展示、完整且不融合 | 仅修布局与裁切，不重设计角色 |

严重问题是身份漂移、人体错误、视图不全、服装结构矛盾和左右错位；先修这些，再微调皮肤与装饰。没有实际图时以上是待验收项，不能报告“图片验收通过”。

多视图持续失败时可建议：固定身份母版 → 同版本正面全身 → 侧面 → 背面 → 合成板。只有具备合适生成/编辑工具且用户要求实际图片时才执行；执行后逐张检查。若使用的图像工具有独立编辑规则，按其实际规则操作，不因为本参考建议而改用脚本编辑图片。
