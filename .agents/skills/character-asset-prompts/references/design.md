# design

适用本 skill 主入口的任务范围。以下为专科细则；用户明确选择优先。

一、先提取再补问

遵循 [需求提取与问询](intake.md)。已有描述直接提取；缺少影响形象的字段时先问，用户授权代选后才能补核心设定。信息足够则直接生成，不要求再确认。局部修改保持既有设定，多角色共享画风但分别检查缺项。

二、风格与设计强度分开选择

【视觉风格】
- 写实：遵守年龄、人体和衣料的合理表现，允许自然肤质；不能同时禁止 photorealistic。
- 电影感3D：保留可信结构，按项目需要简化形体；皮肤、头发、布料细节与整体风格协调。
- 手工定格：强调木、布、黏土、漆面、针脚和手作体积；不强制人类毛孔或皮下散射。
- 2D动画：强调轮廓、色块、线条、平涂或绘画笔触；不把 flat 2D、cel shading 作为通用负面词。
- 自定义：将参考拆成形体、线条、色彩、材质与光照特征，选一个主方向，最多两个辅助方向。不要机械混合一串作品名或品牌名。
风格未指定时先补问；用户明确让AI选择时，才可采用“电影感3D、鲜明但不过度”的暂定方案并标明。

【设计强度】
- 克制：适合日常人物、写实群像、制服角色。允许简单服装、纯色、干净状态和近对称设计。
- 鲜明：用清晰廓形、合理色彩关系和1-2个记忆点形成识别度。
- 高定实验：用户要求或题材确实适合时，强化比例、解构、材质对比与局部点色；仍需符合职业、时代、行动需求和世界观。
不强制人人极端比例、三层衣服、三种瑕疵、撞色或贵重配饰。婴幼儿、少年、洁净职业与新衣状态尤其不套用成人磨损模板。

三、设计顺序：先锁定，再补细节

1. 提取已确认项：角色ID、年龄段、体型、外观、服装、标志物、时代与环境。
2. 选3-5个主锚点：从脸型、发型、体型、服装轮廓和标志物中选择真正能跨镜头辨认的特征。
3. 服装先看用途与结构，再决定材质和配色。默认1-3层，以实际穿着为准；隐藏层无需全部写进图像提示词。
4. 主要面料优先写“材质＋可见表面＋垂坠或反光”。纱线支数、织法、整理工艺只有能改变画面或用户要求时才展开。
5. 磨损、修补、污渍和身体标记必须有位置、程度和叙事依据。没有依据时可不加，不为显得高级强行添疤痕或纹身。
6. 配饰有用途或叙事价值即可。未提供来历时写为设计建议，不虚构成已确认的角色传记。
7. 面部描述以可见结构为准：脸型、眉眼、鼻、唇、肤色及必要纹理。不要将下颌、眼型、体型等外貌特征当作人格或道德判断。
8. 年龄由整体形态与状态体现；不规定25岁必须有细纹、35岁必须显老等固定组合。
9. 设计虚构角色时不主动套用明星或已有角色身份。不要声称“100%原创”“绝不会相似”或“保证无侵权”；文字设计不能证明这些结论。
10. 无毛发、非人类、机械或拟物角色跳过不适用的人类字段，改写为对应的结构、接缝、涂层与材质。

## 四、本目录人物美工深化

“提高美工”要得到可画出的设计关系。以下项目按本次画面所需选择，不要求每人写满全部字段。

### 1. 先判断哪些项能改

内部区分：原文/参考可见事实、已确认设计、必要保守推导、新设计提案。确认事实锁定；推导和提案在设计说明标注，获确认后才进入正式锁定卡。仅有半身参考时，不能把推测身高、背发、鞋履说成已知。

把模糊需求转为变量：

| 需求 | 可执行的优化 | 保留边界 |
|---|---|---|
| 更美/更帅 | 发际线整理、眉形线条、妆面层次、唇色、表情放松或明确授权的五官调整 | 未授权时不改脸型、瞳距、眼型、鼻唇比例和年龄 |
| 更高级 | 肩线、领口、腰线、面料重量、哑光/低光泽对比、少量有效装饰 | 不默认换成华服、高跟鞋或奢侈品牌 |
| 更真实 | 接触阴影、关节体积、布料厚度、材质反射、适度区域色差 | 不自动加老化、疤痕、脏污和磨损 |
| 更有辨识度 | 在脸发、体态、服装轮廓中明确主锚点 | 已确认角色不靠换脸或新身体标记区分 |
| 更适合建模 | 中立姿态、轮廓留缝、严格侧背、可解释的连接与遮挡 | 不把造型图夸称为工程图或现成模型 |

### 2. 脸部设计：轮廓、关系、表面分层

- **轮廓/骨相**：额头—颧部—下颌宽度关系、面颊体积、下颌转折、下巴长度和圆钝程度。新设计选择少量明确特征；已有角色继承参考，不强制尖下巴、窄鼻或大眼。
- **眉眼**：眉身粗细、眉峰与眉尾；眼裂长宽比、眼角方向、眼睑覆盖、瞳距与虹膜占比。眼睛高光服从布光，不写发光虹膜来冒充生动。
- **鼻唇**：鼻梁起伏、鼻尖体积、鼻翼与唇宽关系、唇峰和上下唇厚度、嘴角静态。侧面检查额头、鼻梁、鼻尖、唇和下巴的连续轮廓，不把侧面另设计成新脸。
- **年龄与表情**：用原设定的体积、皮肤状态、眼周和口周表达；中立基准不靠夸张笑容、眯眼、嘟嘴改变形态。特定表情母版已确认时继承。
- **妆面**：按职业、时代、情境与画风选择眉妆、眼线、睫毛密度、腮红位置及唇色；说明覆盖程度和边缘软硬，仍保留身份结构。未要求化妆时可保留素颜。
- **皮肤**：先固有肤色与明暗体积，再局部色差、粗糙度和微纹理。CG美型用细腻低强度纹理；摄影写实只在近景写适度毛孔和绒毛；2D不强制微毛孔。SSS不等于全脸泛粉、白皮或油亮。

避免“绝美鹅蛋脸＋高鼻梁＋大眼＋V型下巴”全员复用。审美目标由用户和项目决定，天然不对称、宽脸、深肤色、成熟年龄或特殊比例不视为质量缺陷。

### 3. 体态与头发：先体块，再细节

- 体型写肩、胸廓、腰、骨盆和四肢的相对体积，已有头身比保持。没依据不编精确身高、围度或全员九头身。
- 基准姿态优先头颈端正、肩线自然、重心稳定、双脚落地；用放松A姿或微离躯干的双臂让袖口、手和腰线可见。T姿只在用户需要绑定参考时使用。
- 手掌、手腕、膝踝和鞋型具可信结构；服装塑形不代替身体结构，不以拉长脖子、抬高胯或缩小头部冒充优雅。
- 发型描述发际线、分缝、头顶体块、鬓侧、主发束路径和发尾位置。先锁整体轮廓，再主束、次束、少量碎发；避免等粗面条束和满头钢丝。
- 后脑与背发只按已见发型和连接关系延续；盘髻、辫尾、发饰须交代固定位置。不能因为正面漂亮而在背面换发型。

### 4. 服装设计：每个关键结构能在三视图延续

先用途与行动需求，再从以下部位选真正改变形象的设计：

| 部位 | 可见设计字段 | 跨视图核对 |
|---|---|---|
| 肩颈 | 肩线位置、领型、领口厚度、交叠方向 | 领口至后领连续，肩缝附着正确 |
| 躯干 | 合体/宽松、前片开合、腰线、叠穿顺序 | 侧面厚度合理，背部省道或拼接有依据 |
| 袖子 | 袖型、袖口、长度、肘部余量 | 不同视图保持同一袖型，不穿过身体 |
| 腰臀 | 腰带位置、闭合、裤裙轮廓、开衩位置 | 腰带压在对应衣层，左右不镜像 |
| 下摆 | 长度、重量、褶量、边缘工艺 | 前侧背长度相容，褶皱受重力和支点影响 |
| 鞋履 | 鞋楦、鞋口、跟/底厚度、固定方式 | 左右成对，接地可信，不能变成不同鞋款 |
| 配饰 | 形状、材质、数量、自身左右、挂接点 | 有实体连接，不悬浮、不增减、不镜像 |

有明确制服、时代服装或参考穿搭时保留。未知结构可先给一套保守提案，不让三视图各自自由生成。武器、工具、剧情信物等需独立复用的物件另登记道具；角色板按任务只交代佩戴关系，避免手持动作遮挡结构。

### 5. 配色与材质：有主次，不统一改白皮金饰

- 主色支撑大轮廓，辅助色分层，强调色服务识别点；数量与占比因角色而定，不强制撞色或固定比例。肤色、发色、衣料固有色与灯光色分别描述。
- 多角色共享画风时用脸发、肩腰体态、版型和主色形成差异；同为制服可通过合法的体态、发型和既有细节区分，不编造新军衔或标志。
- 布料写织物类型、可见表面与重量/垂坠；针织可见织纹和弹性，丝绸高光沿褶流动，棉麻多漫反射，皮革有厚度和克制反射，金属有边缘与局部反射。不能把全部材质写成亮面塑料。
- 刺绣、纹样、五金和珠饰应有尺度、附着面和密度；少量重点比全身花纹更容易跨图继承。不要从词库自动带入起球、氧化、血迹或裂纹。
- 当前风格明确时，材质技术只服务该风格；2D用线条/色块分材质，定格用手作表面，写实3D用粗糙度/反射/厚度，美型CG按参考控制细节。

### 6. 灯光用来读结构

纯白底资产板可用偏轴柔和主光、适度补光和必要分离光；保留眼窝、鼻侧、下颌、衣层的体积，浅色衣料边缘不能融入背景，深衣不能死黑。全身景深足以看清手足、接缝和饰品。

商业写真可使用柔化和高调光，但要按目标单独输出；不将S04的默认人物、肤色、服装、浅景深和美妆动作灌入建模板。风格参考只能提供获授权的光色/材质，不替换身份。

### 7. 优化交接

局部修改记录 `change / preserve / constraints`：change列用户授权的变量，可有多个但应分清；preserve列身份、年龄、比例、画风和未修改造型；constraints列本次高代价错误。正文、服装版本、锁定卡同步更新；只改某项时不借机重设计其余项。
