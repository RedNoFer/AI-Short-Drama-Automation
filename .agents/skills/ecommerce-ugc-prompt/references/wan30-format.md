# Wan3.0 电商提示词结构 v1.3

七段用于本地组装和检查，非官方固定语法。每段保留需要控制的信息，允许合并、简写或在不适用时省略；物理可行性不能省略。B1 不逐字套句，B7 不凑数。用户只要可粘贴正文时不附内部卡、评审表和字段说明。

## 1. 先确定输入模式

| 模式 | 编写重点 |
|---|---|
| 纯文生视频 | 明确商品、场景、动作与风格；无图不声称已锁定真实包装，商品文字准确性待核验 |
| 商品多图参考 | 点名各图的商品身份、视角与用途，正文只引用实际上传素材；参考图不等于首帧约束 |
| 首帧生视频 | 沿用首帧商品、空间和当前状态，重点写后续动作、运镜与声音；不重新布置同一开场 |
| 首尾帧生视频 | 设计从首帧到尾帧的可执行过程；若需要穿透、封口自动复原等才能连接，先修正端点或过渡方案 |
| 视频编辑 | 明确改动项、起止范围与保留项；仅此类任务使用有比较对象的“其余保留”表述 |
| 视频延长 | 从原片出口状态继续，不重置抓握、数量、余量或姿态；写明延长方向及目标内容 |

官方不同任务允许的素材组合不同。当前说明中，首帧/首尾帧使用对应帧类型，不能同时混入参考音频等其他类型；参考生成可按规则混合参考图、视频、音频。实际生成前以目标入口当前支持项为准，不把通用公式当作所有模式都支持音色参考的依据。

另外按 [卖点、台词与素材分支](brief-and-input-routing.md) 判断商品图、模特图和音频各自的角色。素材是否存在与产品卖点是否已由用户提供是两件事；不能只取图片可见细节而忽略用户明确提供的功能或体验。

## 2. 七段组装

### B1 风格与物理基调

按轨选择真实摄影表现，材质遵从商品。例如：

> 真实商品摄影，保留包装本来的哑光纸面与局部烫金反射，动作具有可信重量和连续的接触关系。

UGC 可写手机自拍，品牌可写影棚；不统一低饱和、全哑光或无反光。“真实物理引擎”不能代替具体动作描述。

### B2 总体目标

说明品类、展示轨、时长、画幅、主卖点、对购买者的价值和收尾。主卖点决定画面与台词，不只写品类名称。例：

> 15 秒、9:16 食品电商展示，突出包装正面信息与纸盒工艺，以商品停稳的镜头收尾。

避免把轨名或内部版本号当作模型理解展示意图的唯一依据。

### B3 商品与参考

描述已知商品身份、材质、结构、关键文字；明确商品图、模特身份图、场景图与音频的各自用途，不跨用属性。全局写一次身份一致性，后续镜头只补当前状态和关键变化。示例锁定句：

> 商品款式、标识布局、配色和尺寸比例沿用图1；镜头中的抓握、朝向和开合按下文连续变化，材质保留真实响应。

实际引用规则：

- 官方自然语言写法为 `图1`、`视频1`、`音频1`，各类型分别按上传顺序编号。
- 目标网站若要求 `@Image1` / `@Video1` / `@Audio1` 等标签，只按该网站已确认的映射转换；不能混写 `@音频1` 并假定所有入口都识别。
- 每个引用必须对应已上传的素材及用途。没有图片就用已确认事实描述，并在正文外注明待补素材；没有音频就自然描述音色。
- 一张正面图不能被说成背面参考。未展示细节不可擅自补写品牌文字、配料、型号或开合机构。

### B4 场景、支撑与光线

写明承托面、商品起始摆放、必要道具、人物/手部与拍摄位置、光源逻辑。阴影和高光服从光源与材质；生活场景、白底、干净台面、专业影棚均可使用。氛围道具说明用途，不能混成商品内容物或额外赠品。

### B5 时间轴与镜头

默认写法：`镜头N[起-止秒]：景别与机位，商品当前状态；主动作及必要物理过程；结束状态与摄影机运动。`

- 时间段连续、无重叠，覆盖目标时长；镜头状态接得上。时间预算按真实动作确定，无每镜至少 2.5 秒的统一硬限。
- 静态展示写承托、姿态与机位即可。运动镜头优先写清接触、驱动、路径和落点，参照物理规范判断需要拆镜的地方。
- 摄影机可以固定，商品可以静止；不强迫每镜都有加减速、不禁止合理匀速环绕。
- 正面文字镜头给清楚视角、焦点和停留；不让移动中的密集小字承担必须准确的核心信息。
- 生成用连续过程与剪辑省略区分清楚；同一操作不要一边“一镜到底”又一边要求跳切重置。

### B6 声音

本地默认分别交代：

```text
人声：按用户提供的逐字台词或核心卖点组装；写清出镜说话人或画外音、时段、逐字台词及必要声线。用户给卖点时主动写成自然口播，突出该产品的使用价值；只有无卖点资料时才限于可见信息。纯视觉、静音或确无有用台词时，才写“全片无台词、无旁白”。
音效：与接触、材质、动作时刻对应的声音及必要环境音；无音效需求时明确说明。
背景音乐：风格、节奏、进入/退出及与人声关系；不要时写“无背景音乐”。
```

用户提供的卖点可以超出静态图可见范围，但不能擅自扩大其含义。用户提供“滋润”不扩写为医学功效；“舒适”不扩写为久戴不累或适合所有人；“折叠”不自动扩写为车架伸缩或某种铰链路径。逐字台词超时先指出冲突并给可选精简版，未经授权不默改。15 秒通常用一至两句围绕同一主卖点的介绍，30 秒通常用两至三句不同信息，按实际说话窗口留出停顿。出镜说话按需加“口型同步”；商品/手部画面通常采用画外音。上传音频先明确是音色、原话、音效还是音乐参考，再核对输入模式。不能以“全片静音”同时要求可闻动作音；完全静音时三项均关闭并核对平台音频设置。

### B7 关键约束与负向

只选择本次存在风险的约束，不重复整张商品卡。先写正向可执行过程，再补必要负向。例如手持纸盒可写：

> 避免手指穿入盒体、抓握脱离后商品悬停、落桌穿透及连续镜头中的商品跳变。

有液体才补出流、倒流、穿壁和无源增量风险；没有手就不必列手指风险。不得用“其余动作、服装和画面保持不变”约束一个没有原视频的新生成任务，不要求光学反射和柔性形变永远不变。

## 3. 参数与交付

参数单独记录为生成设置，正文中的时长和比例与设置一致。2026-10-27 核对的官方说明提供最长 30 秒及多种画幅/分辨率，但网站封装与模式可能另有限制；调用时核对当前入口，不沿用旧手册中的参数当作永恒上限。多图参考与首尾帧模式的配置不可互相替代。

默认交付：必要素材/设置说明（缺项时明确标出）＋一份可直接粘贴的中文提示词。用户只要正文时直接给正文，必要阻塞缺项仍需简短说明。未完成素材绑定的模板不能标记为可直接执行。

示例见 [Wan3.0 电商示例](wan30-examples.md)；物理及成片验收见 [物理与验收规范](physics-and-acceptance.md)。
