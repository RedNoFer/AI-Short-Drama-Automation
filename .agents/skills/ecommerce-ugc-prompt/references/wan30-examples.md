# Wan3.0 电商物理写法示例

以下为虚构演示条件，不代表当前已经上传素材或生成视频。实际使用必须替换为已确认商品事实并绑定真实素材；未满足前提时不能直接宣称可执行。图N采用官方自然语言写法，网站标签按其真实映射转换。

## A. 纸盒拿取与放回，15 秒

前提：图1是同一封闭纸盒的正面照片，图2是其右前侧照片。已确认盒面为深绿哑光纸、局部烫金、品名“每日坚果”和规格“750g”；纸盒尺寸适合成人单手抓稳。其余品牌元素以真实图为准，不额外编造。目标只展示正面及小角度侧面，不要求背面小字。

```text
真实商品摄影，保留哑光纸面和局部烫金随角度变化的自然反射。
15秒，9:16竖屏食品电商展示，突出包装正面信息与纸盒工艺，以商品放稳收尾。
商品身份、印刷布局、配色和尺寸比例参考图1，右前侧结构参考图2。封口保持完整；盒面核心文字为“每日坚果”“750g”，不新增品牌或标识。
商品直立于水平厨房木桌上，底面由桌面完整承托。窗在画面左侧，柔和日光照明；背景简洁。成年人的右手从画面右侧操作，摄影机置于桌前支架上。
镜头1[0-3秒]：正面近景，盒子直立静止，品名和规格处于清晰焦点内，留出文字可读停留。摄影机固定。
镜头2[3-7秒]：硬切至中近景，沿用原摆放。右手靠近盒身，拇指贴住盒体左侧，其余手指包住右侧与后侧；抓稳后垂直抬离桌面约五厘米，停住。盒子始终有手抓持，未开封，摄影机固定。
镜头3[7-11秒]：沿用上一镜同一右手的抓握和高度，手腕带动盒体缓慢转至右前侧约三十度，展示图2所示侧面。手指与盒体同步移动，握持不脱离；烫金高光随朝向自然变化。摄影机固定。
镜头4[11-15秒]：右手保持该朝向，将盒子缓缓垂直降回桌面；底面接触桌面并停稳后，手指松开，右手向右撤离。最后约两秒只保留桌面承托的静止商品。摄影机固定。
人声：画外音（3-8秒），自然、清楚地说：“每日坚果750克装，深绿色盒面配局部烫金，正面信息清楚直观。”
音效：抓握时轻微纸面摩擦；镜头4盒底接触木桌时一声轻落定声，另有低音量室内环境声。
背景音乐：无背景音乐。
避免手指穿入盒体、盒子脱离抓握悬停、落桌穿透、切镜后换款或姿态无故复原。
```

检查重点：镜头2末尾五厘米高 → 镜头3延续高度及抓握 → 镜头4保持侧向落桌；没有为正面收尾而塞入一次额外回转，没有把烫金强行改成哑光。

## B. 透明瓶倒液，15 秒

前提：图1为已确认的透明玻璃食用油瓶，图2为其开口瓶嘴细节。瓶内淡金色食用油初始约半瓶，瓶盖在拍摄前已取下；标签及额定容量仅按实际图保留，不虚构品牌、成分或功效。操作台水平，透明接收杯容量充足。

```text
真实厨房商品演示，保留玻璃折射、油液透明度及对应光源的自然高光。
15秒，9:16竖屏，展示一次连续倒油及停止出流的过程。
玻璃瓶身份与标签参考图1，开口结构参考图2。开场瓶盖已取下并放在桌面左侧，不展示开盖过程；瓶内油液约半瓶。
透明接收杯放在水平桌面中央，杯底完整接触桌面。成年人右手已握稳瓶身中段，将直立瓶子持于杯右上方；左手不入画。柔光从画面左后方照射，摄影机在桌前固定支架上。
镜头1[0-4秒]：中近景，建立开口瓶、右手和空杯的相对位置。右手持续握持瓶身，瓶子直立，瓶口未出流，杯子静止，瓶盖留在桌面左侧。
镜头2[4-10秒]：右手带动瓶子逐渐倾斜，瓶口位于杯口上方且朝向杯内。油液到达开口后向下流入杯中；杯内液面逐渐升高，瓶内余量同步减少。保持一股细流后，右手逐渐将瓶子恢复直立，出流随倾角减小而停止。摄影机固定，手、瓶口和接收杯同时保持可见。
镜头3[10-15秒]：延续直立瓶子的抓握，在杯旁稳定持住，不再倾倒。杯中液面轻微晃动后逐渐平稳；瓶内余量低于开场，瓶盖仍在原位。摄影机固定，展示实际留下的液体状态。
人声：画外音（4-9秒），语气平实：“倒油的过程和杯里的液面变化，都能直接看清。”
音效：只有出流阶段的轻微倒液声及低音量厨房环境声；停止出流后倒液声结束。
背景音乐：无背景音乐。
避免液体穿过瓶壁、向上倒流或悬停、瓶内余量自动补满、杯子自行移动、瓶盖凭空回到瓶口。
```

检查重点：开口是起始事实，不跳过尚未发生的开盖；出流有来源与接收容器；停止后余量不复原；反射和折射允许随真实角度变化。

## C. 常见不成立请求的处理

| 输入要求 | 应如何调整 |
|---|---|
| “松手后让商品浮在空中旋转，保持真实拍摄” | 改为有真实承托的电动转台，或手持转动；不能保留无支撑悬浮并标记物理通过 |
| “单手自拍，同时双手拧开盖子” | 手机固定支架或明确由另一人拍摄，再安排双手开盖；不让同一只手兼顾手机和瓶盖 |
| “四秒内撕封、开盖、倒液、盖回并读完背标” | 保留一个核心操作，其余拆镜或删减；固定时长内仍不成立则指出具体需要调整的内容 |
| “挤完后软管外形和剩余量完全不变” | 固定商品身份与印刷，允许受压形变和余量减少；不使用“所有结构和状态完全不变” |
| “玻璃香水瓶要真实，但禁止所有反光和折射” | 保留玻璃物理特征，通过柔光和机位控制高光强弱，避免大面积反光遮挡标识 |
| “只有正面图，必须清楚展示背面真实配料表” | 请求背面真实素材，或先只展示已知正面；不得编造配料和条码 |
| “用跳切让已经撕开的同一封口重新完整” | 修改镜头顺序或明确更换新件且数量有据；不能用剪辑掩盖不可逆状态复原 |

这些案例用于人工语义审查。文字模板通过不证明实际视频已通过物理验收。
