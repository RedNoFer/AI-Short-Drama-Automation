# 物理可信性与验收

本文件是电商提示词的强制写作与审查规范。目标是在动作设计阶段排除反真实的情节，再用成片检查确认实际表现。无物理仿真运行时，不声称已经通过真实物理引擎计算。

## 1. 六类硬性检查

| 项目 | 正文必须说清的关键关系 | 不通过的情况 |
|---|---|---|
| 支撑与重力 | 静置物由什么承托；离开承托面后由什么抓持；落下后在哪接触停住 | 商品无承托悬停、手已撤走物体仍停在半空、重心越出支撑区仍不倒 |
| 接触与施力 | 手或工具作用在哪里；抓握先于抬起；接触面先于推动；松手晚于承托完成 | 手隔空推动、手指穿入硬壳、握住空气、物体先运动再被碰到 |
| 运动连续 | 初始位置/朝向、移动路径、速度范围及结束状态；不无故重置 | 商品瞬移、无驱动自转、在连续画面中掉头跳变、落桌后穿入台面 |
| 材料响应 | 刚性/柔性、厚度、重量及实际开合机制；仅写与动作相关的形变 | 玻璃像橡胶挤瘪、纸盒像液体流动、瓶盖穿过瓶口、密封袋内容物穿袋出现 |
| 液体与颗粒 | 容器是否开口、流动路径、接收容器、余量变化与终止条件 | 液体逆重力无故上流、穿壁、无源补满、颗粒凭空增殖或落下后悬停 |
| 时间与状态 | 动作在时段内可执行；跨镜头保留开封、朝向、抓握、位置与数量变化 | 四秒塞入多次开合与倒取、开封后自动封回、已倒出的内容物复原 |

镜头只有静态陈列时，明确承托与商品静止即可，不强行增加手部或受力表演。已由全局明确且未变的环境无需逐镜重复；抓握、开合、承托、数量或位置变化必须明确交接。

## 2. 写动作的方法

按当前动作需要描述：

> 初始状态 → 施力主体与接触部位 → 运动路径/适当幅度与速度 → 必要的材料反馈 → 结束状态。

不强制每个动作写满全部字段，不要求填写无依据的重量、摩擦系数或角度。能用“拇指抵住盒前侧、其余手指托住后侧，握稳后抬离桌面”说明的动作，不用堆砌“每根手指展开”等易与抓握矛盾的细节。

- 抬起：确认抓握和重量匹配，瓶身光滑或容器较重时使用合理握持或双手承托，不添加夸张肌肉绷紧。
- 放下：先接触承托面并停稳，再松开手指撤手；落定声与接触同步。
- 旋转：明确手、转台或其他驱动；与视角变化区分。持续持物时，手与商品同步运动，接触关系不跳变。
- 开合：按实际螺纹、卡扣、拉链、撕口或折页结构操作；打开后的盖子、封条和碎片有去向。未知机构先补信息，或改拍不涉及开合的展示。
- 倒液：先有开口和接收容器，倾斜至液面可从开口流出，再恢复直立停止出流；液柱受重力影响。不要强制“残留一滴”“必有飞溅”，表现取决于黏度和瓶口。
- 挤压：软管/泵头/软袋按结构受力，开口与出料对应；材料允许的形变不当作一致性失败。
- 粉末/颗粒：从真实开口或工具倒出，有碰撞、堆积和余量变化；不为质感强制加入浮尘或粉末云。

一镜优先围绕一个清楚的主动作，允许其必要子步骤，例如“抓稳—抬起”或“落桌—松手”。若出现多次主动作、换手或承托转移，估时后拆镜或简化。不能把“一镜一主事件”当成禁止所有动作连续过程的机械规定。

## 3. 机位、手部与光学

- 拍摄机位应有现实可行的承载方式。自拍者手持手机时，该手不能同时开瓶或操作商品；双手操作可改用手机支架或明确由另一人拍摄。
- 运镜不得无故穿过商品、人体或实体桌面；宏观特写的镜头距离与对焦范围要合理。固定机位无需写加减速；匀速推轨或电动转台允许存在。
- 反射、折射、高光随真实材质、光源、机位和物体姿态变化。不要锁死高光位置，也不要为“防 CG”消除玻璃与金属应有的光学特征。
- 多光源、柔光箱、影棚和高对比均可成立；检查光源逻辑、投影方向与接触阴影的协调。存在补光时不强求所有阴影只有单一方向。
- 字体不因物体转背仍漂在正面，反射中的标识不应凭空另长一套；景深与清晰度应服务当前要展示的区域。

## 4. 内部连续性记录

有状态变化时，在内部用简短表或笔记记录，不必把账本全塞进模型正文：

| 镜头 | 进入状态 | 变化及原因 | 离开状态 |
|---|---|---|---|
| 1 | 纸盒封口完整，直立桌面 | 仅摄影机推进 | 原位直立，未开封 |
| 2 | 同上，右手画外 | 右手握稳后抬离约五厘米 | 右手持盒，悬空有抓持 |
| 3 | 右手持盒 | 手带动小角度转向 | 右手持续抓持，朝向已改变 |
| 4 | 沿用镜头3 | 放回桌面，停稳后松手 | 商品桌面承托，手撤离 |

硬切可以改变机位，不自动允许商品换款、封口复原或余量补满。确需省略放置/换手步骤时，明确剪辑中的时间经过和新状态，不把跳切伪装成连续动作；不重复展示已经完成的不可逆操作。

## 5. 双阶段验收

### 提示词交付前

- [ ] 商品事实可追溯，未知结构没有编造；固定项和状态变量分开。
- [ ] 用户提供的核心卖点已进入台词；画面围绕该卖点安排。逐字台词按要求保留，产品价值没有被通用外观讲解替换；未把用户卖点扩成额外承诺。
- [ ] 折叠/伸缩演示有结构依据，App 演示有真实功能与界面依据；缺项已按受影响部分标明，未用假的折叠动作或界面跳变充当证据。
- [ ] 六类物理检查适用项通过，不适用项可省略；重点检查松手、落桌、旋转和开合的边界。
- [ ] 时间轴首尾相接、无重叠，结束时间等于目标时长；动作和台词均有足够时间。
- [ ] 摄影机、手部、工具及承托安排能同时成立；没有同时占用同一只手的任务。
- [ ] 正文先描述正确过程，负向项仅补充相关风险；没有“全部不变”与必要状态变化冲突。
- [ ] 素材引用对应实际上传类型与顺序；无空图片/音频引用。
- [ ] 材质、文字可读策略、音效和口播与动作相容；卖点没有超出证据。

任一物理项不通过，修改动作/时长/镜头并复查受影响的后续状态，不以负向清单代替整改。不能在固定时长内成立时，先简化非核心动作；核心演示仍无法成立则指出需要调整的具体时长或素材，不擅自改变商品用途。

### 实际生成后（仅在获得视频时）

重点检查接触前后、离桌/落桌、转向、开盖、出流/停流与切镜处，逐帧或慢放核对。记录问题时间点、可见现象和受影响镜头；物理错误不得标为通过。修复时优先简化动作、稳定机位或提供更合适参考，再重生成问题片段；持续失败则更换为可执行的展示角度或经用户确认的后期方案，不无限盲重试。

不能仅凭提示词合规、格式校验通过或单帧看起来正确，就宣称整段视频遵守物理。未生成/未取得视频时，验收结论止于“提示词已审查，成片待验收”。
