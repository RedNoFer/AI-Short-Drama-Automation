# Wan3.0 电商与 UGC 提示词

将已知商品事实和展示目标整理为可执行的视频提示词。默认交付中文正文；保留用户确认的语言、商品、卖点、时长与画幅。只编写提示词不代表已生成或验收视频，也不自动发布内容。

**物理可信性是硬性验收项。** 商品的支撑、接触、受力、运动、材料响应与前后状态必须成立。遇到不成立的动作，先修改展示方式或拆镜，再编写正文；不能只追加“真实物理引擎”“禁止穿模”后照搬原动作。视频模型不能保证每次遵守物理规律，提示词检查和成片检查分别报告。

## 读取与执行

1. 先读取 [卖点、台词与素材分支](references/brief-and-input-routing.md)，确定用户提供的是逐字台词还是卖点简述，并识别商品图、模特图、音频及其用途。用户明确提供的商品特点是本次文案依据，不因为图片没显示就退回泛泛的外观介绍。
2. 建立商品锁定卡，区分固定身份与可发生的状态变化；同时建立“主卖点 → 购买者所得 → 台词 → 对应画面”的简短映射。只有影响执行的缺项才询问；可自行决定的风格细节直接处理。
3. 编写前必须读取 [物理与验收规范](references/physics-and-acceptance.md)，按动作核对因果和时间预算。
4. Wan3.0 任务必须读取 [提示词结构](references/wan30-format.md)，按任务类型组装；复杂拿取、倒液或 UGC 手部操作再读 [示例](references/wan30-examples.md) 中对应条目。
5. 完成正文后检查卖点是否真正进入台词与画面，再检查物理、状态、素材引用、时间轴、文字及声音；用换品类检查发现套话：若把商品名换成其他品类仍通顺且信息不损失，重写。已有成片时再检查可见结果，未提供视频就写明“仅完成提示词审查”。

其他模型不套用 Wan 的引用语法、输入组合或参数上限。用户明确要求完整短剧包时转入目录内短剧工作流，不将商品提示词扩写成小说改编任务。

## 商品锁定卡

将下表用于内部写作；用户只要正文时，不额外输出一整张卡。

| 字段 | 要求 |
|---|---|
| 商品身份 | 品牌、品名、型号、SKU、主推款与数量，使用用户或素材给出的真实名称 |
| 结构 | 外形、比例、开合方式、正反面布局；未见的侧面或背面不编造文字与功能 |
| 材质与色彩 | 纸、软塑、玻璃、金属等真实材料及工艺；保留亮面、烫金、透明、液态等本来特征 |
| 文字优先级 | 核心品牌/品名/必要规格逐字确认；次要小字按参考保留；严格逐字准确的密集文字另列素材或后期校验需求 |
| 固定项 | 商品身份、图案布局、标识、基础尺寸与材质；不能因运镜或剪辑自行换款 |
| 状态变量 | 初始开合、位置、朝向、承托、抓握、内容物余量；开封、倒出、挤压等操作允许引起合理变化 |
| 事实来源 | 各图、视频、音频的实际上传顺序及用途；卖点对应的用户资料或可核验来源 |
| 核心卖点与台词 | 用户明确给出的特点、体验或原话；区分逐字保留、允许润色和仅给方向；记录主卖点对应的购买者所得与展示方式 |

不把“结构不变”写成“包装永不形变”：软袋允许受压变形，瓶盖允许旋开，外盒允许按真实结构打开。无参考图时仅描述已知事实，标记待补素材；不写“参考图中的”来暗示存在未上传图片。

## 三条展示轨

以下为本地写作建议，用户规格优先；物理要求不随风格放宽。

| 轨 | 常用组织方式 | 风格选择 |
|---|---|---|
| 品牌质感 | 氛围 → 使用或材质细节 → 商品收尾 | 可使用影棚、专业布光、干净背景和适合商品的对比度；反射、折射和阴影应有一致来源 |
| 电商展示 | 陈列 → 关键卖点 → 必要角度或使用演示 → 商品收尾 | 信息清楚、颜色与材质忠实；无需为展示背面强行加入拿起翻转再放下 |
| UGC 真人 | 使用场景或问题 → 真正操作 → 可见结果 → 自然推荐 | 可选手机手持、自然光、生活背景和适量停顿；不强制造失误、洒漏、脏污或口误 |

默认电商/UGC 为 15 秒、9:16，用户已给规格则沿用。15 秒常从 3–4 镜起草，30 秒常从 5–6 镜起草，均为可调整建议，不能以镜数或最低秒数代替动作可执行性判断。先给动作足够时间，再安排信息与镜头；无法容纳就删减次要展示、拆镜或说明需要更长时长，不加速硬塞。

摄影机可以固定、平移、环绕或手持；匀速运动本身不违反物理。必须分清摄影机移动和商品移动。不能让本应静置的商品为了展示角度自行旋转；使用转台时明确转台支撑与驱动。

## 文字、声音与证据

- 核心文字在对应镜头点名，给正视角、足够尺寸、清晰焦点和停留时间，避免手指遮挡。不能承诺靠“锐利可辨”保证文字准确；条码、二维码、配料表等需准确时使用真实资产与后期校验。
- 电商展示、商品介绍、种草或带货任务，先判断一句简短口播是否能补充购买信息；有明确介绍需求时，应安排人声，不把“无台词”设成默认。人物在画面内且适合直接表达时用出镜口播；画面以商品或手部为主时用画外音。只有用户指定纯视觉/静音，或已确认人声不会增加有用信息时，才明确写无台词、无旁白。
- 用户给逐字台词时直接组装到提示词，按其要求保留原文；用户给卖点方向时，将其写成针对该商品的自然口播，不要求用户先写完整文案。先表达产品特点和实际价值，再安排演示；不要用“给你看清楚”“细节都在这里”等镜头复述替代用户提供的卖点。用户确认的“佩戴舒适、滋润、折叠收纳”等可以用于本次文案，即使静态图不能显示这些特点；不自动扩写为长期保证、量化效果、亲身测评或其他功能。
- 只有用户资料和图片都没有给出有效卖点时，才采用有限的外观介绍，并在正文外指出具体缺项。App 演示缺少功能、机械动作缺少结构时，只暂停依赖缺项的部分，不编造界面、折叠路径或测试结果；其余提示词继续完成。不能把带占位符的模板标为可直接生成。
- 台词用自然、简洁的日常语言，直接服务于商品理解或选择；删掉空泛赞美、口号、重复画面动作的旁白和无信息寒暄。台词不必把镜头里已经看见的每个动作再念一遍，可以补充用途、选择依据或可核实的特点。写清说话人、逐字台词、出现时段、画外音或出镜口播；出镜口播按需注明口型同步。
- 按实际说话窗口估时，给停顿和呼吸留余量。15 秒围绕一个核心利益，常用一至两句，30 秒可容纳分段讲解；句数不是硬上限，先把用户主卖点讲清。动作复杂、说话较慢或用户另有要求时相应调整；必要时缩短表达或使用画外音，不加速硬塞。
- 音效对应真实材质和发生时刻。握住纸盒只有轻微摩擦，落桌接触才有落定声；声音不能暗示画面里没有发生的碰撞、开封或倒液。
- 本地默认显式决定人声、音效、BGM 三项。对商品介绍任务应优先写明台词及其时段；确需纯视觉时再写“全片无台词、无旁白”。音效和背景音乐也分别说明有无及其作用，不能将无台词推定为无音效或无音乐。
- 音色参考必须实际上传且当前输入模式允许；素材无法使用时不写空引用。

## 表达边界

保留商品真实用途、操作因果和可核验卖点，不虚构测试结果、使用体验、认证、销量或效果。美妆、健康等效果描述不得从素材无法证明的结论推导；采用可见的质地、涂抹、清洁等事实时也不能伪造对比证据。不得编造授权或素材来源。

若操作涉及危险模仿、伤害或其他平台限制，先采用真实、安全的操作设计，或结果/反应镜头，保留必要信息；无法保留时说明差异。不能仅用谐音、拆字、外语或影子重现被限制的细节，不能保证通过审核，也不维护所谓通用违禁词表。
