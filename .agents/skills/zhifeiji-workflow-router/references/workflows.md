# 组合工作流与交接规范

这是路由组合规范。原始创作细节始终从 [源文件索引](resource-map.md) 对应的实际 MD 读取；S15 另读完整执行 TXT。用户只需要某一阶段时，直接进入该阶段。

## 如何选流程

| 已有输入 / 想做的事 | 工作流 |
|---|---|
| 小说 → 多集短剧（横屏或竖屏） | W01 |
| 可拍剧本 → 电影短片资产与视频提示词 | W02 |
| 对白或情绪 → Kling演员表演 | W03 |
| 原创IP → 二维 / 风格化三维角色与海报 | W04 |
| 人物插画 → 高写实肖像、全身、三视图 | W05 |
| 场景图 → 电影主图、同场景多视角 | W06 |
| 人物 / 服饰 → 商业写真与口播 | W07 |
| 机甲 / 载具 / 道具 → 技术设定板 | W08 |
| 现有剧本 → 诊断、修正或资产提取 | W09 |
| 已有图 → 静态改角度或视频运镜 | W10 |
| 白模视频 → 正式资产替换提示词 | W11 |
| 一句话 / 当前画面 → 故事板或剧情组图 | W12 |
| 人物描述 / 已有资产 → 美工优化与建模参考提示词 | W13 |
| 预设 15/30 秒片段 → 小墨 6.3 分镜 → Seedance 2.5 提示词 | W14 |

## W01｜小说到多集短剧

1. [S15](resource-map.md#s15)：读取使用入口、完整指令 TXT，并按任务读取改编模式、输出类型、短剧规则。S15 的竖屏默认不覆盖用户指定的 16:9；后续镜头构图按用户画幅设计。
2. 用户要多集时建立人物/关系/时间线/伏笔档案 → 分集规划 → 按选定输出类型生成正文。拍摄稿/AI分镜读取现有剧本格式 MD。保留同一故事档案，不把每批剧本当作独立故事重写。
3. 仅当剧本有抽象心理、小说体、无法拍摄等问题，或用户要求诊断时，加 [S20](resource-map.md#s20)。已经合格不重复“治疗”。
4. 用户还要做资产：进入 [S03](resource-map.md#s03)，再按角色/场景/道具选择资产模块。
5. 用户还要视频提示词：已预设每片段时长、画幅和清晰度，且要求小墨 6.3 逐镜与 Seedance 2.5 最终正文时，转 [W14](#w14)；其他任务按目标选择 [S21](resource-map.md#s21)、[S18](resource-map.md#s18) 或 [S08](resource-map.md#s08)。

**停止点**：用户只要分集规划/剧本，不自动继续做图片或视频。
**交接**：故事档案、剧本版本、人物知情与关系变化、伏笔、服装/伤情/道具状态。
**缺项**：S15的校验脚本未附，使用人工格式检查，不报告脚本通过。

## W02｜可拍剧本到电影短片制作材料

1. 剧本已可拍则直接用；需修正才用 [S20](resource-map.md#s20)。
2. [S03](resource-map.md#s03) 拆角色/场景/道具并固定 `@CH/@SC/@PROP` 编号。
3. 用户要统一画风、参考图或色卡时用 [S11](resource-map.md#s11) 定调。传入已确定风格时不重复定调。
4. 按资产需要分支：写实人物 [S16](resource-map.md#s16)；CG/服装 [S10](resource-map.md#s10)；机械技术板 [S14](resource-map.md#s14)；一般电影场景 [S06](resource-map.md#s06)；森林荒漠遗迹定向场景 [S05](resource-map.md#s05)。不是每次都跑完这几项。
5. 空间需要补足时选 W06；已有完整多机位场景则跳过。
6. 只选择一个最终视频主格式。预设片段参数并指定小墨 6.3＋Seedance 2.5 时，执行 [W14](#w14)；其他目标按下列主格式选择：
   - Seedance 2.0完整剧本精细逐镜 → [S02](resource-map.md#s02)。
   - Seedance 2.0短片段扩写 → [S07](resource-map.md#s07)。
   - Seedance 2.5动作多镜头 → [S18](resource-map.md#s18)。
   - Seedance 2.5竖屏情绪对白 → [S21](resource-map.md#s21)。
   - Kling 3.0人物表演 → [S08](resource-map.md#s08)。

**已有分镜表**：直接继承数量、顺序、景别和运镜，不重拆整片。
**交接**：稳定资产清单、实际参考图、色卡/风格字段、镜头目的、空间位置与前后镜状态。
**产物边界**：这里可交付制作材料和提示词；实际媒体生成需要可用工具。

## W14｜预设片段的小墨 6.3 分镜到 Seedance 2.5

适用：用户在分镜前确定每条生成视频的时长规格（如 15 秒或 30 秒）、画幅（16:9 或 9:16）和清晰度（如 720p），并选定 [E24 小墨个人分镜 Skill 6.3](resource-map.md#e24) 作为逐镜导演规范。用户只给统一规格时，不必预先指定片段总数；片段边界和镜头归属在分镜规划时随剧情节拍确定。若用户已给片段边界，直接继承。每条片段可以有多个镜头，不在分镜完成后另做镜头归组。用户给出的参数优先；不要把示例值当成其他任务的默认值。

从[短剧工作流Skill](../../short-drama-workflow/SKILL.md)进入时，可由系统先根据小说、剧本和表演估时确定集数与片段规格，再执行本流程；该技能的最终视频提示词正文预算为 2000 字符以内，与 S18 适配器的本地约定一致。当前单 MD 导出按[精简导入格式](../../short-drama-workflow/references/compact-import.md)保存资产图片提示词和片段绑定，不预写尚未导入的真实参考图编号；实际接口若更严，仍以接口限制为准并回到片段规划，不删关键剧情表演。

该短剧工作流目前默认每条生成片段 30 秒、6–8 镜、5–7 次明确硬切；其[项目策略](../../short-drama-workflow/policy.json)与[可机检格式](../../short-drama-workflow/references/validation-contract.md)覆盖适配器的默认时间段数量建议。每个硬切镜头在最终正文保留单独时间行，不因压缩为少量叙事段落而丢失。用户日后指定新默认值时更新策略与校验。

1. 开工前登记时长/画幅/清晰度规格。按可拍剧本的因果节拍，在分镜规划时划出片段编号与边界；每个片段明确开场事实、必须发生的事件、对白、结果和出口事实。用户已经给出逐片段边界时沿用。内容放不进指定时长时，在镜头设计前调整剧情分配并说明问题，不靠异常语速、删原句或无因加速硬塞。
2. 继承 [S03](resource-map.md#s03) 的稳定资产身份；空间不足时借鉴 [S19](resource-map.md#s19) 的场景锚点和保守补全。先做片段一致性卡：每个角色记录稳定 ID、真实参考图/已确认母版、可见身份特征（脸型、发线和发型、体态、服装版本及识别性配饰）；每个场景记录稳定 ID、真实参考图、固定地标的左右/前后关系、出入口、材质和光源方向；关键道具记录 ID、外观识别点、初始持有人与左右手。未确认的背面、脸部或隐藏空间只列为待定/提案，不写成既定事实。再记录人物的世界位置、关系轴线、移动路线和视线。S19 的环境反打不自动等于人物对话正反打。
3. 对每个预设片段读取 E24 原文并设计连续编号的逐镜分镜。执行它的物理可行性、180°轴线、视线/景别/运镜衔接、对白反应、镜头经济性和短剧视感规则。原版禁止一镜到底；仅有一两次切换的草稿默认退回重拆，除非镜头已完整承载本片段的不同信息与表演节拍；不得加无信息切镜凑数。原文的“全片/每集/每场”配额按其对应范围统筹，不对每条 15/30 秒片段重新强制凑足全片运镜种数。遵守原版优先级：物理可行性 > 叙事情绪 > 多样性指标。
4. E24 原版明确不计算时长，因此另建**已划定片段内**的镜头时间码表，给已设计镜头分配起止时间。时间码一律为整数秒（如 `0-3秒`、`3-6秒`），从 0 连续覆盖到片段终点，不得有小数、空档或重叠；同时核对对白自然发声时长、切点与动作结果。E24 原版分镜稿仍保持其仅有镜头序列的格式。时间码与片段归属随分镜完成，不在提示词阶段决定镜头如何归组。
5. 逐片段交给 [S18 的 Seedance 2.5 通用提示词生成适配器](resource-map.md#s18)：把逐镜信息整理为该片段的一条最终正文，分离画幅/时长/清晰度等生成参数；只有实际存在且本次上传的参考图才可映射图片编号。当前短剧工作流的单 MD 导出没有图片附件，【参考】只写已绑定的资产代码及可见职责，待目标应用生成并批准图片后再建立真实图片映射。公共规范只写本片段不变且**具体可见**的身份/服装版本、场景地标与光向，道具持有人、站位、动作和表情的变化写进对应时间段。单写“人物场景保持一致”不算完成一致性约束。保留台词、动作因果、主要运镜、入口与结束状态；逐镜核对原镜头编号是否在最终时间轴保留必要切点和信息职责。独立 W14 与短剧工作流均按 2000 字符预算；短剧工作流另按 5–7 次硬切规则压缩重复措辞，但**不合并已规划的硬切镜头行**。若仍超适用预算，回到第 1 步重排剧情节拍与片段边界，再重做分镜；用户已固定片段边界时不擅自增加。E24 镜头序列是中间稿，不把它和 S18 v3.5、S21 的最终模板全文并列投给模型。
6. 片段之间逐对核对出口→入口的人物位置、动作姿态、服装/伤情、道具持有、空间轴线、光源、对白与声音。原版 S18 v3.5 的尾帧承接句仅在确有可用尾帧且所用工具支持时使用；未生成或未验收的尾帧仍是文字计划，不写成实际图片引用。实际媒体生成后再验收画面、运镜、口型和声音。

**交接**：片段规格与分镜时已确定的片段编号/边界、逐镜分镜、每镜时间范围、一致性卡（稳定 ID→真实参考图→可见不变量）、片段入口/出口事实、原镜头→最终时间段/切点覆盖关系、最终 Seedance 2.5 正文及其字符数。16:9 和 9:16 应分别编排构图，720p 是生成参数，不用“高清”一词冒充实际分辨率。

## W15｜打斗路由（短剧工作流阶段 3.5）

短剧片段含打斗时的增强路由，插在小墨 6.3 分镜（W14）之后、提示词编译之前：**A 全打斗段**（完整攻防交换链）转一镜到底拍点制，打斗 skill 战斗语法优先（388 攻防五结果/受击反馈链/连招三层＋花128 二十一拍与三起两落曲线），豁免镜数带与硬切、默认按第三档 4500 字符；**B 混合段**只对交锋镜做攻防增强，其余走原规范；**C 威慑对峙**（围而不攻/只监视不攻击）跳过。画风统一不引入水墨，特效改用剧内母题；上下文衔接三接口（入镜承接/出镜收尾/跨段战损）为硬要求。判定标准、优先级裁定表、排除清单与源文件选型见 short-drama-workflow [打斗路由规范](../short-drama-workflow/references/fight-router.md)。触发语：打斗路由、动作戏增强、这集有打斗。

## W16｜Wan3.0 提示词轨（生成模型双轨）

按生成模型选轨：Seedance 2.5 走既有 S18＋小墨规范；**Wan3.0** 走 [Wan3.0 提示词规范](../short-drama-workflow/references/wan30-prompt-spec.md)（写法标准）与 [Wan3.0 通用提示词生成适配器 v1.0](../short-drama-workflow/references/wan30-adapter-v1.0.md)（编译器手册，与 S18 同构）——20000 字符上限（目标 3000–8000，防稀释）、2–30 秒弹性时长／智能时长、0.5 秒拍点粒度、多模态参考（10 图＋5 视频作动作/运镜/特效参考＋5 音频作音色/口型驱动＋文件参考）、一致性显式枚举条款、@Image/@Video/@Audio 绑定与 `<音效>` 点标记、编辑指令整改分级。分镜层与六视角质检两轨共用；机检 `--model` 分支就绪前 Wan 轨片段人工核数。触发语：Wan3.0、万相轨、换模型写提示词。

## W03｜演员表演与对白

主模块：[S08](resource-map.md#s08)，面向Kling 3.0。输入关系、场景、台词与已有角色图 → 识别触发点 → 设计视线、微表情、呼吸、动作幅度与停顿 → 输出一段成品演员调度提示词。

- 已有角色图就使用，不重新制作人设。
- 商业写真参考尚未准备时可加 [S04](resource-map.md#s04)；插画转写实身份母版可加 [S16](resource-map.md#s16)。
- 若用户指定Seedance，继承这些表演字段作为辅助分析，最终由S07/S18/S21中的适当模块组织；说明这是格式适配，不声称执行Kling生成。
- 用户未指定模型时明确推荐Kling路由；不把它写成任何模型通用的最终模板。

**交接**：表演者、交流对象、首帧姿态、视线目标、台词原文、情绪变化和动作预算。

## W04｜原创IP角色开发与风格化三维

主模块：[S01](resource-map.md#s01)，分三个文件读取：
1. 二维设计、素体、脸型、五官 → `01-角色设计核心流程.md`。
2. 已有完整二维定稿，转风格化三维/SSS皮肤/重打光 → `02-三维与皮肤提示词.md`。
3. 已有角色定稿，制作摄影组图/特写/双人海报 → `03-摄影与海报提示词.md`。

可直接从用户已有定稿进入后两步。视觉编号索引仅在用户有相应图库时读取；本目录没有该图库。
**分流**：用户要影视级高写实而非卡通三维时进入W05，不套用皮克斯/C4D风格。

## W05｜插画到高写实人物资产

主模块：[S16](resource-map.md#s16)。

原插画 → 纯黑白结构线稿 → 用户要求的脸型/眼型局部调整（可选）→ 正面肖像 → 确认并记录脸部母版 → 写实全身 / 人物三视图（按用户要求选择）。

- 用户明确“锁定这张脸”，或已有可信的会话确认，才进入全身与三视图。不要重复请求已有确认。
- 结构以最终线稿为准，颜色以原彩色图为准，面部身份以确认肖像为准；三类参考职责不互换。
- 人物三视图的左脸部特写+右正侧背布局采用S16；CG人设上方脸部+下方三视图采用 [S10](resource-map.md#s10)。
- 只有用户要尺寸、规格、机械细节技术板时才转 [S14](resource-map.md#s14)。

**交接**：原图、最终结构线稿、确认肖像、服装/配色与当前锁脸状态。

## W06｜场景主图与多视角空间

先区分产物：

- **电影主图+三/五/九格固定场景资产板**：[S17](resource-map.md#s17)。
- **反打/左/右/鸟瞰等独立环境图**：[S19](resource-map.md#s19)。
- **多机位菜单/全景、角色或产品多视图**：[S09](resource-map.md#s09)。
- **三张事件前后或情绪变化的独立叙事图**：[S06](resource-map.md#s06)，不是固定空间资产板。

S17路径：事实原图 → 电影化主图 → 核对主体、构图与地标 → 将合格主图设为共同母版 → 按指定版式制作资产板。已有合格电影主图时跳过前两步。

**依赖处理**：S17四份references未附。定位请求可直接给准确主MD及缺项；执行请求先说明当前可依据主MD做局部实现，不声称完整加载缺失模板。需要替代时使用S06电影化+S09多机位，或S19独立空间图，并明确布局与原S17完整流程不同。缺失部分后来补齐则读取恢复完整路径。

**交接**：事实原图、合格主图、地标/左右/通道/高差/光向/天气/色彩、隐藏区域的统一最小推断。

## W07｜商业人像、服饰与口播

[S04](resource-map.md#s04) 组织美妆/护肤/写真摄影方案 → 需要服装与穿搭板时加 [S10](resource-map.md#s10) → 需要跨图/跨片统一色卡时加 [S11](resource-map.md#s11) → 需要Kling口播/人物对白时加 [S08](resource-map.md#s08)。

只要服饰商品板，直接S10；只要静态商业写真，停在S04。高写实人物身份母版不足时先走W05。
**交接**：同一人物参考、妆发、服装、配饰、灯光、镜头与台词；不得用新写真结果悄悄更换角色身份。

## W08｜模型技术设定板

主模块：[S14](resource-map.md#s14)。输入机械/载具/武器/产品等模型图 → 识别轮廓、结构与材质 → 正侧背三视图 → 尺寸或比例、细节框与规格区。

- 用户未提供实际尺寸，使用比例或未知标记，不从一张图推导精确工程尺寸。
- 若只是从剧本拆出道具，先 [S03](resource-map.md#s03)；已有明确道具参考则直接S14。
- 人物身份板不进入此流程；人物/异形/机械人体的干净身份三视图转W05。
- 这类图片是视觉技术设定材料，不将推断结构声明为可制造CAD数据。

## W09｜现有剧本的修正与拆资产

- “只诊断哪里不行” → [S20](resource-map.md#s20) 诊断报告，保留原文。
- “诊断并修正成可拍剧本” → S20诊断+修正，不插入多余确认。
- “改成短剧分集/重构故事” → [S15](resource-map.md#s15)，不是仅S20格式处理。
- “只提取角色道具场景” → [S03](resource-map.md#s03)，不默认先改剧本。
- “检查场序、闪回和动作格式” → S15现有 `screenplay-format.md` 与质量量表；不要运行不存在的校验脚本。

## W13｜人物资产美工与建模参考

主补充：[E23角色资产提示词](../../character-asset-prompts/SKILL.md)。适用于“提高人物美工、优化人物提示词、人物建模参考、脸发/体态/服装材质深化”。

1. 读取已有文本、真实参考和确认状态。若来自完整剧本，先以S03提取事实并沿用`@CH-001`；已有档案直接进入本阶段。
2. 读取E23设计规则，按“身份锚点→五官/体态→妆发→服装剪裁/连接→配色/材质→布光”细化获授权变量。未知结构为提案，不覆盖已确认项。
3. 依据任务选辅助：S01局部五官/风格化3D、S10服装结构、S04商业妆发与皮肤、S11项目风格；只读相关部分。真实插画转换以S16为主并沿用锁脸流程，CG优化不转真人。
4. 建模参考读取E23的`references/modeling-quality.md`。采用用户/项目布局，否则用16:9纯白、左严格正面身份特写＋右完整正/左侧90度/背面全身；全身结构清晰、同尺度同服装。明确选原版S16/S10时用相应版式，不混写。
5. 编译可复制中文提示词、必要负面与锁定卡，身份不变量和服装版本分开；按用户输出要求删掉不需要的说明。计数是写作预算检查，不是图像质量证明。

**交接**：角色ID、年龄/脸发/体态锚点、服装版本与固有色、当前媒介、图像参考职责及实际路径、允许修改项、背面补全与未确定项、草案/候选/确认状态。

**验收**：脸部和侧面结构一致、人体比例合理、发型与衣层连接连续、左右位置正确、材质可辨、版式完整。没有生成图时只验收文字；不声称完成拓扑/UV/绑定或图片确认。

W02人物资产分支、W04角色开发、W05写实转换和W07人像服饰需要提高人物美工时接入本流程的相关阶段，不强迫重跑已有确认资产。
