# H3 素材引用规范（资产 → 参考标签）

适用：MiniMax H3 轨（base 三字段／Ref2VA 六段式）的正文里，资产怎么变成模型认识的标签。官方原文见 `25 minimax H3官方skill/skills/h3-prompt-writing/references/`（不改写）；本文件只定义**本目录资产到 H3 标签的编号与登记规则**。

## 一、四类标签

| 标签 | 指什么 | 本目录来源 | 官方上限 |
|---|---|---|---|
| `<Subject N>` | 可复用的可见内容：人物、场景、道具、风格、动作 | 固定资产条目（`CHAR_/LOC_/PROP_`） | 无数量上限，随引用素材总量约束 |
| `<Picture N>` | 一张真实参考图（首帧／尾帧／角色身份／场景母版） | 片段的 `#### 首帧提示词`／`#### 尾帧提示词` 出图并批准后上传的图 | 图 ≤9 |
| `<Video N>` | 参考视频（剪辑源、续接起点、整片时间结构） | 用户提供的参考视频 | ≤3 段，每段 2–15 秒，总 ≤15 秒 |
| `<Audio N>` | 参考音频（音色参考或整轨复用） | 用户提供的音频或声线母版样本 | ≤3 段，每段 2–15 秒，总 ≤15 秒 |

标签一经定义就在该片段正文里保持同一含义；跨片段编号可以不同，但每个片段的映射必须在内部表登记。

## 二、编号规则（确定性，可机检）

1. **`<Subject N>` 按片段绑定顺序编号**：`角色`（绑定行出现序）→ `场景` → `道具`，各自从 1 开始，片段内连续不跳号。
   - 绑定 `角色：CHAR_01,CHAR_02` ＋ `场景：LOC_01` ＋ `道具：PROP_01` ⇒ `<Subject 1>`=CHAR_01、`<Subject 2>`=CHAR_02、`<Subject 3>`=LOC_01、`<Subject 4>`=PROP_01。
   - `线索`（`CLUE_`）是叙事线索，未必是可见主体；可见时也占一个 `<Subject N>`，不可见时只留在剧本与内部表，不进正文。
2. **`<Picture N>` 按图片用途编号**：`<Picture 1>` = 该片段的首帧图（对应 `#### 首帧提示词`），`<Picture 2>` = 尾帧图（对应 `#### 尾帧提示词`），其余参考图按上传顺序顺延。
3. **`<Video N>` / `<Audio N>`** 按实际上传顺序编号，从 1 开始。
4. 四类标签各自独立编号空间：`<Subject 2>` 与 `<Picture 2>` 可以同时存在，互不占用编号。

## 三、绑定与登记

| 内容 | 写在哪 | 说明 |
|---|---|---|
| 资产代码绑定 | 精简制作包的绑定行 `角色：CHAR_01` / `场景：LOC_01` / `道具：PROP_01` | MD 里唯一出现资产代码的地方 |
| 资产 → `<Subject N>` 映射 | **内部 04/05 表**（不进 MD） | 如 `CHAR_01 阿泽 → <Subject 1>`；映射表是交付追溯依据 |
| `<Picture N>` 对应哪张图 | 片段的 `#### 首帧提示词` / `#### 尾帧提示词` 字段 | 出图并批准后上传的图即该编号 |
| 未上传的真实图片 | **不预写编号** | 正文只写资产可见不变量（外观、服装版本、地标、光向），编号等图批准后再补 |

正文里**不出现** `@CH-001`、`CHAR_01` 这类代码：模型只认 `<Subject N>`。代码只留在绑定行与内部映射表。

## 四、机检规则（`validate_compact_package.py --model h3`）

1. 片段有 `#### 首帧提示词` ⇒ 正文必须出现 `<Picture 1>`；没有该字段 ⇒ 正文不得出现 `<Picture 1>`。
2. 片段有 `#### 尾帧提示词` ⇒ 正文必须出现 `<Picture 2>`；没有该字段 ⇒ 正文不得出现 `<Picture 2>`。
3. 正文出现的 `<Picture N>`（N≥3）必须有对应的已登记参考图来源，否则报错。
4. 绑定的 `角色 + 场景 + 道具` 数量必须等于正文 `<Subject N>` 的数量，且编号从 1 连续；不等即报错（映射漏登记或凭空多主体）。
5. `<Subject N>` 在 Ref2VA 模式必须出现在 `subject_definitions` 里；`retention_analysis` 不写说话人 ID。
6. 未上传图片不得预写编号：没有首帧/尾帧字段时出现 `<Picture N>` 直接判错。

## 五、写法要点

- `<Subject N>` 首次出现时给足可复现特征：外观、服装版本、地标、光向、材质；Ref2VA 模式在 `subject_definitions` 定义，base 模式在正文首次出现处定义。
- `<Picture N>` 只在「该图确实作为目标帧或锚点」时出现；仅作风格参考的图不要占用编号。
- 同一主体的换装是同一 `<Subject N>` 的连续性设计，不另立编号。
- 台词与画面可见文字保留原语言并逐字照抄；资产代码不进入台词。
