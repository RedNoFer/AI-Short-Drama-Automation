# 分镜视感自查表（可机检格式）

本文件是「小墨 6.3 视感自查」的**格式定义文件**。自查表以前是散文式自述，只能靠评审事后读；本文件把它改成可统计的表，由 `scripts/crosscheck_storyboard.py` 在**阶段 3 出口门**当场核对声明值与实际值，不合格不得进入阶段 4。

规则权威仍在 E24 原版与 [项目策略](../policy.json) 的 `video.prompt_quality_tiers`；本文件只定义「怎么记才可校验」。

## 为什么必须做成表

散文自述有两个漏洞，且都只能靠最后评审发现：

1. **声明无法验证**——「固定镜头 0 个（≤1 达标）」这句话，没人能确认逐镜表里是不是真有固定镜头；
2. **统计靠手算**——固定占比、焦段种数、机位角度种数、连续固定、连三近景，全部可以机械统计，手算就会错，错了也没人查。

表化之后：作者照表填，脚本照表算，声明与事实不一致当场判错。

## 必需结构

每个片段（或每集分镜文件）必须同时有**一段统计行**和**一张逐镜表**。

### 1. 统计行（单行，键值对，用「；」分隔）

```text
视感统计：镜数=8；固定=0；固定占比=0%；焦段种数=5；机位角度种数=7；侧45占比=38%
```

- **六个必需键**：镜数、固定、固定占比、焦段种数、机位角度种数、侧45占比。缺键即判错；顺序不限。
- 百分比写 `38%` 或 `38.5%`，脚本按 ±1pp 容差比对；`机位角度种数` 允许 ±1（写法差异），其余精确比对。
- **不设「常规占比」**：E24 的「常规镜头≤30%」没有可机械判定的定义（固定／环境／标准焦段都能解释成「常规」），硬算会误杀正常分镜。该条仍由评审按 E24 原版判断，不进机检。

### 2. 逐镜表（列名可中英混写，但必须含这四列）

| 镜 | 景别 | 焦段 | 机位 | 运镜 | 景深 | 固定 |
|---|---|---|---|---|---|---|
| S01 | 大远景 | 24mm | 正面平视 | 极缓慢横移 | 深 | 否 |
| S02 | 全景 | 35mm | 侧45°平视 | 极缓慢横移 | 深 | 否 |
| S03 | 中近景 | 50mm | 侧45°微俯 | 手持微晃跟拍 | 浅 | 否 |
| S04 | 特写 | 85mm | 侧45°平视 | 固定 | 浅 | 是 |

- **必需列**：景别、焦段、机位、运镜。缺列即判错。
- **可选列**：镜（镜号）、景深、固定、备注。`固定` 列缺省时由「运镜」列推断（含「固定／静止／不动」且不含「微」即算固定）。
- 表头必须出现在该表第一行；`|---|` 分隔行自动跳过。

## 列取值规范（脚本按此归一化）

| 列 | 允许写法 | 归一化 |
|---|---|---|
| 景别 | 大远景／远景／全景／中景／中近景／近景／特写／大特写 | 最长匹配，其余视为「未识别」并判错 |
| 焦段 | `24mm`／`24 mm`／`24` | 取整数毫米；写「广角／标准」而无数字视为未识别并判错 |
| 机位 | 正面／侧45°／侧90°／侧背／背面／俯拍／仰拍／过肩，可带俯仰后缀 | 去空格、全角转半角后按字符串计种数 |
| 运镜 | 自然语言短语 | 只用于判定「固定」与「侧45」占比，不参与种数统计 |
| 固定 | 是／否／重锤凝固／留白长镜 | 是／重锤凝固／留白长镜计入固定；后两者标记为「例外固定」 |

**例外固定**：E24 允许「重锤凝固＋留白长镜」作为固定镜头例外。在 `固定` 列或备注里写 `重锤`／`留白`／`凝固` 即标为例外，不计入 ≤10% 配额，但**不计入也不代表可以连续出现超过 1 个**——连续固定仍按「例外也算连续」检查。

## 脚本判定的项目

| 检查 | 判定 | 级别 |
|---|---|---|
| 统计行存在且七个键齐全 | 缺键即错 | 阻断 |
| 逐镜表存在且含四列 | 缺列即错 | 阻断 |
| 景别/焦段可识别 | 出现「未识别」即错 | 阻断 |
| 声明值 vs 实算值 | 镜数/固定/焦段种数精确；百分比 ±1pp；机位角度种数 ±1 | 阻断 |
| 固定占比 ≤10% | 按非例外固定计 | 阻断 |
| 最长连续固定 ≤1 | 例外固定也计入连续 | 阻断 |
| 连续三近景 = 0 | 近景／特写／大特写／中近景连三 | 阻断 |
| 焦段种数 ≥4、机位角度种数 ≥6 | 第二档及第三档 | 阻断 |
| 侧45° 出现 | 第二档及第三档 | 重要 |

## 使用方式

```bash
# 校验（阶段 3 出口门会自动调用，也可单独跑）
python3 .agents/skills/short-drama-workflow/scripts/crosscheck_storyboard.py 创作输出/作品名/内部/04-片段规划与逐镜表.md

# 从逐镜表反算统计行，粘回文件（作者不用手算）
python3 .agents/skills/short-drama-workflow/scripts/crosscheck_storyboard.py 创作输出/作品名/内部/04-片段规划与逐镜表.md --emit

# 第一档项目只校验声明一致性，不套小墨配额
python3 .agents/skills/short-drama-workflow/scripts/crosscheck_storyboard.py <文件> --tier tier1_standard
```

退出码 0 表示声明与事实一致且配额达标；非 0 逐条列出不一致项。脚本只证明「统计没算错、配额没超」，**不判断运镜是否有叙事职责**——那仍是独立评审的职责。
