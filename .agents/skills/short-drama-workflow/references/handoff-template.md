# 交接包实例模板（总控 → 子任务）

[多智能体隔离执行](multi-agent-execution.md)的填空式交接包。新项目每个阶段首单直接复制对应模板，花括号由总控填写。规则：给路径不给全文；白名单外文件执行员不得读取；执行员只写「产出」列出的文件。

## 阶段 1 执行员交接包（全剧改编）

```text
【阶段】1 全剧改编
【范围】小说《{作品名}》全部章节（或第{x}–{y}章，注明部分制作）
【必读（白名单）】
- 小说源文件：{绝对路径，与输入单登记一致}
- 路线源文件：S15 03-ChatGPT完整指令.txt ＋ 知识库（全部）＋ {按体裁路线条件加读 E26 对应文件：R-AI=小说转AI影视剧本skill.md / R-SERIES=短剧系列剧本创作skill.md / R-MICRO=微电影剧本创作skill.md / R-PLAIN=无}
- {skill根}/references/story-evaluation.md
- {skill根}/references/runtime-planning.md
- S15 {S15主文件绝对路径} 全文；知识库：{short-drama-rules/screenplay-format/quality-rubric/adaptation-modes/output-profiles 路径}
【上游输入】内部/00-项目输入单.md（画风、画幅、声音路线、用户锁定项）
【产出】内部/01-故事档案与分集规划.md；内部/02-逐集拍摄剧本.md
【依据原句】本条派单里每个事实约束的正文出处（逐字原句＋集/片段/镜头）；给不出原句的约束不得下派

【闸口】① 估时三表齐（故事/剧本/片段边界）② 剧情独立评审按「通用层＋本路线层」通过 ③ 无记忆引用原文 ④ 体量与形式脚本检查通过（validate_screenplay_volume.py，R-AI 口径）
【禁止】不读阶段2及以后规范；不写资产提示词与视频提示词；不预设集数
【返回】结论/证据路径/未决问题/估时区间与集数统计
```

## 阶段 2 执行员交接包（资产与声线）

```text
【阶段】2 资产设计
【范围】{角色数}角色、{场景数}场景、道具线索清单（S03 拆出的 ID 总表）
【必读】references/asset-image-production.md；references/voice-and-dubbing.md；
S03 {拆资产主文件与配置文件路径}；E23 角色资产技能；按需 S10/S16/S11/S19
【上游输入】内部/01、内部/02（剧情需要的形象/空间事实）；内部/00 用户锁定画风
【产出】精简制作包固定资产区（角色/场景/道具/线索图片提示词）；内部/03-资产与空间设计.md（视觉母版、空间卡、声线母版）
【依据原句】本条派单里每个事实约束的正文出处（逐字原句＋集/片段/镜头）；给不出原句的约束不得下派

【闸口】① 图片提示词含 16:9 与四视图/全景版式要求 ② 身份锚点 3–5、同角色换装同母版 ③ 声线母版每发声角色 3–5 锚点、盲听可辨、旁白/混叠/低语定义齐 ④ 母版经用户确认冻结 ⑤ 角色美工账每角色一行、持物链逐道具一行（缺行门判错）⑥ 出口门 `--stage 2` 为 0 错误 ⑦ **隔离评稿人已出 内部/03b-资产评审.md**（本阶段放行条件，缺则门判错）
【禁止】不写实际图片已生成；不把声音锚点写进图片提示词；不预分配 @Image 编号
【返回】结论/证据路径/资产 ID 总表/未决问题
```

## 阶段 2 资产评审员交接包（隔离评稿人，不读下游）

```text
【阶段】2 资产母版独立评审（范围：{角色/场景/道具全集}）
【被审产物】内部/03-资产与空间设计.md；内部/04b-站位图/SCENE_LOC_*.json（命中风险闸门时）
【对照依据】references/asset-image-production.md（九块字段与阶段 2 出口条件）；references/voice-and-dubbing.md；references/outfit-variants.md；failure-cases.md#character-01、#proc-04
【五个对抗视角】
① 身份锚点：脸型骨相、眉眼鼻唇相对关系在正/侧/背三视图是否都成立（正面与侧面须是同一条连续轮廓）
② 妆造与饰件：素颜、无饰品是否显式写明；发饰固定位置能否接上背面
③ 服装与变体：服装三层是否可辨；命中换装条件是否登记为 PROP 变体并写归属
④ 声线母版：每发声角色 3–5 锚点、角色间反差、旁白/混叠/低语定义、声源方案；盲听能否辨人
⑤ 持物链：每道具一行（获取点→持有人变更→去向），是否存在「早于获取点出现」
【产出】内部/03b-资产评审.md：逐项结论＋证据（引用资产提示词原句）＋缺陷（位置/预期/现状/严重度/退回阶段）
【禁止】不改文件；不读阶段 3/4/5 产物；不接受「执行员自检通过」作为证据；不接受一句「通过」结案
【返回】结论(通过/需修改)、缺陷清单、评稿人标识（子任务 ID/模型）
```

## 阶段 3 执行员交接包（分镜，按集派单）

```text
【阶段】3 片段与分镜（本批：{E0X SH01–SH0n}）
【必读】references/story-evaluation.md；小墨6.3原版全文；W14 组合流程；动作戏加读 S18 v3.5
【上游输入】
- 内部/02 本集剧本段落；内部/03（资产 ID、空间卡、声线母版压缩版）
- 上一集末片段【收尾】与出口事实（站位/道具/光向/情绪）；本集下一集首镜入口事实
【产出】内部/04 本集条目（逐镜卡、整数秒时间轴、硬切运镜、出入口事实、空间与持手链）
【依据原句】本条派单里每个事实约束的正文出处（逐字原句＋集/片段/镜头）；给不出原句的约束不得下派

【闸口】① 每片段 6–11 镜/5–10 硬切，0→30 整数秒连续（H3 轨：4–15 秒单条、毫秒切点递增、0–6 硬切，见 policy.model_profiles.h3） ② 上下镜与跨片段衔接闭合 ③ 台词字秒比 ≤5（跨切注明）④ SPACE/SYNC 相关场景按反例清单核对 ⑤ 表演镜指派：按 micro-expression-layer.md 为≤2个表演镜登记原型/情绪极性/泄露方向，写入 04 表演栏 ⑥ **视感统计行六键齐全且与四列逐镜表实算一致**（`crosscheck_storyboard.py`，格式见 references/storyboard-selfcheck.md）⑦ 出口门 `--stage 3` 为 0 错误 ⑧ 打斗路由 A/B/C 逐片段落盘（阶段 3.5 门）
【禁止】不写最终视频提示词正文；不为凑切镜加无信息镜头
【返回】结论/证据路径/片段与镜头统计/未决衔接点
```

## 阶段 4 执行员交接包（视频提示词编译，按集派单）

```text
【阶段】4 最终提示词（本批：{E0X}）
【必读】references/prompt-review.md；references/voice-and-dubbing.md；references/compact-import.md；
S18 适配器 v1.0；references/failure-cases.md 相关条目
【上游输入】内部/04 本集逐镜表；内部/03（声线母版压缩版逐字可用、公共母版、资产职责）；
上下游片段出入口事实；本集小说原文（逐字）
【产出】制作包内本集各片段的 #### 视频提示词 text 块（四段结构）
【闸口（写每条时即时自检）】
① 四段：【参考】【公共总规范】【时间轴】【收尾】，无【参数】
② 时间行自然语言：`起-止秒，内容`；首镜直写开场，其后每行「硬切，」引出；镜头编号只存内部04表，正文不出现 `｜镜头…｜起始/硬切｜`
③ 七类声音标签+「口型」；台词逐字；声线锁定行只列本片段实际发声者且逐字取母版；④ 表演层：按 micro-expression-layer.md 把表演原型落成可见生理线索（每镜≤2个、片段≤4个、正常速度动词、非笑点剧情避用微笑歧义词）
④ 正文 ≤3000 Unicode（按档 2000/3000/4500；H3 轨 ≤6000，官方未设上限）；整数秒连续；5–10 硬切；【收尾】含下一条入口
【禁止】不预写 @Image；不改台词；不临场改音色；不删剧情凑长度
【返回】结论/每条字符数/引用资产清单/未决问题
```

## 阶段 5 总控与评审员交接包

```text
【总控机检（不派子任务）】
- python3 {skill根}/scripts/validate_compact_package.py {制作包绝对路径}
- python3 {skill根}/scripts/validate_novel_coverage.py {制作包} {输入单登记的源文件绝对路径}
- python3 {skill根}/scripts/tests/test_compact_validator.py
【评审员子任务交接包】
【阶段】5 对抗性独立评审（范围：{批次}）
【必读】被审制作包；内部/02、内部/03、内部/04；references/prompt-review.md；源小说文件
【视角】①剧情忠实与因果 ②表演与动作可拍性 ③空间与上下文衔接 ④声音（来源/口型/声线）⑤硬规 ⑥评估基准符合性（按交接包指定的通用层＋路线层逐项判定）
【评估基准】{路线名 R-AI/R-SERIES/R-MICRO/R-PLAIN ＋ 通用层 ＋ 路线层条目编号 ＋ 出处}（缺此项的评审记录无效）
【要求】默认稿件有问题、主动找反证；每条结论给位置+原文证据+严重度（阻断/重要/建议）+改法；全量不抽样
【禁止】不改文件；不接受「生产方说通过」
【返回】缺陷清单（含通过片段明示）+ 总体结论
【修复复验】执行员在最近通过快照上修复后，评审员全量复验（改动+相邻回归）；同一处两次不过→升级用户
```
