# 角色引用闭环验收

适用：阶段 3 登记预期出镜/发声与绑定；阶段 4 全套提示词完成后，以完整提示词集执行一次语义闭环评审；阶段 5 只核对最终包与已评审提示词的哈希和机械映射。旧包修订与续集按阶段 4 的全覆盖评审口径执行。验收对象是实际提示词正文，不以内部资产清单或机检通过代替。

## 逐段反向核对

1. 先读全部时间行，列出实际入镜者及实际具名声源；包括局部入镜、背影、镜面/回忆中的可辨角色、画外延续、心理独白和具名无词低语。不把只被台词提及、翻译解释中的姓名、人物姓名的同字词、未展示的回忆对象算成出镜者。匿名群演注明无独立身份、无正脸，不冒用已有角色。
2. 入镜者和具名发声者必须在该片段`角色：`绑定；每个已绑定角色在【参考】有对应`代码＝职责`，且代码在固定资产区有定义。H3按本段Subject映射逐项对照。禁止只从绑定清单正向检查，否则从名单漏掉的人会逃过全部后续检查。
3. 公共人物一致性只列本段需要引用的角色。复制全剧人物外观或声线到每段，不能靠追加绑定把多余人物“补齐”。声线锁定只列实际发声者，并逐字取母版；姓名或资产代码均可。只有呼吸、衣料声不能自动判定为对白；可闻低语与可辨台词分别写声音来源和口型状态。
4. 角色图确定脸、体态、妆发、饰件和默认装。公共层可用`姓名：身份外观遵循 CHAR_xx 人物参考图`，同码须已绑定并有参考职责项；不强迫重复服装文字。换装才绑定不同款的服装PROP，不能把默认装重复登记为变体。检查动作对衣服结构的隐含要求：裙装不能凭空用裤袋、短袖不能出现长袖袖扣、无外套不能拢外套、无包不能抓包带。修动作或引用已授权变体，不另造身份。
5. 实际入镜或参与动作的既有独立 PROP 要核对绑定与参考；回忆实画、湖面显影仍是可见画面。只被台词提到或藏袋未显露的物品不自动加图。新增持物先核是否与人物图已有物件为同一物，避免同一包/表/衣服重复资产。若提示词编译造成参考张数超限，修提示词或依已批准规则调整；若冻结的逐镜表本身需要超限资产，登记上游验收漏项并重开阶段 3，拆段或减少实际显示的独立资产。不得把漏图写成“文字兜底”后直接标通过；用户已确认的例外须单独保留风险，不能冒称图锚闭合。
6. 最终包改动后同步实际编译源、分镜绑定与母版；重建后字节/内容核对，防止旧源覆盖修复。

## 机检与独立评审分工

`validate_compact_package.py` 的CAST-01～04检查Seedance/Wan四段正文的已知姓名、显式声源、绑定、参考、公共身份及声线。代码声线与姓名声线等价；台词在前标签在后且只有一个候选角色时可识别。多角色同镜代词、泰语的中文义、无词声音等必须保守判断：不能根据识别失败就删除声线或误加人物。H3须结合其Subject/Speaker映射独立逐段核查，不把四段正文检查冒称H3已检查。

阶段 4 的初评在整套提示词机械检查通过后，由与起草方隔离的新上下文全量逐段反查，不能抽样、不能只读绑定行。必须记录提示词哈希、模型轨、集数/段数/镜数、每段实际人物/说话人/绑定/参考/声线/道具/服装版本与时间窗证据。含糊声源或未建资产须明确判定，不能用“保持一致”结案。内部落盘`角色资产引用独立复验_日期.md`，由05评审文件或索引引用；阶段 5 仅确认导出版本与该记录的哈希一致。

缺漏绑定、缺参考、冒出第二套造型、无法确定声音身份，均是本项验收阻断。修后重跑受影响范围的机检，并对变更提示词、相邻接口及相关共享依赖定向复验；未变且哈希一致的结论继续有效。提示词引用通过、应用实际提交参考图齐全、生成视频遵循，是三个不同状态；只能对实际完成的一层下结论。提醒必须逐项裁定或明确保留；存在未验范围时不能写“整包验收通过”。

## 最小反例

- 孟露有台词、角色和参考均漏：必须报CAST-01，不能因绑定名单没她就跳过。
- 角色已绑定但没参考职责：必须报CAST-02。
- 片段双人却复制四人外观：移除多余公共身份，不盲加两人图片。
- 台词“提到塔纳”或中文义“瓦塔纳坤”：提及不算塔纳出镜。
- 声线用CHAR代码、对白标签跟在台词之后：不能误删真实声线；歧义交独立评审。
