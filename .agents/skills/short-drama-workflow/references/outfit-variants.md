# 服装变体与首饰（outfit variants）

角色资产锁的是**身份**，不是一套穿遍全剧的固定衣服。场合、年代、身份、剧情一变，服装必须跟着变；变体要单独出图、单独登记、单独绑定，不能只写在角色资产里。本文件规定变体怎么设计、怎么进交付包、怎么被机检。

## 一、资产模型

| 层 | 载体 | 锁什么 | 出图 |
|---|---|---|---|
| **身份母版** | `### 角色 CHAR_xx｜姓名` | 脸型五官、发线发型、体态、年龄感 | 16:9 白底四视图（沿用本目录规范） |
| **默认服装** | 写在角色资产提示词的「固定服装：」段 | 常态场合的一套完整装（外层/内搭/下装/鞋/配饰） | 与身份母版同图 |
| **服装变体** | `### 道具 PROP_xx｜角色名·服装名` | 场合装/年代装/制服/礼服/孝服等 | 16:9 单张服装平铺图（俯拍平铺或隐形模特；**不含人体、人脸、模特**；道具只锁衣服） |

**变体是道具类资产**，因为导入模板只有角色/场景/道具/线索四类，每类只有一条 `#### 图片提示词`；道具是唯一能承载"独立第二张图"且被片段绑定的类型。模板不改版。

## 二、何时必须出变体（触发条件）

命中任意一条即必须出变体，不得沿用默认装：

1. **场合变化**：婚礼、葬礼、宴会、面试、答辩、开庭、入职、升学、探病、正式会面。
2. **年代跨度**：回忆、两年前、十年前、跨季、年代戏。同一角色在两个年代各出一套。
3. **身份/职务变更**：制服、工装服、军装、警服、白大褂、礼服、校服、囚服。
4. **剧情明确换装**：文本出现"换上""脱下""穿上""系上"等动作，或角色在戏内换了衣服。
5. **场合级配饰**：婚礼头纱、孝带、领带、腕花、头饰、盔甲、斗笠——首饰与服装同批出，不单独记。
6. **战损/污渍后的换洗**：战斗、淋雨、泥浆后换的那套干净衣服是**状态版本**，不是新身份。
7. **光脚/单衣等极端状态**：按正文写，另存一版。

**不变体的情况**：全剧同一场合、同一时代、同一身份且无换装动作——只保留默认装，不为凑数出图。

## 三、变体资产怎么写

### 命名

`### 道具 PROP_xx｜角色名·服装名`，例如 `PROP_09｜陈川·婚礼西装`、`PROP_10｜林悦·婚礼连衣裙`、`PROP_11｜陈建国·两年前旧夹克`。角色名前缀让人一眼看出归属，也让机检能对回角色。

### 图片提示词必写字段

1. **媒介与画风（必写，不能只写"沿用身份母版"）**：写**服装产品摄影**锚——"真实服装产品摄影，真实面料纹理与缝线，物理光照，自然褶皱与垂坠；不做 3D 渲染，不做塑料感，不磨皮"；CG 项目写对应画风锚。缺这段，模型会把"服装设定"按默认概念设定图风格画（**已实证：真人项目生成成 3D 卡通**）。
2. **版式：单张纯服装图**。16:9 横版，中性浅灰无缝背景，俯拍平铺或隐形模特；整套各件分区摆放、互不遮挡，单画面、单主体、无文字。**画面里不得有人体、人脸、模特、假人、手**；**禁止"平铺与穿着并列"、禁止多格拼版、禁止"设定板"构图**。拼版会把排版、棚光和概念图风格一起带进视频；穿着态会生成第二张脸。
3. **为什么不出脸**：脸、发型、身形由角色塑像图锁，**道具图只锁衣服**。变体图一旦出脸，就多出第二张脸、第二套身份真值，模型会在两张脸之间平均；而且道具编辑器按"单主体道具布局"审核，人物穿着图容易被当成角色图。不需要把角色塑像图挂给道具生成，也不需要写"沿用 CHAR_xx 的脸"。
4. **套装清单**：逐件写廓形、裁剪、连接、材质、固有色、磨损与标志。写"深藏青单排扣羊毛西装外套，垫肩略方，袖口两粒哑光牛角扣，内里同色缎面；白色府绸衬衫，深灰素色领带；炭灰西裤，裤线笔挺；黑色系带皮鞋"这种可生产的描述，不写"高级""正式""得体"。
5. **归属声明（机检依赖，不可省）**：`本套装供 CHAR_02 穿着；脸、发型与身形由 CHAR_02 单人塑像图锁定，本图只锁服装。`
6. **与默认装的关系**：写明"与默认装为同一人物的另一套穿着，不是新人物"，避免被当成新角色。
7. **负向限制**：不出现文字、商标、水印；还要写"3D 渲染、CG、卡通、二次元、塑料感、磨皮、人体、人脸、模特、假人、手、多格拼版、设定板、穿着图"。

### 固定提示词骨架（照这个顺序写）

```text
真实服装产品摄影，真实面料纹理与缝线，物理光照，自然褶皱与垂坠；不做 3D 渲染，不做塑料感，不磨皮；克制低饱和，稳定中性白平衡。
16:9 单张平铺服装图：浅灰无缝背景，俯拍平铺，整套衣服的各件分区摆放、互不遮挡；画面里没有人体、没有人脸、没有模特、没有假人、没有手，不是多格拼版、不是设定板、不是穿着图。
套装清单：<外层/内搭/下装/鞋/配饰，逐件>
裁片连接：<门襟/肩缝/袖口/压线>
材质与颜色：<面料、固有色、磨损>
可穿戴结构：<套头/拉链/系带>
本套装供 CHAR_xx 穿着（姓名）；脸、发型与身形由 CHAR_xx 单人塑像图锁定，本图只锁服装。
剧情状态：<基础态>
负向限制：3D 渲染、CG、卡通、二次元、塑料感、磨皮、人体、人脸、模特、假人、手、多格拼版、设定板、穿着图、任何可读文字、品牌标签、图中水印。
```

### 变体片段的三锚与参考覆盖（防"换场地就换衣服"）

角色塑像图永远穿着**默认装**，变体图是另一套衣服——两张图同时挂进一个片段，模型会看到两套服装。必须用文字把职责切开：

1. **第三锚换掉**：绑定变体的片段，该角色的识别锚第三项必须换成变体的上装，默认外套不得再出现在锚里。例：塔纳默认锚是「白色短款白大褂」，穿变体衬衫的片段写成「黑色短发三七分／细金属框眼镜／白色医生衬衫」。
2. **镜内换装写状态**：同一片段里先穿默认装、后换变体（例如当场脱下白大褂），锚写成「前半白大褂→后半白色医生衬衫（2.5–6 秒褪下，之后不穿回）」，不要只写其中一个状态。
3. **参考里点明唯一基准**：`PROP_12＝本段服装唯一基准（平铺整套，不含人体），由 CHAR_06 穿着；CHAR_06＝身份唯一基准（脸、发型、身形，单人塑像图）。`——角色塑像图仍然挂，但职责只剩身份；不要写"只作比对"，否定句仍按 WAN30-05 判错。
4. **同一片段只许一套上装**：除镜内换装动作外，一个角色在一个片段里不能同时挂两套上装变体。

### 片段 SH01｜30秒｜婚礼当天

角色：CHAR_02,CHAR_03
场景：LOC_04
道具：PROP_09,PROP_10

#### 视频提示词

```text
【参考】CHAR_02=陈川外观与体态锁定；CHAR_03=林悦外观与体态锁定；
PROP_09＝本段服装唯一基准，由 CHAR_02 穿着；PROP_10＝本段服装唯一基准，由 CHAR_03 穿着；
LOC_04=陈家院子婚礼现场。
【公共总规范】……
【时间轴】
0-5秒，……
```

要点：

- 服装进**片段的 `道具：` 绑定行**，随片段走，不随角色走。
- 【参考】里服装条目**必须写明由谁穿着**（写角色代码或姓名均可），否则视频模型无法把套装对到人身上。
- 镜头行用自然语言写"陈川穿着那套藏青西装"或"换上西装后的陈川"，**不写 PROP_09 这类代码进正文**（代码只出现在【参考】与绑定行）。
- 换装必须发生在片段边界或有镜内动作：上一片段的收束状态写"已换上西装"，下一片段第一镜从该状态起；片段内换装要给出可见动作来源，不能靠硬切暗换。
- 未变体的角色，其【参考】里仍写"（日常装、身份与体态锁定）"。

## 五、机检口径

`validate_compact_package.py` 对每条片段做五项服装检查：

| 检查 | 判定 | 级别 |
|---|---|---|
| 归属缺失 | 绑定的服装资产声明供 CHAR_xx 穿着，但 CHAR_xx 不在本片段角色绑定里 | 错误 |
| 参考未写归属 | 【参考】里的服装资产没写归属角色（代码或姓名） | 错误 |
| 与锁定装冲突 | 角色资产「固定服装」锁的是 A，镜头行明确写该角色穿 B | 错误 |
| 同片段多套 | 同一角色在同一片段被明确写了两种以上上装 | 错误 |
| 场合词无资产 | 镜头行出现场合级服装词（西装/礼服/婚纱/连衣裙/孝服/军装/警服/旗袍/唐装/中山装/校服/运动服/工装服），但本片段未绑定任何服装变体 | 提醒 |

归属判定只认**明确句式**（"陈川穿着…西装""西装穿在陈川身上""陈川的西装""陈川换上…西装"），同一行里别人的衣服不计入，避免把同框人物的服装算到同一个人头上。

## 六、内部档案与交付包的关系

服装版本账在**内部档案**（阶段 2 的资产与空间设计）里逐条登记：角色、版本名、适用场合、适用集、绑定片段。**只登记在内部档案是不够的**——版本必须同时落成交付包里的独立资产条目，否则应用侧只会拿到默认装。内部版本账与交付包资产条目的对应关系在阶段 5 逐项核对，缺一即判"服装变体未落地"。

## 七、缺项与降级

- 用户明确只要默认装、剧情也无场合变化 → 不出变体，资产层登记"全剧单装"并在执行账写明。
- 场合服装已在角色资产里画成"多套并列"（不是规范的单套）→ 拆成独立变体资产，不靠一句"可换装"糊过去。
- 变体图缺角色塑像参考 → 先补参考图生成；只靠文字"沿用脸"会按模型默认风格重画（真人项目实测出 3D 卡通）。
- 多格设定板 → 拆成单张纯服装平铺图；穿着态图不用于道具资产。
- 变体图出现人脸/人体 → 重出纯服装图；脸由角色塑像图锁，道具只锁衣服。
- 首饰与服装同批出图；单独的首饰（戒指、手镯）如影响连续性，按道具登记。
