# 美术推导规范（C 阶段强制前置门）

> 2026-11-08 用户指令设立：题材决定美术，美术推导必须在**任何资产卡落笔之前**完成并落盘。
> 实机反例：《真千金驾到》校园题材漏设计统一校服体系，复盘阶段才由用户发现——基础操作不得后置。

## 1. 定位与产出物

- 触发时机：B 阶段剧本定稿后、C 阶段第一张资产卡之前；
- 产出物：`<作品目录>/内部/01-美术推导.md`（固定模板见 §3），同时把结论压缩成一行登记进 `内部/00-项目输入单.md` 的 `| 美术推导 | … |` 行（fast_gate 第 0.6 步校验该行存在）；
- 硬约束：资产卡的 服装三层/饰件/场景元素 必须能回指到推导结论；推导里没有的服装体系（如校服/职业装/军团制服）不得在卡上临时发明。

## 2. 五步推导链（顺序执行，逐步落盘）

1. **题材类型**：校园/职场/古装/军旅/家族豪门/超自然……不同题材自带不同的着装规范与场景符号库，先定性再取用；
2. **世界观与背景**：时代、地域、社会规则、家族/组织结构、钱与权力的来源——所有"为什么这样穿、为什么有这样的场景"的因果都在这一层（例：家族因绑架威胁零曝光→继承人身份靠物证体系叙事）；
3. **着装规范体系**：题材带规范时（校服/职业装/制服）必须先设计**统一元素**（主体服装、校色/企业色、徽章、鞋履），再设计**对照变体**——阶级差、新旧差、定制差在统一体系内表达（例：同一套校服，二手版 vs 高定版＝"同一套校服两种人生"）；禁止用散装便装替代有规范的题材着装；
4. **场景符号表**：每个主要场景给出 2-3 个可复用的"物证级"符号（捐助铜牌、储物柜走廊、密室门、家族纹样），符号进场景卡的空间拓扑行，服务世界观暗示与伏笔回收；
5. **画风基线**：对标同题材爆款的具体观感（写明对标作品），产出一段可全局替换的画风句＋真实感锚句，登记进输入单画风登记——资产卡与视频公共层全部引用同一基线，禁止两套画风并存。

## 3. `内部/01-美术推导.md` 固定模板

```text
# 01-美术推导｜《作品名》
## 题材类型
## 世界观与背景（时代/地域/社会规则/权力结构）
## 着装规范体系（统一元素 + 身份/阶级对照变体 + 场合变体清单→对应 CHAR 变体卡）
## 场景符号表（场景→物证级符号→进哪张场景卡）
## 画风基线（对标作品 + 全局画风句 + 真实感锚句）
## 与资产卡的映射（每张服装相关卡 ← 推导结论哪一条）
```

## 4. 校验与合评

- fast_gate 第 0.6 步：包旁输入单存在时，缺 `美术推导` 登记行＝硬错；
- 合评清单增第 11 项：着装规范/场景符号与题材一致、资产卡逐条引用推导；
- 旧项目重跑机检前，先补 `01-美术推导.md` 与输入单登记行（允许结论从既有资产卡反推补写，但须补写）。
