# 交付与验收契约

默认只把 [精简制作包导入规范](compact-import.md)定义的 `精简制作包.md` 保存到资源根目录「创作输出/作品名/」并交付给用户。内部可用临时工作稿记录原文章节→事件→集→片段→镜头→资产提示词的追踪、剧本与评审，但不把这些额外文件放进最终导入包。长篇可按集批量制作；未覆盖范围不能冒充已完成。

以下旧式展开布局仅在用户后来要求完整制作包或图片文件时使用，**当前单 MD 导入任务不交付这些文件**：

| 产物 | 必须包含 |
|---|---|
| 00-项目规格与进度.md | 用户给的小说/风格、原文覆盖、系统提出的改编/画幅/片段/声音方案、版本与未完成范围 |
| 00-机检清单.json | 片段与资产全量 ID、每条计划镜头 ID/硬切数、提示词与实际资产文件路径、上传映射；按 [机检格式](validation-contract.md)生成，供脚本逐条和全剧校验 |
| 01-全剧故事档案.md | 原文事实与改编决定分栏；人物目标/知情、关系、时间线、主支线、世界规则、伏笔与名场面 |
| 02-时长与分集规划.md | 事件→场景→集覆盖表、每场表演估时、总时长区间、集数推算、逐集目标/阻碍/转折/钩子、默认 30 秒片段数量；初版与校正版依据 |
| 03-逐集剧本/ | 全部集的场序、可见动作、说话人和原句台词、必要声音、集末状态与下一集入口 |
| 04-资产与空间/ | 资产总表、每个可见 @CH/@SC/@PROP 的出图提示词和实际资产图、角色服装版本、场景主图及必要反打/俯视平面图、道具图；每图路径、版本、风格与选定状态 |
| 05-片段分镜与状态/ | 每集片段清单；默认每条 30 秒、6–11 镜、5–10 次硬切（H3 轨沿用应用片段单位、0–6 硬切、毫秒切点）；每镜编号与职责、景别/机位/运镜/起止时间、开场/出口状态、人物走位/视线、道具持手、台词与表演节拍；**H3 轨另附资产→`<Subject N>`/`<Picture N>` 映射表与参考素材清单** |
| 06-视频提示词/ | 每片段唯一最终正文及字符数、独立生成参数、实际资产图上传顺序映射、原事件/场/镜头→提示词时间段与切点对应 |
| 07-全剧提示词规范评审与整改.md | **每一条**提示词的剧情追踪、硬性条件、连续性和画面质量审查，问题、修订前后版本、复评结果与全剧覆盖统计 |
| 08-视频遵循与成片验收.md | 仅在实际视频存在后填写：每片视频文件、提示词要求与实际画面偏差、跨片段衔接、修片/重生与复验 |

## 资产图的完成条件

资产总表覆盖所有要进入镜头的可见角色、场景、剧情道具与线索；群演或非识别性环境物可按合理组别管理，但不能漏掉会影响连续性的主体。当前导入文件为每项资产保存**图片提示词**，角色身份/服装版本、场景地标/光源/出入口和道具结构写具体。主要场景的俯视空间关系在内部规划，并把影响生成的站位和走位写入相应视频提示词。

单 MD 导入不承载图片文件；即使内部曾出图检查，也不能把这张图称为目标应用已导入的资产。目标应用中的图片要导入后生成或上传、检查并批准。用户要求展开制作包时，才按前表交付实际图片文件及其审查结果；不虚构路径或 @Image 编号。

**声音同样不进 MD**：内部完成声线母版（见[声线母版与配音规范](voice-and-dubbing.md)），MD 公共层只承载由母版派生的「声线锁定：」文字。TTS voice ID、配音演员、用户提供的人声样本属于后期/应用侧资产；走后期配音路线时另在内部产出配音台本（片段/镜号/角色/声源/台词逐字/声音类型/时间码/情绪语速/口型要求），不作为额外文件交付给导入应用。

## 文字交付前的两类硬门

**A 连续性门**：角色脸发/服装/伤情、场景地标和左右关系/光向、道具外观与持手、镜头进出画/轴线/视线、上一片段出口与下一片段入口逐项相符。不能用一句「保持一致」代替这些事实。

**B 剧情与视频质量门**：原文章节→剧本场景→分镜→提示词追踪完整；每条默认 5–10 次有职责的硬切，运镜另计、动作物理可行，情绪有触发/过程/反应，武打有蓄力/发力/接触/反馈/反应，对白和声音能在 30 秒内成立。片段计划镜头数不能充当模型已输出的切镜数。

两门从写作时就生效：剧情在事件、剧本和片段规划交接时按[剧情质量评估](story-evaluation.md)执行；资产与分镜在各自起草和交接时检查；提示词逐条编译时按[提示词质量规范](prompt-review.md)即时评价。每批写入后再由 [单 MD 校验脚本](../scripts/validate_compact_package.py)检查导入结构、字符数、时间码、资产代码绑定、镜头 ID 与硬切数、声线锁定行（按轨加 `--model seedance25|wan30|h3`，Seedance 轨按档加 `--tier`），agent 独立复核语义质量。脚本**不能**验证图片文件存在，因为此导入格式没有图片字段。最终全剧无脚本错误、无未关闭的 agent 评审问题，才交付为「提示词规范评审通过」。若实际接口比项目方案更严，须先调整片段计划与正文，再校验复评。

## 实际视频的状态边界

- 「资产提示词已定版」表示图片生成文字通过审查；不表示目标应用里已有资产图。
- 「提示词规范评审通过」表示文字、参考和计划镜头通过全量审稿，不表示模型按指令生成。
- 「文字声线规范通过」表示声线母版与锁定行齐全一致；不表示成片同角色跨片段音色相同，后者须样片或成片验证。
- 「视频遵循验收通过」只在实际视频逐项对照提示词并记录证据后使用。

视频失败时定位为剧本、资产、空间、分镜、提示词、生成或剪辑问题，修改受影响阶段与相邻片段，重新审稿和验收。
