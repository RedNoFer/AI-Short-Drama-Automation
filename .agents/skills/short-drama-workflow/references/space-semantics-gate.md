# 空间语义与跨镜连续性验收门

逐资产、逐镜与逐提示词证据按[逐项质量验收证据契约](quality-evidence-contract.md)固定落盘；阶段2／3／4出口门强制核对覆盖、引文及哈希。阶段3同时运行已实现的站位几何检查，不能用示意坐标或“以正文为准”替代实际空间设计；基底需要有效参考相机，逐镜增量需有效实际机位。几何通过仍不等于真实可拍或图像已验证。

适用多人、狭小空间、车辆、固定座位、出入房屋、道具交接及空间关系会影响剧情的场景。沿用 SPACE-01、SYNC-01 和 W18；本门补充人工语义检查，不声称现有脚本可判断空间正确。项目输入、用户锁定的空间、已选资产图和冻结剧本优先；未知项标待确认，不因缺信息猜左右舵或把假设当成事实。红喵本目录仅有 JSON 与文字，无可用渲染运行时，不得声称实际生成了站位图。

## 阶段 2：空间母版与可见证据

对每个风险场景建立空间卡与对应基底：固定地标、实体边界、出入口、可通行区域、摄影机参考方向、光源；明确每人初始位置、朝向、姿势和实际支撑，每件关键道具的初始数量、位置、持有人与状态。人尚未进入时写不在场及入口，不用空数组冒充已设计。室内外同一建筑须通过院门、路、停车区、石阶、前廊、主楼门、门厅等真实适用地标建立连接，汽车写具体停放位置和可见边界。

车内须登记车头方向、前后排、实体座位和朝向、乘客与座位对应、头枕椅背及扶手、人物视线与可达递物路线；左右驾驶位依素材而定。`sit` 仍须对应实际座位与可达支撑；坐位未知或仅有坐标不能评为通过。核对已提供/已选的实际参考图：数量、朝向、结构、人物和车辆与空间卡冲突先修母版。尚未有图时只审文字、登记“图片核对待完成”，实际生成前核对图片。

## 阶段 3：逐镜及接口

逐镜核对场景基底、人物是否在场／入画／被遮挡／画外、世界位置与朝向、坐立及支撑、走位与出入、机位位置和可见面、道具持有人与位置。必须让人物入镜方式、身体、实体承托、视线和相机可达；不可凭示意坐标或“以正文为准”填充空白。逐个对照镜头声明的画内人数和 JSON `inFrame`（含未点名者），核对资产 ID 和道具实物；画外与离场是不同状态。像成对鞋、两份协议要逐件记录，不把同类物当成一个模糊状态。镯子等穿戴物记录所属人物和左右侧。

对每对相邻镜头与片段登记出口→入口：空间与时间、人物位置/朝向/姿态、可见与画外、道具的数量与位置/持有、服装伤情、关键动作；场景切换标明跨门、上下车、时间跳转等合理变化。每行需写具体事实与文件/镜号证据，不得用整批相同的“站位连续”代替。独立评审逐项审查，记录范围、版本哈希、问题及关闭证据，空间问题阻断阶段 3 放行。

## 阶段 4：提示词编译与实际提交核对

将冻结事实中影响模型理解的座位、位置、朝向、承托、出入口、相机、进出与道具状态，按适用镜头转成简明自然语言；正文与基底／镜级增量／绑定逐项比对，不能只写“保持一致”。室内无车时不要无故绑定室外车辆；需门外可见时写明隔门位置。人物在相邻镜头可因硬切已在画内，只有同镜内新入画才需要实际走入或遮挡后露出；不以过量负面词代替具体事实。核对上传图实际内容、槽位顺序与平台追加内容；声音角色保留身份与声线绑定，图片是否上传依据入口功能。

阶段 4 全覆盖评审要对每条风险镜头留“镜号→基底/人物/道具→正文位置→结论”以及相邻片段接口，含分镜、空间基底、镜级增量、资产版本和待评提示词的哈希；冲突回最早错误层，改动令受影响及相邻评审失效。未完成语义评审，不因机检通过放行。

## 样片与状态

实际生成后，比较实际提交版本与参考素材，按时间核查入画人数／身份、固定结构、坐姿支撑、动作方向和道具状态，并核对片段出口与下一入口；确认异常再修空间、编译或素材，不擅自归因模型。记录问题时间、截图/视频、提交版本和修复后复验。制作包文字完成不等于视频质量通过；未生成样片标“待生成验证”。

## 回执与最低阻断条件

阶段 2/3/4 评审记录列受影响场景、片段/镜号、母版与实际图版本、人物和道具事实、原始条目与正文对应、人工检查结论、未解决项及哈希；核验失败或证据缺失为未通过。冲突示例：乘坐镜用 `stand`、乘客未绑定座位、正文称三人在画内但 JSON 只标一人、错误道具 ID、鞋的数量/位置前后冲突、室内引用不在场车辆。样片有问题则记录为“成片未通过”，不得沿用旧的文本通过结论代替。

允许合理变化：真实转场后出现新地点、硬切到已经站在画内的人、人物正常走入、被遮挡后露出、明确的上下车与带原因的道具转移。机检仅证明已实现的字段或映射检查；不能证明坐姿承托、空间可拍、声音同步或生成质量。
