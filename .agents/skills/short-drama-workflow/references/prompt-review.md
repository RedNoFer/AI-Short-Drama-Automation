# 分阶段提示词质量规范与全剧复核

本规范在**提示词起草前、逐条编译中、每批导出后和全剧交付前**使用。剧情本身的评价先按[剧情质量评估](story-evaluation.md)在改编、剧本和片段规划阶段执行；提示词阶段检查它有没有准确转成可生成的画面和声音。不要等全剧初稿写完才第一次核对。每条在内部留评价与修订记录，不抽样；最终 MD 只包含导入字段，不塞入审稿记录。

## 提示词质量评价的执行位置

1. **起草前**：取已通过的片段剧情卡、逐镜表、资产版本、**声线母版**和前后片段状态；列出本条必须呈现的剧情结果、对白/表演、动作因果、镜头职责与不可变的身份/空间/**声音**锚点。按[反例索引](failure-cases.md)读取与当前场景相关的检查；多人共处、固定座位或狭小空间须用 SPACE-01。Wan3.0 项目还须读 [WAN30-01](failure-cases.md#wan30-01)，并按 `scripts/audit_wan30_antipatterns.py` 的报告逐项找反证：参考图类型、镜头前置、静物/空镜时长、并肩词、不看镜头、对话单拍、道具时序、文字规避、冷灰光。出现人物分身时读 [WAN30-02](failure-cases.md#wan30-02)，核对参考图是否单人、每镜是否超过 3 张正脸、4+ 人是否拆镜、五人全景是否 ≤2 秒且无台词、人数锁定句是否在位、反射/复刻是否标 `幻境层`。输入本身缺失或冲突时退回上游，不能凭空补写。
2. **逐条编译中**：按下方「剧情追踪、硬性规范、画面执行」三个维度写每个时间行。每写完一条立即对照内部 04 逐镜表的原镜头 ID 与片段出口，检查是否漏了关键结果、错误分配说话人、压掉反应、写出不可实现的走位/运镜，或让公共规范与时间行矛盾。先修该条，再进入下一条。
3. **每批导出后：一次对抗性独立评审。** 先运行[精简制作包校验脚本](../scripts/validate_compact_package.py)与[小说原文覆盖率脚本](../scripts/validate_novel_coverage.py)，失败先改；脚本通过后由**一个全新独立子任务/审稿视角**（单个模型、不携带起草记忆；条件允许时换模型是可选增强）做一次全量评审。评审是对抗性的，必须依次走完六个固定视角：①剧情忠实与因果（台词逐字、关键动作/结果无丢失、说话人正确）②表演与动作可拍性（语速与**动作余量**——台词占镜内时长超 75% 的镜是否已拆台词或补动作、物理、武打因果；**动作戏三子项：打空气检查——每一击必须有命中/格挡/闪避/拆招/反击之一的明确结果，禁"刀光闪过"不写对手应对；受击承接检查——重击/大招后下一镜必须承接受击状态，禁完好无损继续打；战损连续性检查——伤损/衣甲/道具状态跨镜延续或有镜内恢复动作**；A 级一镜到底段加查拍点运镜过渡是否连续、入镜/出镜与相邻段衔接）③空间与上下文衔接（**先对照阶段 3 上下文衔接自查表逐对复核，自报失实按评审问题处理**；再独立找反证：站位/视线/道具状态链/场景光向，镜间·片段间·集间；**战损链：本集任意片段出现过战斗战损后，伤痕/衣物/武器损耗状态在后续所有片段延续（不论该片段是否打斗级），恢复须有镜内动作；每段独立生成、参考图是完好基线，战损须逐段在提示词重新声明，评审查"该段提示词是否漏带战损声明"**）④声音（七类来源标签、口型状态、声线锁定覆盖且与母版逐字一致）⑤小墨6.3视感复读（对照 E24 原版把分镜视感重新检查一遍：固定镜头≤10%且禁连续固定、微运镜替代绝对静止、常规镜头≤30%、侧45°主力、景别不连三近景、焦段与机位角度种数、重锤后留白镜；不合格回阶段 3 重排，不得在提示词层打补丁）⑥硬规（四段结构、时间轴、硬切 5–10〔镜头 6–11；A 级一镜到底段走 fight 分支：无硬切、拍点 ≥2 且 0–30 连续、字符按第三档 4500〕、字符上限按档〔默认第二档 3000／第一档紧凑 2000／第三档 4500〕、自然语言、无代码批注）。评稿人要主动找反证、默认稿件有问题，每条结论引用原文/剧本/规范位置作为证据，无证据的主观意见标「建议」不算阻断；全量逐条覆盖，不抽样，不接受「生产代理自检通过」。记录评稿人标识（子任务 ID/模型名）。
4. **回滚、重生与复验预算。** 评审发现阻断/重要问题，回到最近一次「脚本 + 评审」全通过的存档版本，由起草方重新生成受影响提示词；根因在上游（分镜站位、资产/声线母版、剧本节拍）时回退到对应阶段重做，不能在提示词层打补丁。重生后从头重跑脚本，并**重新做一次全量独立评审作为修复复验**：既审改动条目，也审相邻条目有无新回归，不允许只复审改动点。同一处经两次回滚复验仍不通过，停止自动返工，把分歧点、已耗评审次数、剩余风险与候选方案交用户决策，不得带病交付。评审次数软上限为「1 次初评 + 2 次回滚复验」；到上限仍有分歧时由用户决定接受、改需求还是继续。
5. **全剧交付前**：全量重跑脚本，逐对检查跨片段/跨集状态、原文覆盖、衔接链条与台词声音来源一致性，复查受共享资产变更影响的提示词。无未关闭缺陷才标记通过。

质量评价对每条分别给出「剧情与表演、镜头与动作、资产与连续性、表达可执行性」的**通过 / 需修改 / 因输入缺失待定**结论，并指向原事件、场景、镜头或资产证据。任何关键剧情遗漏、人物/场景冲突、动作不可拍或指令互相矛盾均不能评为通过。脚本负责字符数、整数秒、硬切数和格式；agent 评价戏剧效果与生成指令是否具体、可理解、可执行。质量状态不是模型生成成功率的数值预测。

## 评估基准的传递（评稿人不得自选尺子）

本次评审按**阶段 0 选定的体裁路线**执行：[通用层 + 该路线层检查项]，出处见 [剧本体裁路线与评估基准](script-route-and-rubric.md)。交接包必须携带该基准（路线名 + 路线层条目编号）；评稿人按指定基准逐项判定，缺基准的评审记录无效。路线层不豁免通用层。

## 严重度判定口径（评审结论统一标准）

| 级别 | 判定标准（满足任一即归此级） | 处理 |
|---|---|---|
| 阻断 | ① 机检硬规违反（四段结构、时间轴、硬切数、字符上限、绑定/参考不一致、声线锁定缺失或跨片漂移、原文覆盖率不达标）② 台词被改字、说话人错配、关键剧情动作/结果丢失 ③ 同一提示词内指令互相矛盾（如狼群零接触又写贴窗）④ 物理/空间不可拍（无承托、穿座、无源光）⑤ 资产身份冲突（同 ID 脸/服装/五官锁定被破坏） | 必须回滚修复，修复后全量复验；不得带病进入下一批 |
| 重要 | ① 相邻镜/片段/集的站位、道具状态、光向、情绪话头接不上 ② 声音来源或口型状态不可判定 ③ 关键线索信息观众无法接收（不可读文字且无口述）④ 表演时长压线（>5 字/秒无申报）⑤ 程序性语言残留但不影响理解 | 本批交付前修复；确无法修复的升级为阻断交用户 |
| 建议 | 不影响生成与理解的措辞、节奏、构图优化、可选表演增益 | 记录，作者择便修，不阻塞放行 |
| 路线层不符 | 不符所选体裁路线的基准（如 R-AI 的体量/画面粒度/爽点密度、R-SERIES 的钩子强度 L3+/人物弧/余韵、R-MICRO 的人物数上限/不可逆代价） | 体量、粒度、爽点密度、人物弧、钩子强度类＝重要；钩子类型连续重复、缺余韵、人物超限＝重要或阻断；反俗套与风格优化＝建议 |

补充口径：评审员与作者对级别有分歧时，阻断/重要以本口径为准；模棱两可从高判定并注明理由。机检已判错的项目一律至少算重要（通常为阻断），评审不得降级为建议。

## 上游交接条件

- **剧情**：事件表、分集、逐集剧本和片段规划已按[剧情质量评估](story-evaluation.md)分别通过；关键动机、因果、台词、可拍性或集末钩子有缺陷时退回对应阶段。
- **资产与分镜**：身份/版本、空间地标与光向、道具持手、人物站位、镜头职责、动作物理可行性和表演节拍已核对；`内部/03b-资产评审.md` 存在且结论为通过（阶段 2 出口门已校验）；视感统计与逐镜表一致、阶段出口门 `--stage 3` 为 0 错误。镜头时间码以整数秒连续覆盖片段，30 秒片段默认 6–11 镜、5–10 次硬切。未通过时先修资产或分镜。
- **H3 轨专用核对**：正文用官方字段结构（base 三字段／Ref2VA 六段式），字段顺序、切点毫秒递增、`[Shot N]` 编号连续、`(S1)` 说话人 ID、`<d>[语言]…</d>` 语言标签、`<Subject/Picture/Video/Audio N>` 标签全文一致且无悬空、`overall_soundscape`/`non_diegetic_music` 句数、资产→标签映射已登记内部表；片段时长 ≤15 秒。结构问题退回阶段 4，映射或承接问题退回阶段 3。
- **声音**：声线母版已定稿（每个发声角色 3–5 锚点、角色间反差、旁白/混叠/低语定义、声源方案），本片要发声的角色都能在母版找到条目；TTS voice ID 或配音声源已选定或已有选声计划。详见[声线母版与配音规范](voice-and-dubbing.md)。

## 逐条评审的三个维度

### 1. 剧情追踪与内容质量

- 原文章节/改编事件→逐集场景→片段节拍→逐镜信息职责→最终提示词时间段可反查。关键动机、反转、名场面、原句台词、动作结果和对手反应不得无记录丢失。
- 每条有明确可见的开头状态、触发、行动、结果、出口；抽象心理已转成可演的眼神、停顿、呼吸、身体动作或明确标注的旁白。
- 对白和表演发生在正确人物、正确时间段；情绪变化有诱因、过程与回应。武打/追逐的蓄力、发力、接触、反馈、反应和最终站位能在片段时长内成立。
- 用具体可执行描述替代“电影感、保持一致、情绪到位”等空泛词；剪去同义词、重复资产卡和对结果无用的摄影术语，但不牺牲剧情表演。

### 2. 硬性规范

- **台词声音来源必须逐句判明**：区分「口型对白」（画面内人物开口、口型同步）、「心理独白」（角色内心声音、无口型）、「画外旁白」（全知旁白、无口型）、「画外余音」（收束段余韵、无口型）、「画外延续」（跨镜/跨片段 L-cut，口型按接续镜规则）、「低声自语」（可闻不可辨）与「混叠人声」（多人声叠加）。含对白的镜头行必须同时出现来源标签与「口型」字样；同一句台词跨镜/跨片段时，写明画内还是画外、说话者是否仍在画面内、口型如何处理。台词文本逐字不改，但声音出处、口型与画面内/外状态必须可判定，不能只写「说」或只写引号。**时间行必须是自然语言整句**：格式「起-止秒，内容」，首镜直写开场，其后每行用「硬切，」自然引出；镜头项目编号（E01-SH01-S02 等）与 `｜镜头…｜起始/硬切｜` 字段只属于内部逐镜表，禁止出现在提交正文（资产绑定代码除外）。禁止「景别→运镜」箭头缩写、名词堆叠或只有摄影术语的碎片。
- **声线锁定必须进公共层**：含人声音频的片段，【公共总规范】必须有一行逐字取自声线母版的 `声线锁定：`，只列本条实际发声角色；同角色跨片段用词一致，母版改动后全量重派生。嘶吼、哭腔、耳语等情绪极值写在镜头行作为表演指令，不能临时改写锁定行；模型直出人声若无样片门的跨片段稳定性证据，不能声称声线一致。规则与配音台本见[声线母版与配音规范](voice-and-dubbing.md)。
- **台词语速口径**：按「汉字字数 ÷ 镜内时长（秒）」计算，标点、空格和换行不计；默认上限 5.0 字/秒。旁白、无口型、混叠人声或跨镜合成句可放宽，但必须在该行写出申报（如「综合速率4.5字/秒（不计标点）」「本行语速申报5.5字/秒」）；跨镜/跨片段的一整句按合计时长算综合速率，不能只看单行时长。机检脚本按此口径对含台词的镜头行做上限检查，无申报的超速行判不合格。**口径来源**：该数字出自 S02 第 88 行「念白托底（中文约每秒 5 字），再往上留 2-3 秒给动作和呼吸」，原文是镜长下限的经验值、写作「约」；本流水线把它改造成上限，原文的「动作余量」改用占比口径检查——**台词占镜内时长（＝汉字数÷5÷镜内秒数）超 75% 的片段会报提醒**，评审须逐条处理（拆台词到相邻镜、补动作/反应镜、或写明保留理由），未处理按「重要」计。画外旁白、心理独白、无口型、混叠人声与已申报行豁免。台词一律用直引号 "…"，术语与强调用「」，便于机检区分台词行与普通引文。
- 每条对应唯一片段 ID、目标时长、画幅、清晰度、声音策略和模型；默认 30 秒，时间轴以整数秒从 0 连续到 30 秒，无小数、重叠、缺口或超时；用户改变规格时按更新后的项目策略检查。逐条核对每个动作和每句台词的子区间是否落在对应镜头内、时长是否容纳自然语速。若台词跨切，明确切后是画外延续/L-cut、说话者是否仍在画面内及口型规则；不能让切镜时间先结束、台词时间仍延长，却没有桥接说明。
- 导入 MD 的每条视频提示词 `text` 块正文以 Unicode 字符数计，**含标题、标点、空格与换行，默认第二档≤3000（分镜须已按小墨 6.3 合规重排），第一档紧凑≤2000**。资产图片提示词、小说原文、内部表格不计；若平台更严，按平台真实限制处理。目标应用后来追加真实参考图绑定时还要重新核对实际提交正文长度。
- **小墨 6.3 视感复读**：阶段 4 逐条评审与阶段 5 独立复核都必须按 E24 原版把该片段的分镜视感重新检查一遍（固定镜头比例与连续固定、微运镜、机位配比、景别/焦段/景深标注、重锤后留白镜），依据是内部逐镜表与提示词正文中的运镜描述；不合格按阻断处理、回阶段 3 重排。机检不查视感，此项是 agent 硬职责。**但统计类项目已经前移到阶段 3 出口门**：固定占比、焦段种数、机位角度种数、连续固定、连三近景由 `crosscheck_storyboard.py` 按逐镜表实算并与「视感统计：」声明值逐项比对（格式见[视感自查表格式](storyboard-selfcheck.md)），评审**不重复手算这些数字**，只判断运镜与景别是否有叙事职责、是否服务剧情、是否与表演节拍咬合。评审若发现统计行与逐镜表被同步改错（两边都错到一致），按「自报失实」登记。
- 单 MD 的角色/场景/道具/线索绑定对应已定义的图片提示词，正文【参考】使用相同资产代码；同一资产 ID、脸/服装版本、场景地标、道具外观无冲突。没有导入图片，不得预写 @Image 或 @图片编号；目标应用生成并批准基准图后再核对真实图片引用。
- 逐镜信息职责、必要硬切、主要运镜、对白、音效、动作接触点和片段出口在最终正文可定位；默认每条 6–11 镜、5–10 次明确硬切，每镜单独一行并标记「起始/硬切」。硬切数、运镜数分别核对，不把计划数声称为生成结果。（H3 轨改为：职责与出口在 `[Shot N]` 段落内可定位，硬切数为镜头数−1，运镜与切点分别核对。）
- 上条出口与下条入口的人物位置/朝向/视线、服装伤情、道具位置/持有人/开合状态、空间轴线、光源、声音对应。每个关键道具建立「初始位置与状态→接触/转移→结束位置与状态」；中途取出、收回、打开、放下或保持未动都要有来源和动作，不能无铺垫出现，也不能让“全程未动”与中间镜头冲突。跨场跳时空明示。
- 不混用 S18 v3.5、S21 和适配器的多个最终模板；无占位符、虚构参考、相互矛盾的指令或未说明的模型参数。

### 4. 表演可见性与情绪极性（E25 微表情层）

- 表演层是否写成**可见生理线索**（眼睑、视线、眉心、唇线、下颌、喉结、呼吸、头颈肩、手部）而非抽象情绪词（"他很难过"、"情绪复杂"、"眼神有故事"）。
- 情绪极性是否守住：克制悲伤不得漂移成释然/暖笑，恐惧不得漂移成放松，强装镇定不得漂移成自信；终态与剧本情绪一致。
- 面部与身体线索是否互相矛盾或顺序不成立（同时并置多个线索、左右侧跨镜乱跳）。
- 嘴部安全：非笑点剧情是否避开会诱发微笑的模糊措辞，是否需要显式写明"嘴角不上扬"类限定。
- 表演线索密度：每镜 ≤2 个、每片段 ≤4 个、表演镜 ≤2 个；大远景与环境镜不写面部微动作。
- 依据：[微表情表演层](micro-expression-layer.md)；评级按下方严重度口径（极性漂移＝阻断，抽象情绪词／线索矛盾＝重要，密度超标＝建议）。

### 3. 画面执行质量

- 机位、景别、运镜有信息或情绪职责且物理可达；16:9/9:16 构图承载主体与动作；硬切能让观众辨认人物关系与结果。
- 角色身份、服饰、场景、道具及项目画风在片段内可辨且与资产图片提示词一致；光源方向有场景依据。实际出图后再比对真实图片。
- 对白留有自然发声和反应时间；武打接触、受力、落点无遮挡或有明确切镜处理；声音、节奏与动作同步。

### 空间专项通过条件

对 SPACE-01 适用片段，写分镜和视频提示词前，先并排核对场景资产提示词、已选定的场景图/补充视图、空间卡和用户锁定的调度。制作「资产架构→镜头继承」对照：固定结构与数量、角色对应的实体座位/区域、前后左右关系、朝向/关系轴线、道具承托、可用机位及遮挡。每个镜头标出继承了哪些关系、机位改变后哪些关系只在画面中换边；不能只在开场写一次座位表，再假定后续镜头自动继承。

对照时以用户锁定的空间事实和已确认的空间设计为约束，并用实际选定的资产图检查可见几何。资产提示词与生成后选定的图在座椅、门窗、道路、操作台或朝向上不一致时，先标记冲突并确定要修正的母版；不能各取一部分混写进视频提示词。图里未显示的空间不得由视频提示词擅自补成已确认事实；确需新方向时先基于同一空间架构补视图或明确提出保守方案。完成对照后逐镜核对以下五项，不能仅因正文已经写过座位清单就标通过：

- **人物对应实体位置**：每人位于指定的现有座椅/区域；固定结构的数量、前后/内外关系与素材一致。切镜只改变观察方向；有换座或移动时须有可执行的过程与出口。
- **相机对应可见范围**：机位和朝向能够拍到指定主体；明确必要的正面/侧背、靠背等遮挡和画外人物。镜头后的角色无须为了全员露面被搬到镜头前，露正脸不能靠凭空翻转身体或车厢实现。
- **动作对应执行者与设备**：驾驶者、说话者、持卡者或操作者逐项对应到正确人物；所处位置能触及操作对象，不能把“操作设备”自动改写成“坐驾驶位”。
- **道具对应支撑与接触**：关键设备的大小、承托、持手和取放路径在该空间成立；缺承托面或相互占位时，退回资产/分镜修订。
- **压缩后仍可定位**：最终短正文保留必要的实体位置、关键结构与机位可见性；公共层只写一次不变关系，切后只补实际变化。内部分镜卡留完整检查，不把台账或大段禁止清单塞进公开提示词。

空间对照至少留一份可审的内部记录：`场景资产约束｜镜头号｜人物实体位置/朝向｜机位与观察方向｜可见/遮挡主体｜继承或变化｜结论`。镜头切换只允许改变观察方向、景别和画面左右；人物实际移动必须有动作路径和状态更新。上述对照完成后，才可把稳定不变的必要约束压缩进公共提示词，并在局部时间行写清机位和变化。

人物落错座、固定结构重复、机位看不见所需动作或道具缺实际支撑时，空间项判「需修改」；单纯画面左右随反打变化不能判错。几何语义须人工核对，字符数/时间轴脚本不能替代。具体反例、纠正边界和可复制写法见 [SPACE-01](failure-cases.md#space-01)。

## 评审记录与关闭条件

每条建立一行或一页，评审记录按固定模板留档（缺项视为该轮评审无效）：

| 字段 | 内容 |
|---|---|
| 轮次与评稿人 | 第几轮、子任务 ID、所用模型（同模型独立上下文为基线，异模型注明）、范围（全量/片段集） |
| 对象版本 | 片段 ID、正文版本/字符数、源事件/场景/镜头 ID、资产映射 |
| 结论 | 剧情追踪、连续性（含上下文衔接）、硬性规范、声音来源与口型、**声线锁定（取自母版、覆盖说话角色、跨片无漂移）**、表演动作质量，逐项通过/需修改/待定 |
| 缺陷 | 缺陷 ID、具体位置、预期/现状、严重度（阻断/重要/建议）、退回阶段 |
| 回归 | 修订版本、回滚自哪个存档、重跑机检 rc、覆盖率结果、第 2 轮对每条旧缺陷的关闭确认与新问题 |

缺陷写明具体位置、预期/现状、严重度与退回阶段。

脚本能证明单 MD 结构、资产代码绑定、文本字符数、整数秒时间码、显式硬切标记，镜头行是否自然语言成句、含对白的行是否带声音来源标签与口型字样，以及含人声音频的片段公共层是否带 `声线锁定：` 且覆盖可识别的说话角色；不能判断图像是不是同一张脸、切镜是否有意义、情绪是否演到位、标注的来源与实际声音是否相符、模型是否真的照提示词生成。agent 不重复手数硬切或抄字数，应把审稿时间集中在这些语义与视觉问题上。

硬性不合格、剧情/表演遗漏、资产错误、声音来源标注缺失或错误、声线锁定缺失或与母版不一致、片段衔接冲突必须修正；画面质量问题也要给出实际修订，不以“建议优化”结案。修订一条导致相邻片段或公共资产变更时，重审受影响的全部条目。全剧覆盖率为 100%，所有问题关闭后才写「全剧提示词规范评审通过」；仍有无法消解的限制则列出未通过项和原因。评审必须由与起草方上下文独立的评稿人完成并留档。

## 生成后再核对提示词遵循

如果已有实际视频，逐条对照最终提示词与视频文件检查人物、场景、道具、镜头切点/运镜、表演对白、武打接触、声音、首尾状态。记录「要求→实际画面→偏差→重生/剪辑/提示词修订→复验」。若开场场景、主体或动作顺序整体错误，先核对实际提交的提示词版本、参考图绑定顺序与生成设置；在未取得这些证据前，把“输入/引用错配”和“模型未遵循”列为待查，不要把整段偏离直接归因于某一句提示词。没有实际视频时该项为「待生成核验」，不能从提示词合格推断生成视频必然遵循。

用户将偏差作为反例反馈时，按[反例维护步骤](failure-cases.md#接收与更新)合并同类问题，保留已证实画面与被更正的旧判断，将有依据的修订写回对应阶段。规则已经加入、修订文本已经复核、新视频已经验证分别记录；不能用前两项替代最后一项。
