# 可机检的提示词与交付清单

本文件是用户另行要求**实际图片文件及展开制作包**时的旧式交接格式。当前默认单 MD 导入应读取 [精简制作包导入规范](compact-import.md)，运行 `validate_compact_package.py`；不能用本文件要求单 MD 引用尚未上传的图片。展开格式的项目默认值以 [policy.json](../policy.json) 为准：30 秒、5–7 次硬切、正文≤2000字符。最终提示词采用四段结构【参考】【公共总规范】【时间轴】【收尾】，不写【参数】（剧集/时长/画幅由清单与应用设置承载）；含人声音频的片段公共层带逐字取自声线母版的「声线锁定：」（见[声线母版与配音规范](voice-and-dubbing.md)）。本项目的每一个硬切镜头必须单独占一行；原适配器的时间段合并建议不得吞掉已规划的切点。

## 每条正文的固定结构

保存为 UTF-8 纯文本。以下为格式示意；真实镜头行须写具体画面、动作、表演、声音和切镜职责，不得复制占位文本：

    【参考】@Image 1=@CH-001角色身份图；@Image 2=@SC-001场景主图；@Image 3=@PROP-001道具图
    【公共总规范】工作流定版的身份、服装版本、场景地标与光向、项目画风及声音规则。声线锁定：@CH-001＝锚点逐字取母版（只列本片段实际发声者）。
    （片段代码、30秒、16:9、720p、有声、Seedance 2.5 等参数登记在机检清单与应用生成设置，不写进正文）
    【时间轴】
    0-5秒，建立站位与可见目标；写清景别、主运镜及动作结果。
    5-9秒，硬切，切至对方反应，保留轴线和视线。
    9-14秒，硬切，主角看到门口异动，停步并转头。
    14-19秒，硬切，门口人物抬手示意，主角对上视线。
    19-24秒，硬切，主角靠近门口，右手放下道具。
    24-30秒，硬切，双方隔门停住，交代出口站位。
    【收尾】最终姿态、道具持有人与位置、环境结果、下一条入口状态。

一条片段默认 6–8 行镜头：第一行直写开场，其后每行以「硬切，」自然引出，非首行数量即硬切数（5–7 次）。时间行格式是「起秒-止秒秒，自然语言内容」，镜头编号只存内部逐镜表、不进正文；起止均为整数秒，时间从 0 连续到 30，不得有小数、空档或重叠；每行只有一个主要镜头意图和一个主要运镜，复合运镜须有叙事原因。内容字段必须写成自然语言句子（禁止「景别→运镜」箭头缩写与名词堆叠）；含台词的行必须标注声音来源（口型对白/心理独白/画外旁白/画外余音/画外延续/低声自语/混叠人声）并写明口型状态。所有重点镜头均写独立行，不能以「期间快速剪辑」代替硬切点。生成参数在清单与应用设置中另记，正文不设【参数】段；实际接口字段按工具设置。

## 机检清单

在作品目录保存「00-机检清单.json」。在片段规划阶段先冻结 planned_clip_ids 和每条 expected_shot_ids；资产图定版后登记 assets；编译完成后填写 prompt_path、references、planned_hard_cuts。示例只展示字段形状：

    {
      "schema_version": 1,
      "policy_version": 6,
      "planned_clip_ids": ["EP01-C001"],
      "assets": [
        {"id": "@CH-001", "type": "character", "path": "04-资产与空间/角色/CH-001.png"},
        {"id": "@SC-001", "type": "scene", "path": "04-资产与空间/场景/SC-001.png"},
        {"id": "@PROP-001", "type": "prop", "path": "04-资产与空间/道具/PROP-001.png"}
      ],
      "clips": [
        {
          "id": "EP01-C001",
          "duration_sec": 30,
          "ratio": "16:9",
          "resolution": "720p",
          "audio": "有声",
          "model": "Seedance 2.5",
          "prompt_path": "06-视频提示词/EP01-C001.txt",
          "expected_shot_ids": ["EP01-C001-S01", "EP01-C001-S02", "EP01-C001-S03", "EP01-C001-S04", "EP01-C001-S05", "EP01-C001-S06"],
          "planned_hard_cuts": 5,
          "required_asset_ids": ["@CH-001", "@SC-001", "@PROP-001"],
          "references": [
            {"marker": "@Image 1", "asset_id": "@CH-001"},
            {"marker": "@Image 2", "asset_id": "@SC-001"},
            {"marker": "@Image 3", "asset_id": "@PROP-001"}
          ]
        }
      ]
    }

所有路径相对机检清单所在的作品目录；资产图片和提示词必须在目录内存在且非空。角色板和场景主图的实际像素比例须近似 16:9；道具图未设统一画幅。清单内 planned_clip_ids 必须与 clips 一一对应，内部镜头 ID 与逐镜表一一对应（提交正文按时间行顺序对应）；@Image 编号从 1 连续排列，并在【参考】中映射到实际资产 ID。脚本不能证明图像已上传到供应商，上传顺序在提交时还需对照。

## 执行

    python3 /Users/a1/work/3000课程21个skill/.agents/skills/short-drama-workflow/scripts/validate_delivery.py --manifest /绝对路径/创作输出/作品名/00-机检清单.json

可用 --clip-id EP01-C001 只校验当前片段，便于按集增量整改；最终全剧交付前必须不带 --clip-id 全量运行。脚本退出码 0 表示确定性项目通过，非 0 表示失败，输出具体条目。它不替代 agent 对剧情、表演、美术和实际视频的判断。
