# 资产图与视频提示词分层规范（唯一真值）

**一句话：一个事实只写一处。资产图写「是什么」，视频提示词写「这一镜怎么拍、谁在哪、做了什么、变成什么」。**

资产图是外观与空间的**母版**；视频提示词是这一镜的**调度**。同一件事在两边各写一遍，模型每镜会二选一：近景吃文字、远景吃图，脸、服装、场景、道具就会逐镜漂。分层不是少写，而是把每个事实放到它该在的位置。

## 一、为什么必须分层

- **资产图**要经得起单独看：一张角色塑像图能锁住脸、发型、饰件、服装三层；一张场景空镜能锁住结构、材质、光位；一张道具图能锁住形制与基础态。
- **视频提示词**要经得起单独拍：这一镜的机位、景别、运镜、人物在场与走位、动作、表演、台词、声音、道具状态和出入口。
- **重复描述 = 第二套真值**。正文写「旧白色圆领短袖」、资产图也写「旧白色圆领短袖 T 恤」，模型会在不同镜头里各取一套；正文再补「车身反一条硬亮线」、道具图却写「哑光漆面」，车就会在不同镜头里换材质。
- **场景图是空镜**。人物、车辆、动物、手持物由 `CHAR_xx`／`PROP_xx` 绑定和正文点名；场景图不预先画进去，否则视频里会多出第二个人、第二辆车。

## 二、职责矩阵

| 事实 | 资产图 | 视频提示词 | 写在哪 |
|---|---|---|---|
| 脸型、骨相、五官相对关系、肤色、妆面 | ✅ 写全 | ❌ 不写 | 角色图；正文只写三锚 |
| 发型、发色、发际、发饰 | ✅ 写全 | ✅ 只写发型锚（长度／轮廓／固定饰件） | 角色图；三锚之一 |
| 固定饰件（眼镜、耳环、手绳、手表） | ✅ 写全 | ✅ 只写固定饰件锚 | 角色图；三锚之一 |
| 服装品类、固有色 | ✅ 写全 | ✅ 只写外套品类＋固有色 | 角色图；三锚之一 |
| 服装剪裁、版型、面料、内搭、裤、鞋 | ✅ 写全 | ❌ 不写 | 角色图；正文不重复 |
| 场景建筑、门窗、固定陈设、材质、纹理 | ✅ 写全（空镜） | ❌ 不重写 | 场景图；正文只写机位／朝向／光位／可走位置／出入口 |
| 场景时间、天气、光位基准 | ✅ 写基准 | ✅ 写本镜实际光位与变化 | 场景图；正文写变化 |
| 人物在场、站位、朝向、走位、动作、表演 | ❌ 不写 | ✅ 写 | 片段绑定＋正文＋站位层 |
| 车辆、动物、手持道具的在场 | ❌ 不画 | ✅ 绑定 `PROP_xx`＋正文点名 | 道具资产；场景图保持空镜 |
| 道具形制、尺寸、材质、纹样、颜色 | ✅ 写全 | ❌ 不重写 | 道具图；正文只写状态 |
| 道具状态（开／合、新／旧、有字／无字、在谁手里） | 只写基础态；持久状态另立变体 | ✅ 写本镜状态 | 瞬态写正文；持久状态建变体 |
| 镜头、景别、焦段、运镜、硬切、转场 | ❌ 不写 | ✅ 写 | 视频提示词 |
| 台词、旁白、声音来源、口型、情绪表演 | ❌ 不写 | ✅ 写 | 视频提示词 |
| 多套服装、多个年龄、多个伤情 | ✅ 拆成多个资产（默认装＋变体） | ✅ 绑定对应变体 | 一张图只锁一个状态 |

## 三、资产图：该写什么、不该写什么

资产图的完整字段见[资产图制作规范](asset-image-production.md)。本节只规定**边界**：哪些事实必须写全，哪些不能混进来。

### 3.1 角色图

**导入字段就是供应商正文。** 精简包的 `#### 图片提示词` 会原样进入目标应用的供应商图片提示词栏，必须包含可执行的画面描述。不得写入“资产来源”“原图文件”、本地文件路径、“不另生成”或跨集换装/审批/上传说明；这些只能存于内部输入单和执行账。用户已提供或已审核基准图时，继续使用已选图，同时保留可用的绘图正文供以后生成候选；是否重绘由应用的生成操作决定。MD 中的本地路径不会上传图片或建立图像引用。用户选定的特殊版式在项目输入单登记，不通过塞入供应商正文的说明或校验豁免放行。

**必须写全**（九块）：

1. 媒介与画风；2. 年龄感与体态；3. 骨相与脸型；4. 眉眼鼻唇相对关系；5. 妆面与皮肤；6. 发型与发饰；7. 饰件；8. 服装三层（上装／下装／鞋）；9. 版式与同人约束。

**不要写**：

- 镜头运动、景别、焦段、硬切、转场、分镜顺序——资产图不是分镜。
- 台词、旁白、独白、哭声、笑声、愤怒／悲伤等表演指令——资产图不是剧本。
- 对手、场景环境、剧情动作（走、跑、坐下、拿起、拥抱）——这些由视频提示词承担。
- 同一张卡里的第二套服装、第二个年龄、第二种伤情；需要就另立[服装变体](outfit-variants.md)或状态变体。
- 负向只写当前工具可执行的错误；不要用负向句补外观（如「不要圆领」「不要短袖」），外观用正向写全。

**允许写**：中性站姿、平视镜头、机位高度、画幅、占高、白底／浅灰底、四视图或单人塑像图版式——这些是**资产图的制作参数**，不是视频分镜。

### 3.2 场景图

**必须写全**（八行骨架）：

1. 真实感锚；2. 空间拓扑与固定地标；3. 前中后景；4. 天气、时间与光源；5. 材质（哑光优先）；6. 无人物声明；7. 场景底板职责句；8. 负向限制。

**不要写**：

- 人物、人体局部、倒影、可移动车辆、动物、手持道具。
- 人物站位、走位、动作、台词、剧情——这些是视频提示词和站位层的事。
- 分镜顺序、镜头运动、硬切、转场。
- 同一张图里的不同时间／天气／季节；需要就另立场景变体。
- 剧情道具（车、行李、杯子、工具）；固定陈设除外，且须同句标「固定陈设」并写清与墙、门、台阶的净距。

**允许写**：机位站在哪里、朝向哪里、画面里能看见哪些固定结构——这些是场景图的**建立视点**，不是人物调度。

### 3.3 道具／线索图

**必须写全**：

- 单主体、用途、形体与尺寸参照；材质、颜色、磨损／标志；可握持或佩戴结构；基础态；单主体清晰视图。
- 带字道具写「无可读文字」或「字不可辨」，按 TEXT-01 处理。

**不要写**：

- 持物人、人脸、手、身体、场景环境——道具图只锁物，不锁人。
- 动作、台词、情绪、剧情。
- 同一张图里的多个剧情状态（开／合、新／旧、有字／无字、未使用／使用后）；需要就另立状态变体。
- 镜头运动、景别、硬切、转场。

## 四、视频提示词：该写什么、不该写什么

视频提示词的完整结构见[导入规范](compact-import.md)与各轨规范。本节只规定**哪些事实不该重复**。

### 4.1 人物

**只写三个识别锚**：

```text
姓名：发型／固定饰件／外套品类＋固有色
```

- 发型：长度、轮廓、固定发饰；不写发丝走向、发蜡、层次。
- 固定饰件：眼镜、耳环、手绳、手表等**全片不变**的那一件；不写材质、尺寸、花纹。
- 外套：品类＋固有色（如「藏青夹克」「白色大褂」「米色连衣裙」）；**不写**面料、剪裁、版型、领口、袖口、拉链、纽扣、垫肩、褶皱、内搭、裤、鞋。

**不要写**：

- 脸型、骨相、五官、肤色、妆面——角色图已经锁死。
- 服装的剪裁、版型、面料、层次、内搭、裤型、鞋型——角色图／服装变体已经锁死。
- 资产图的版式（四视图、单人塑像、白底、占高 92%–94%）——那是制作参数。
- 「图里已经有这个人」的假设；出场角色必须绑定 `CHAR_xx`。

**状态变化**：

- 瞬态（淋湿、沾泥、撕破、解开前襟、拉起帽子、摘下眼镜）：写「在参考图服装基础上…」，只写变化，不重写原服装。
- 持久换装（婚礼、葬礼、制服、年代跨度、戏内换装）：另立 `PROP_xx｜角色名·服装名`，片段绑定、参考行写明由谁穿；不允许正文口头换衣。
- 伤情、血迹、战损：按状态链写「新增／扩大／结痂」，不重写原皮肤与五官。

### 4.2 场景

**只写**：

- 机位、景别、焦段、运镜、硬切／转场。
- 朝向、光位、可走位置、出入口。
- 本镜实际的时间／天气变化（如「黄昏转夜」「雨停」），只写变化，不重写场景基准。
- 必要的**短空间锚**：如「左侧矮墙、右侧盐堆」，只写方位，不写材质、纹理、颜色、尺寸。

**不要写**：

- 建筑结构、门窗位置、固定陈设、墙面／地面／天花板的材质与纹理——场景图已经锁死。
- 家具的雕花、漆面、木纹、石纹、青苔、裂纹、剥落——这些是场景图的活。
- 场景图里「已经有的人／车」；场景图是空镜，人物与车辆必须按 `CHAR_xx`／`PROP_xx` 绑定并在正文点名。
- 把场景图当分镜用：不要写「先拍墙、再拍门、再拍人」的镜头顺序；镜头顺序由时间轴承担。

**允许的例外**：

- 剧情必须让观众看见的**新变化**：墙上新贴的告示、地上新出现的血迹、门被踹开后的新角度——写「新增／变化」，不重写原结构；可移动的告示、杯子等仍应绑 `PROP_xx`，不烘进场景图。
- 空间连续性必需的一个短锚：只写方位与相对关系，不写材质。

### 4.3 道具

**只写状态**：

- 开／合、新／旧、有字／无字、完整／破损、在谁手里、放在哪里、朝向。
- 带字道具只写「字可读／不可读」与阅读结果；不重写字体、纸张、印刷。

**不要写**：

- 尺寸、材质、纹样、雕花、印花、刻字、漆面、金属／塑料／皮革——道具图已经锁死。
- 道具的完整外观复述；正文重复一遍就是给模型第二套真值。
- 道具图里没有的新结构；需要就另立变体。

### 4.4 状态变化与变体

| 变化 | 处理 |
|---|---|
| 淋湿、沾泥、撕破、解开前襟、拉起帽子、摘下眼镜 | 正文写「在参考图基础上…」，不建变体 |
| 换整套服装、换年代、换身份职务、婚礼／葬礼／制服 | 另立服装变体 `PROP_xx｜角色名·服装名`，片段绑定 |
| 道具开／合、新／旧、有字／无字 | 瞬态写正文；持久状态另立状态变体 |
| 伤情、血迹、战损 | 写状态链；跨集持续时建伤情变体或状态卡 |
| 同一角色第二张脸、第二个年龄 | 另立角色变体；不允许一张卡里写两套 |

## 五、判定口诀

1. **「这个事实，资产图已经锁了吗？」** 锁了就不写；没锁才写。
2. **「我写的是外观，还是这一镜的变化／动作？」** 外观归资产，变化／动作归视频。
3. **「删掉这句，模型还能从参考图得到吗？」** 能，就删。
4. **「同一事实出现两次，哪次是真值？」** 资产图是真值；视频只写变化。出现冲突，先改文字，不改图。
5. **「这句话是在描述资产，还是在描述镜头？」** 描述资产→资产图；描述镜头→视频提示词。

## 六、执行顺序（阶段 2 → 4）

1. **阶段 2 写资产图**：先写角色九块、场景八行、道具单主体；每个事实只落在对应的资产里。写完先做一次「资产图不写什么」自检。
2. **阶段 2 资产评审**：隔离评稿人检查资产图是否写全、是否混入镜头／台词／动作／多状态；同时检查同一事实是否在两个资产里重复。
3. **阶段 3 分镜**：人物站位、走位、动作写进逐镜表与站位层，不写回场景图。
4. **阶段 4 编译视频提示词**：先列本片段绑定的 `CHAR_xx`／`LOC_xx`／`PROP_xx`，再写三锚、机位、动作、状态变化；资产图已经锁死的外观不重写。
5. **阶段 4 全套提示词评审**：全部提示词完成后，由独立评审按第七节清单覆盖每条提示词的「分层与去重」；发现重复，删正文，不删资产图。
6. **阶段 5 机检**：跑 `validate_compact_package.py`；机械错误定位到对应字段并修复。语义上的场景/道具细节簇由阶段 4 全覆盖评审判定，阶段 5 不再开新一轮评审。

## 七、评审清单

### 7.1 资产评审（阶段 2，`03b-资产评审.md`）

- [ ] 角色九块齐全；没有镜头、台词、表演、剧情动作、第二套服装。
- [ ] 场景八行齐全；0 人 0 车 0 手持道具；没有站位、走位、动作；材质写具体，不堆空泛词。
- [ ] 道具／线索单主体；没有持物人、手、脸、场景、多状态同图。
- [ ] 同一事实只在一个资产里定义；服装变体与默认装不重复，道具状态变体与基础态不重复。
- [ ] 资产图的负向只写工具可执行的错误；没有把视频分镜、演员调度写进图片提示词。

### 7.2 视频评审（阶段 4，`05-提示词评审与整改.md`）

- [ ] 每个角色只写三锚（发型／固定饰件／外套品类＋固有色）；没有脸、妆、剪裁、面料、版型、内搭、裤、鞋。
- [ ] 场景只写机位／朝向／光位／可走位置／出入口；没有重写建筑结构、材质、纹理、固定陈设。
- [ ] 道具只写状态；没有重写尺寸、材质、纹样、颜色、雕花。
- [ ] 场景图是空镜；出场人物／车辆都有 `CHAR_xx`／`PROP_xx` 绑定，正文点名其在场与位置。
- [ ] 状态变化用「在参考图基础上…」；持久换装／伤情已建变体。
- [ ] 没有「图里已经有人／车」的假设；没有把资产图版式写进正文。
- [ ] 删掉任何重复描述后，正文仍然能执行；不能执行，说明缺的是动作／机位／状态，不是外观。

## 八、机检与审计

| 检查 | 位置 | 级别 |
|---|---|---|
| 资产图出现镜头／台词／表演词 | `validate_compact_package.py` | 错误 |
| 场景图正向句出现裸「车」等可移动道具（车道／车站／车位／车库／车辙／车流／车行及否定句除外） | `validate_compact_package.py` | 错误 |
| Wan3.0 三锚出现面料、剪裁、版型、内搭、裤鞋 | `validate_compact_package.py` | 错误 |
| 视频正文出现 `硬亮线／硬边高光／湿反光／镜面反光／油润／打蜡` | `validate_compact_package.py` | 错误 |
| 视频正文场景／道具材质词成簇（≥3 个不同词） | `validate_compact_package.py` | 提醒 |
| 阶段 2 资产评审缺「分层与去重」段 | `validate_stage_artifacts.py --stage 2` | 提醒 |
| 语义重复、 paraphrase、图文冲突 | 阶段 2／4 独立评审 | 人工判定 |

机检只能抓可枚举的词；**「同一事实写了两遍」最终由评审判断**。评审记录必须写「分层与去重」结论与证据，不能只写「已检查」。
