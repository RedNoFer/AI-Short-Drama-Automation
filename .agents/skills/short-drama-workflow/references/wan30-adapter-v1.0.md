# Wan3.0 通用提示词生成适配器 v1.0

> 与《Seedance2.5 通用提示词生成适配器 v1.0》同构的编译器手册：输入内部逐镜表，输出 Wan3.0 方言提示词。写法标准见 [Wan3.0 提示词规范](wan30-prompt-spec.md)；两轨分工见第九节。v1.0 已完成首轮样片实证（E01-SH01／SH03），暴露的参考图类型与静态摆拍问题已回写为 [WAN30-01](failure-cases.md#wan30-01) 硬规则；v1.1 待 E01 试点重写验证后发布。

## 1. 适用边界

- 生成模型为 **Wan3.0（万相）** 时使用本适配器；生成模型为 Seedance 2.5 时用 S18 适配器，两者不混用。
- 输入是分镜层产物（阶段 3 逐镜表＋阶段 3.5 打斗判定表），本适配器只做**编译**，不做分镜设计；分镜层规则（小墨 6.3 视感、打斗战斗语法、衔接三接口）两轨共用，编译时不得违反。
- 编译产物的质检走既有六视角＋机检（`validate_compact_package.py --model wan30`）＋反例专项审计（`audit_wan30_antipatterns.py`）。

## 2. 输入契约

编译前必须齐备，缺项即退回补齐：

| 输入 | 来源 | 用途 |
|---|---|---|
| 片段逐镜表（含视感自查、衔接自查） | 内部/04 | 拍点/镜头内容与时长 |
| 打斗路由判定表 | 内部/04b | A/B/C 级与战斗语法、战损源 |
| 资产库（角色/场景/道具图片提示词） | 制作包固定资产区 | 参考图编制与三锚；视频参考只用单人全身塑像图（单张、全身、中性浅灰底） |
| 声线母版 | 内部声线规范 | 台词与音频参考登记 |
| 参考素材清单 | 用户/应用端 | 图/视频/音频参考的编号与内容说明 |
| 片段绑定（角色/场景/道具/线索代码） | 制作包片段头 | 【参考】段编制 |
| 上一片段【收尾】 | 制作包 | 入镜承接与战损/状态声明 |

## 3. 生成参数与提示词正文分离

- 时长（2–30 秒）、比例、分辨率、模式选择由**应用设置**承载，不写进正文。
- **模式选择规则**（首尾帧与参考模式互斥）：
  - 默认**全能参考模式**（身份一致性靠单人塑像图＋三锚条款）；
  - 仅当该段的核心诉求是"从上一段真实尾帧续接"（状态连续优先于身份参考）时，选**首尾帧模式**，并把该决策登记进 04b 判定表；
  - 单次 30 秒内的多段续接（`分段2[5-10秒]：从上一分段的最后一帧无缝衔接…无硬切`）在参考模式内完成，不需要首尾帧模式。

## 4. 四段编译规则

### 4.1 【参考】→ 多模态参考层

- 【参考】只写 `代码＝职责`，**代码后不重复名称**（应用会把代码解析成资产名，重复名称会渲染成「娜琳 娜琳＝…」），**不写任何图片编号**；正文指代角色用姓名，不用 `@ImageN`。编号由应用在提交时按本次上传槽位生成，离线包写死必然错位（WAN30-04）。
- 职责声明沿用（外观/空间锁定），不内联角色卡。
- **参考图类型前置验收**：Wan3.0 的角色视频参考是**单人全身塑像图**——16:9 单张、单人单身体、全身入画、**正面**（身体正对、头正、双眼平视镜头，最多 5° 微侧）、中性站姿、中性浅灰无缝背景、人物占高 92%–94%、画面无文字、无场景陈设。资产卡上禁止写「3/4」「不看镜头」「视线落在画外」——那会把人拍成斜侧面，正脸数据损失一半。同一张图同时锁身份与服装。四视图/多视图拼版不得挂进视频参考（会被应用追加"不同观察角度"句，与"单张"正文互斥）。换图前先验：单人、全身、含下装与鞋、无文字、无第二个人。
- **人物一致性：三锚模式（默认）**——每个出场角色一句三锚条款，只写**发型／固定饰件／外套品类＋固有色**三项：
  > `【角色一致性】阿泽：短寸黑发、左腕旧钢表、藏青夹克。外观与服装一律以阿泽的塑像图为唯一基准，本文只写识别锚与状态变化，不重写剪裁、版型与材质。`
  - 三锚必须与资产图提示词**同源**（同样的词、同样的位置），素材改了锚点同步改，不能图是一套、文是另一套
  - **不写剪裁/版型/材质/内搭/裤鞋细节**——那是资产图的职责；正文重写一遍就会与图打架，近景吃图、全身吃字，结果同段两套并存（WAN30-04）
  - **场景与道具同样分层**：场景正文只写机位/朝向/光位/可走位置/出入口，不重写建筑结构与材质；道具正文只写开合/新旧/有字/在谁手里，不重写尺寸、材质、纹样。完整边界见[提示词分层规范](prompt-layering.md)（R31）。
  - **不得写"资产图只作比对、不作视频参考"这类否定句**——等于主动放弃图锚，四个人物会各飘各的；包内出现即判错
  - 行为基调（表演核心）不是外貌，保留在【公共总规范】
- **模式 A（仅当角色无参考图时）**：才使用文字枚举（从资产卡逐字照抄），并在交付时标注"该角色无图锚，一致性弱于图锚角色"
- 状态类道具（如古图银纹）不是外貌——状态变化仍由提示词层按剧情声明

### 4.2 【公共总规范】→ 全局设定

按手册案例颗粒度扩写，五个必写块：
1. **画风与质感**：沿用项目设计基准的画风段，补材质与光影级别描述（本项目为真人现实主义电影摄影：物理光照、自然比例、可辨实物材质、皮肤哑光保留细纹；不写死为 3D 国漫或任何单一画风）
2. **镜头语言**：运镜复杂度声明、慢镜/定格配额（≤2 次、每次 ≤1 秒）、静止上限（≤1.5 秒，对白固定镜 ≤2 秒）、轴线与几何连续声明
3. **声音纪律**：无 BGM（短剧默认）、环境层构成、音效点标记约定（`<音效>`）
4. **禁止项清单**：字幕/水印/穿模/肢体错位/轴线错乱/角色复制等，逐条列出
5. **空间锚点**：本段的空间调度锚（如"芦苇丛边界/岩石群/湖岸"三点动线）＋战损延续声明（如上段有战损）

### 4.3 【时间轴】→ 时间戳戏剧分镜

- 粒度 **0.5 秒**；总长按片段设定（2–30 秒）。
- 每行＝`起-止秒，`＋**镜头前置**（`镜头：景别/焦段/机位/运镜`，放在行首前 30%）＋**2–3 个可见动作节点（含攻防结果/表演三通道）**＋**声音层（自然语言＋`<音效>`点）**。镜头写在几百字画面描述的最后，模型会当作可选备注；样片已实证。
- 拍点间过渡写明（A 级一镜到底段：`镜头不停，随…`／`焦点从X切到Y`；B/C 级硬切段：`硬切，`）。
- 台词：直引号 "…"＋七类来源标签＋口型状态，逐字取自剧本。对话单镜 ≤6 秒；长句拆说话镜＋听众反应镜，画外延续写明同一人不切正面。
- 关键音效用 `<音效>` 内嵌；环境层保持自然语言整句。
- A 级段禁"硬切"字样；拍点间为运镜/焦点过渡。
- **反例约束（WAN30-01）**：静物拍 ≤2 秒、空镜 ≤2.5 秒；每段最多 1 个纯静物插入；删 `极缓慢`，所有运动改成可量化位移；禁三人以上人物 `并肩/一字排开/并排站/排成一排`（两人并肩、台词比喻、影子/倒影排列不算）；每段写 `全员不看镜头`，视线落对手/道具/远处；道具首次出现前写 `本拍 X 不在画面内／空手`；字条只拍纸背/纸边/手指遮字；光色写 `阴天散射、太阳不可见、色温约5000K、冷灰、无金色逆光`。\n- **人物分身约束（WAN30-02）**：每镜主要正脸 ≤3 张；4–5 人场拆成 2–3 个镜头，后景用背影/虚焦；五人全景每段 ≤1 次、≤2 秒、无台词；每个 4+ 人镜头写人数锁定句（`本镜画面内恰好N人：左起…；每人只有一个身体、一张脸；不出现第N+1人`）；参考图必须单人，无四视图/镜像/背景人；普通水面/玻璃写「不映人物」，只有幻境复刻才写「倒影」并标 `幻境层`。**不要只写「不要角色复制」——负向禁止不是人数控制。**

### 4.4 【收尾】

出口状态（站位/持物/战损）＋下一片段承接方式，与 S18 轨同规则。

## 5. 时间轴编译规则

- **按叙事节拍合并，不按 6.3 镜头编号机械复制**——一个拍点可容纳一个小墨镜头，节奏紧时可 1.5 秒级微拍。
- 拍点数建议：对白段 4–8 拍；动作段 8–20 拍；单拍最短 0.5 秒（快切反应），叙事拍 ≥2 秒。
- 连续性：起止秒首尾相接覆盖全段；时间粒度全段统一（不混用 1 秒与 0.5 秒粒度造成节奏误读）。
- 语速 ≤5 字/秒（台词汉字/拍内秒数），跨拍长句按合计申报——两轨同规。台词占镜内时长超 75% 同样报「无动作余量」提醒（同规）。

## 6. 字数预算与信息优先级

- 硬顶 **20000**；**目标 8000–15000（2026-10-20 用户指令：无限思考剧情演绎、越详细越好——镜头内的剧情、人物细节动作、微表情、生态反应、电影质感全部展开）**；防注水底线不变：每个句子必须贡献画面/表演/声音信息，纯修辞重复仍删。
- **结构占比硬规**：**【时间轴】占比 ≥70%**——它是剧情演绎的主战场；【公共总规范】≤20%（图锚模式：每角色一句图锚条款＋表演核心＋纪律块）；【参考】+【收尾】≤10%。
- 时间轴单拍密度：**600–1200 字/拍**，满配演绎维度——①画面因果链（动作的起势/发力/受激/收势全写）②表演三通道微表情链（脸/手/身，含预备动作与收势）③环境行为（前景/中景/背景三层各自在做什么）④光影行为（光在主体与环境上的实时变化）⑤声音层（环境/动作音点/人声状态，关键点 `<音效>` 标记）。密度范本＝官方手册 MV 舞段例（逐拍编舞级颗粒）。
- **有效密度优先于字数**：600–1200 字必须对应 **2–3 个可见动作节点**；只有心理、比喻、形容词，没有可拍动作的段落判为无效密度，删到能拍为止。静物/空镜不适用 600–1200 字密度，按 ≤2 秒／≤2.5 秒上限写。样片已实证：4900 字/段、367 字/拍仍可全是静态，字数不是质量。
- **阶段 6 反例门**：每段编译后先跑 `audit_wan30_antipatterns.py`；镜头后置、极缓慢、静物/空镜超时、并肩词、缺不看镜头、台词单拍超时、暖光词、字条正写特写任一项未清零，不得进入生成。
- 信息优先级（超预算时从后往前砍）：剧情因果与台词 ＞ 表演三通道 ＞ 空间与光 ＞ 镜头语言 ＞ 氛围修辞 ＞ 特效渲染细节。
- 图锚一致性条款、战损声明、衔接承接、状态链（银纹/道具）**不可砍**。

## 7. 声音与风格的写法

- 音效点：`<枪鸣>` `<布料摩擦声>` 内嵌动作句；环境层独立成句。
- 台词：直引号＋来源标签（口型对白/画外延续/混叠人声…），口型状态必须写。
- BGM：短剧默认无；产品/MV 类项目要用 BGM 时在【公共总规范】声音纪律块显式声明风格与起止。
- 音色：有声线音频参考时写"音色取自上传的音色参考音频"（不写 `@AudioN`）；无声频时沿用文字声线锁定行。

## 8. 标准最终输出格式

```text
【参考】CHAR_01＝身份与服装唯一基准（单人塑像图，全片不变）；LOC_02＝空间拓扑与光位基准（全景）；PROP_01＝形制基准（基础态单张）。参考只提供外观、空间与道具结构基准，不携带剧情状态。
【公共总规范】画风…。【角色一致性】阿泽：短寸黑发、左腕旧钢表、藏青夹克。外观与服装以阿泽的塑像图为唯一基准，本文只写识别锚与状态变化，不重写剪裁与材质。…（其余角色各一句，均按发型／固定饰件／外套品类＋固有色写）。镜头语言：…慢镜/定格≤2次每次≤1秒、静止≤1.5秒…。声音纪律：无BGM，环境层…，音效点用尖括号标记。禁止项：不要字幕、不要穿模、不要轴线错乱、不要角色复制、不要并肩站…。空间锚点：…。承接上段：战损/状态声明。
声线锁定：…（文字兜底；有音频参考时加"音色取自上传的音色参考音频"）
【时间轴】
0-1.5秒，镜头：中景，侧45°机位平视，手持轻晃…。画面：他伸手抓住绳结→回身把绳头甩上肩→抬脚踩住桥板…。声音：<绳索摩擦声>…。
1.5-4秒，硬切。镜头：近景，右后方45°，越过肩拍侧脸…。画面：…（2–3 个可见动作节点）。
```

## 9. 与 S18 适配器的分工

| | S18 适配器（Seedance 2.5） | 本适配器（Wan3.0） |
|---|---|---|
| 字符 | 2000/3000/4500 | 硬顶 20000，用户目标 8000–15000（有效动作密度优先） |
| 时间粒度 | 整数秒 | 0.5 秒 |
| 时长 | 固定 30 秒 | 2–30 秒弹性/智能时长 |
| 参考 | 应用端图片绑定 | ≤10 图＋5 视频＋5 音频＋文件 |
| 独有块 | — | 图锚条款、`<音效>` 点、禁止项清单、编辑指令附则 |
| 整改 | 整段重生成 | 编辑指令优先（见第 13 节） |

## 10. 编译执行流程

1. 读输入契约全部材料 → 2. 选模式（参考/首尾帧，登记决策）→ 3. 编【参考】＋图锚（先验收参考图类型）→ 4. 编【公共总规范】五块（≤20%）→ 5. 编【时间轴】拍点行（镜头前置＋2–3 动作节点）→ 6. 编【收尾】→ 7. 过第 11 节自检 → 8. 数字符（用户目标 8000–15000，硬顶 20000；密度优先）→ 9. 跑反例审计 → 10. 交六视角评审。

## 11. 输出前质量检查

- [ ] 四段齐全且顺序正确；无镜头 ID／"｜"／箭头／参数清单开场
- [ ] 包内零编号：`@ImageN`／`@图片N` 出现即判错（WAN30-04）；参考块为 `代码＝职责`
- [ ] 视频参考 5/5 为单人全身塑像图（单张、全身、含下装与鞋、正面、占高 92%–94%、中性浅灰底、无文字）；四视图 0 张进视频
- [ ] 参考图单人：无镜像/水面倒影/背景路人/海报/照片/人台；场景图 0 人、道具图 0 持物人
- [ ] 每镜主要正脸 ≤3；4+ 人同框已拆镜或后景背影/虚焦；五人全景 ≤2 秒、无台词
- [ ] 每个 4+ 人镜头有人数锁定句和左起位置；无「其余三人/四人」模糊指代
- [ ] 普通水面/玻璃不写清晰人物倒影；幻境复刻行标 `幻境层` 且有「剧情复刻」声明
- [ ] 图锚条款在位；无外貌文字枚举（除非角色无参考图并已申报）
- [ ] 拍点行时间连续覆盖全段；粒度统一；每行只有一个起-止秒，行内不重复时间码；A 段无"硬切"字样、B/C 段非首行含"硬切"
- [ ] 每行 `镜头：` 起句；镜头词在前 30%；每拍 2–3 个可见动作节点
- [ ] 静物 ≤2 秒、空镜 ≤2.5 秒；`极缓慢` 0 处；无并肩/一字排开/并排站/排成一排
- [ ] 每段有 `全员不看镜头`；对话单镜 ≤6 秒；有听众反应切镜
- [ ] 道具首次出现前有时序声明；字条/路牌/车牌无可读乱码风险
- [ ] 光色为阴天散射冷灰；无清晨低角度/金色/暖金/日出
- [ ] 台词逐字＋来源标签＋口型状态；语速 ≤5 字/秒；台词占镜内时长 ≤75%（超出逐条处理）
- [ ] 战损/状态承接声明在位（对照上一段【收尾】与 04b）
