# Wan3.0 提示词生成与编辑适配器 v1.1（保留原路径）

> 与《Seedance2.5 通用提示词生成适配器 v1.0》同构的编译器手册：输入内部逐镜表，输出 Wan3.0 方言提示词。写法标准见 [Wan3.0 提示词规范](wan30-prompt-spec.md)；两轨分工见第九节。v1.0 已完成首轮样片实证（E01-SH01／SH03），暴露的参考图类型与静态摆拍问题已回写为 [WAN30-01](failure-cases.md#wan30-01) 硬规则；v1.1于2026-10-30接入官方数据、按任务结构与编辑分流；未新增样片效果实证。

本次规则来源与层级见 [官方依据](wan30-official-rules.md)，任务判定及独立编辑／延长见 [任务编译](wan30-task-compiler.md)。本页四段编译保持制作包导入兼容，不称为官方唯一结构。

## 1. 适用边界

- 生成模型为 **Wan3.0（万相）** 时使用本适配器；生成模型为 Seedance 2.5 时用 S18 适配器，两者不混用。
- 输入是分镜层产物（阶段 3 逐镜表＋阶段 3.5 打斗判定表），本适配器只做**编译**，不做分镜设计；分镜层规则（小墨 6.3 视感、打斗战斗语法、衔接三接口）两轨共用，编译时不得违反。
- 编译产物的质检走既有六视角＋机检（`validate_compact_package.py --model wan30`）＋反例专项审计（`audit_wan30_antipatterns.py`）。

## 2. 输入契约

编译前必须齐备，缺项即退回补齐：

| 输入 | 来源 | 用途 |
|---|---|---|
| 片段逐镜表（含视感自查、衔接自查） | 内部/04 | 拍点/镜头内容与时长 |
| 打斗路由判定表 | 内部/04b | A/B/C 级与战斗语法、战损源 |
| 资产库（角色/场景/道具图片提示词） | 制作包固定资产区 | 参考职责与身份／服装来源；视频角色参考只用单人全身塑像图（单张、全身、中性浅灰底） |
| 声线母版 | 内部声线规范 | 台词与音频参考登记 |
| 参考素材清单 | 用户/应用端 | 图/视频/音频参考的编号与内容说明 |
| 片段绑定（角色/场景/道具/线索代码） | 制作包片段头 | 【参考】段编制 |
| 上一片段【收尾】 | 制作包 | 入镜承接与战损/状态声明 |

## 3. 生成参数与提示词正文分离

- 时长、比例、分辨率、模式选择由**应用设置**承载；本地包不另写【参数】。无视频输入官方接受2–30整数秒或智能时长，视频参考另占预算；**本项目生产硬规范＝单段固定 30 秒**（2026-11-06 用户指令定版，policy 机检强制）；时间轴0.5秒不能直接作为API duration。真实参数按[官方快照](wan30-official-data.json)核对。
- **模式选择规则**（首尾帧与参考模式互斥；文件／链接与其他参考的组合见[官方依据](wan30-official-rules.md)）：
  - 默认**全能参考模式**（身份由人物图与明确的参考职责承载，见 4.1）；
  - 仅当该段的核心诉求是"从上一段真实尾帧续接"（状态连续优先于身份参考）时，选**首尾帧模式**，并把该决策登记进 04b 判定表；
  - 单条片段内部连续动作直接写本镜状态与运动，不使用跨片段制作备注；内部镜头的硬切与连续运动按分镜登记。

## 4. 四段容器内按官方要素编译

### 4.1 【参考】→ 多模态参考层

- 【参考】只写 `代码＝职责`，**代码后不重复名称**（应用会把代码解析成资产名，重复名称会渲染成「娜琳 娜琳＝…」），**不写任何图片编号**；正文指代角色用姓名，不用 `@ImageN`。编号由应用在提交时按本次上传槽位生成，离线包写死必然错位（WAN30-04）。
- 职责声明沿用（外观/空间锁定），不内联角色卡。
- **参考图类型前置验收**：Wan3.0 的角色视频参考是**单人全身塑像图**——9:16 竖版单张、单人单身体、全身入画、**正面**（身体正对、头正、双眼平视镜头，最多 5° 微侧）、中性站姿、中性浅灰无缝背景、人物占高 92%–94%、画面无文字、无场景陈设。资产卡上禁止写「3/4」「不看镜头」「视线落在画外」——那会把人拍成斜侧面，正脸数据损失一半。同一张图同时锁身份与服装。四视图/多视图拼版不得挂进视频参考（会被应用追加"不同观察角度"句，与"单张"正文互斥）。换图前先验：单人、全身、含下装与鞋、无文字、无第二个人。
- **人物身份与着装来源（R6／OUTFIT-04）**：在【参考】逐角色声明身份职责；默认图承担默认装，有变体时人物图只锁身份、服装资产锁指定覆盖范围并明确穿着者。全段仅声明一次，不再输出独立【角色一致性】或公共层“着装来源”重复指针，具体写法见[共用质量契约 §2](prompt-quality-contract.md)。场景不重写建筑材质，道具不重写形制；动作与状态变化正常保留。
- **模式 A（仅当角色无参考图时）**：才使用文字枚举（从资产卡逐字照抄），并在交付时标注"该角色无图锚，一致性弱于图锚角色"
- 状态类道具（如古图银纹）不是外貌——状态变化仍由提示词层按剧情声明

### 4.2 【公共总规范】→ 全局设定

先写“总体描述：”，用一两句交代当前片段的核心事件、情绪及节奏。再按实际需要组织下列内容；声音来源、声线与文字纪律等项目硬项仍按其触发条件执行，不输出空字段或粘贴所有词典。整体不要求每镜都有全部控制维度。
1. **画风与质感**：沿用项目设计基准的画风段，补材质与光影级别描述（本项目为真人现实主义电影摄影：物理光照、自然比例、可辨实物材质、皮肤哑光保留细纹；不写死为 3D 国漫或任何单一画风）
2. **镜头语言**：按冻结分镜声明主要运动与轴线，必要时写起点、路径、速度变化与落点；慢镜／静止配额来自本项目分镜及反例策略，不是官方参数，不向独立编辑任务扩散
3. **声音纪律**：无 BGM（短剧默认）、环境层构成、音效点标记约定（`<音效>`）
4. **禁止项清单**：独立一行，仅列本段适用的生成缺陷；人物／数量／血珠／遮挡／背景构图等正向设计放入口或对应镜头，禁止把局部画面写成全段规则。单框正文不等于独立负向通道。字幕由第 5 块统一承担。
5. **画面文字纪律（公共层统一，禁止任何字幕）**：含对白、心声或旁白的片段，`【公共总规范】`固定写入一行以 **`画面文字纪律：`** 开头的句子，正文**逐字取自下方统一句，不逐条改写、不因本段场景调整**（机械派生，如同 `声线锁定：`。规范出处 [TEXT-03](failure-cases.md#text-03)、[R39](rule-map.md)）：

   > `画面文字纪律：全片段无字幕、翻译字幕、角色名条、标题、时间码、角标和水印。对白、心声及画外声音不转成画面文字；剧情需要的手机、纸张等场景内文字按镜头要求保留。`

   片段内不再逐镜重复（公共事实定义一次）；无台词、无心声的纯动作/空镜段可省略本行。禁止把它并进禁止项清单当作普通否定项。
6. **空间锚点**：本段的空间调度锚（如"芦苇丛边界/岩石群/湖岸"三点动线）＋战损延续声明（如上段有战损）
7. **否定写法纪律（正向白名单）**：生成模型对否定词低敏感、具象名词每多出现一次显著度递增——「X 不出现在画面内」在文本特征里约等于「X 出现」，写两次即加权（实机案例：正文两处「南瓜不在画面内」反致南瓜入画）。执行四条：①正文只写"有什么"，空位用真实物件或「空置」填满，不点名被排除物；②排除用白名单不用黑名单——「画面只有 A、B、C」替代「X 不入画／不出镜／未出镜」（fast_gate 第 0 步硬错）；③要排除的物件若来自参考图，改图不改字（重生成或裁剪，图的特征永远大于文字否定）；④平台有独立负向输入框时，被排除的具象名词以**裸名词**填负向框（负向框内点名经 CFG 相减有效，正文内点名无效）；提示词为单框拼接时，负向行也只保留乱字、水印等抽象缺陷类，不点名具象物

### 4.3 【时间轴】→ 时间戳戏剧分镜

- 粒度 **0.5 秒**；单段固定 30 秒（2026-11-06 硬规范），时间轴首尾相接覆盖 0–30.0 秒。
- 每行＝`起-止秒，`＋**镜头前置**（`镜头：景别/焦段/机位/运镜`，放在行首前 30%）＋**本镜必要的动作/表演及结果（动作数量服从冻结分镜，微表情遵守E25）**＋**声音层（自然语言＋`<音效>`点）**。镜头写在几百字画面描述的最后，模型会当作可选备注；样片已实证。
- 拍点间过渡写明（A 级一镜到底段：`镜头不停，随…`／`焦点从X切到Y`；B/C 级硬切段：`硬切，`）。
- 台词：直引号 "…"＋七类来源标签＋口型状态，逐字取自剧本。对话单镜 ≤6 秒；长句拆说话镜＋听众反应镜，画外延续写明同一人不切正面。
- 关键音效用 `<音效>` 内嵌；环境层保持自然语言整句。
- A 级段禁"硬切"字样；拍点间为运镜/焦点过渡。
- **反例约束（WAN30-01）**：静物拍 ≤2 秒、空镜 ≤2.5 秒；每段最多 1 个纯静物插入；删 `极缓慢`，所有运动改成可量化位移；禁三人以上人物 `并肩/一字排开/并排站/排成一排`（两人并肩、台词比喻、影子/倒影排列不算）；每段写 `全员不看镜头`，视线落对手/道具/远处；道具首次出现须交代获取或持有依据，入镜前只写实际可见状态（如空手），不点名否定物；字条只拍纸背/纸边/手指遮字；光色继承用户画风与本场已确认的真实光源，不强制天气或色温。
- **人物进出与画外承接（WAN30-02）**：多人同场时按冻结分镜写清关键镜头的入镜者、相关画外人物位置及必要的走入动作；硬切后可直接看到已在场人物。提交前核对实际图片与平台自动追加的参考说明，解决单人图与多视图描述冲突；画外声音保留角色身份与声线绑定，图片是否上传按入口能力决定。详见 [逐镜验收](wan30-prompt-spec.md#多人镜头人物进出与参考图核对wan30-02)。
- **人物分身约束（WAN30-02）**：每镜主要正脸 ≤3 张；4–5 人场拆成 2–3 个镜头，后景用背影/虚焦；五人全景每段 ≤1 次、≤2 秒、无台词；每个 4+ 人镜头写人数锁定句（`本镜画面内恰好N人：左起…；每人只有一个身体、一张脸；不出现第N+1人`）；参考图必须单人，无四视图/镜像/背景人；普通水面/玻璃写「不映人物」，只有幻境复刻才写「倒影」并标 `幻境层`。**不要只写「不要角色复制」——负向禁止不是人数控制。**

### 4.4 【收尾】

**硬规范**：整条提示词只描述当前片段的画面、动作与声音；任何段落均不得写上下片段的场景或跨片段衔接指令。上下片段关联只在内部合同核对。

只写当前片段最后一镜已经成立的可见出口状态（必要的站位、持物与伤情），不新增动作、不要求持续停留，不描述下一段场景、人物、对白或动作。下一段入口保存在内部连续性合同并写入下一段首镜；参考图或正文不能保证实际尾帧衔接。

## 5. 时间轴编译规则

- **沿用阶段3已验收的镜头与切点**，编译阶段只转换提示词表达；B/C镜头不重新合并、细拆或重排时间，A级拍点也逐项继承。发现上游不可执行时登记具体漏项并定向修复，不擅改冻结规划。
- B/C级多镜片段逐镜继承已验收的时间轴；本项目30秒默认6–11镜、5–10次硬切，不再套另一套拍点数量建议。A级一镜到底的拍点是镜内动作节拍，不是硬切镜头；数量按已验收的攻防与表演节拍确定，不套多镜镜数带。
- 连续性：起止秒首尾相接覆盖全段；时间粒度全段统一（不混用 1 秒与 0.5 秒粒度造成节奏误读）。
- 中文台词按汉字语速规则检查；泰语等非中文台词按[原语估时规范](voice-and-dubbing.md)登记朗读估时与停连，两者之和不超镜内窗口。语音与动作可以自然并行，不机械相加；中文翻译不计入实际发声，中文语速数值不得直接套给泰语。

## 6. 内容完整性与硬上限

- 每条完整视频提示词仅设 **18000 个 Unicode 字符硬上限**，含标点、空格与换行。**无字数下限、目标带、单拍字数配额或章节篇幅占比门槛**；不因短判过简，不因长判详细，不以补字数作为返工理由。
- 逐镜使用[逐镜内容验收](wan30-prompt-spec.md#逐镜内容验收)：剧情与入口、动作因果与结果、构图/运镜/焦点、情绪表演、实际光影/环境、台词/声音/口型、出口衔接。按本镜职责把相关细节写足；未发生的变化不编造，纯反应镜和空镜不为填配额硬加动作。
- 公共层按画风、角色、镜头、声音与空间组织；公共事实定义一次，时间轴按冻结镜头顺序写本镜变化。可在同一时间行内用「镜头：…。画面：…。表演：…。对白：…。声音：…。」帮助阅读，字段按实际需要使用，不另加导入标题、不输出空字段、不把一句话拆成孤立参数。每个硬切镜头仍独占一个时间行。
- **详略按执行需要决定**：动作的起势/接触/受激/收势、环境遮挡、光影变化和声音时点在影响画面时写清；情绪用少量有效可见线索表达，遵守微表情层，不强制每镜同时展开脸/手/身或让前中后景都动。删掉同义复述，也不得删成只有摄影术语的摘要。
- **反例审计与处置**：作者逐段运行lint，硬错阻断，风险提醒留给独立评审。全集审计按[Wan风险提醒处置](prompt-review.md#wan风险提醒处置)记录证据并通过严格检查；暖光等词汇命中不一律删词，硬错不得用处置记录豁免。
- 信息优先级（超预算时从后往前砍）：剧情因果与台词 ＞ 必要的情绪与表演 ＞ 空间与光 ＞ 镜头语言 ＞ 氛围修辞 ＞ 特效渲染细节。
- 有效身份／服装参考职责、战损、衔接与关键状态信息不可因压缩丢失；无需保留重复指针句。
- **逐镜质量与表达**：执行[共用质量契约 §1](prompt-quality-contract.md)六项验收。机位／光线／动作／表演／声音按本镜职责选择，关键过程写足，不要求平均展开。历史逐镜篇幅案例不设目标；允许按具体缺口定向重写，不为增加字数返工。
- 超过硬上限时先删除重复事实、无关修辞和内部说明；不得通过删台词、动作因果、表演转折或关键切点强行压短。必要内容仍无法容纳时，只回查受影响片段的既定规划并定向复评。

## 7. 声音与风格的写法

- 音效点：`<枪鸣>` `<布料摩擦声>` 内嵌动作句；环境层独立成句。
- 台词：直引号＋来源标签（口型对白/画外延续/混叠人声…），口型状态必须写。
- BGM：短剧默认无属于本地声音方案；用户／冻结方案要求音乐时写明风格、强弱、起止与对白关系。无台词、无BGM与关闭音轨分别控制，不能互相替代。
- 音色：有声线音频参考时写"音色取自上传的音色参考音频"（不写 `@AudioN`）；无声频时沿用文字声线锁定行。

## 8. 标准最终输出格式

```text
【参考】CHAR_01＝身份与默认着装基准（单人塑像图）；LOC_02＝空间拓扑与光位基准（全景）；PROP_01＝形制基准（基础态单张）。参考只提供外观、空间与道具结构基准，不携带剧情状态。
【公共总规范】
总体描述：写清当前片段的主题、核心事件、情绪变化与收束方向，只描述本段。
画风与质感：沿用项目确认的媒介、造型与色调，写清本场实际光源与必要变化；3D按比例／材质／光照、2D按轮廓线／上色／空间组织选择相关信息。

镜头语言：写清本段相机所在的轴线侧及适用的运镜和静止约束；全员不看镜头，视线按镜头行指定。
声音纪律：环境底噪延续，动作音贴合接触时点，无BGM。
画面文字纪律：全片段无字幕、翻译字幕、角色名条、标题、时间码、角标和水印。对白、心声及画外声音不转成画面文字；剧情需要的手机、纸张等场景内文字按镜头要求保留。
禁止项：仅保留本段适用的生成错误约束，不反复粘贴长清单。
空间与入口：写清本段开始时的站位、持物、光向与已有伤情；不写这些状态来自哪一段。
声线锁定：…（文字兜底；有音频参考时加"音色取自上传的音色参考音频"）
【时间轴】
0-4秒，镜头：中景，摄影机在阿泽侧前方约45度平视，随他转身短移。画面：他伸手抓住绳结，回身把绳头甩上肩，随后抬脚踩稳桥板。声音：绳索擦过衣料，脚下桥板在受力时轻响。镜尾：绳头搭在肩上，脚已站稳。
4-7.5秒，硬切，镜头：近景，从阿泽右后方约45度越过肩部看向侧脸。画面与表演：承接站稳后的动作结果，写本镜真实发生的变化。对白与声音：如有台词，写明实际说话人、原句、声音来源与口型；动作音跟随本镜接触点。
…
【收尾】…仅当前末镜已成立的出口状态…
```

## 9. 与 S18 适配器的分工

| | S18 适配器（Seedance 2.5） | 本适配器（Wan3.0） |
|---|---|---|
| 字符 | 2000/3000/4500 | 仅硬上限 18000，无字数下限或单拍字数配额；按逐镜清晰完整性验收 |
| 时间粒度 | 整数秒 | 0.5 秒 |
| 时长 | 固定 30 秒 | 单段固定 30 秒（2026-11-06 硬规范） |
| 参考 | 应用端图片绑定 | ≤10 图＋5 视频＋5 音频＋文件 |
| 独有块 | — | 图锚条款、`<音效>` 点、禁止项清单、编辑指令附则 |
| 整改 | 整段重生成 | 编辑指令优先（见第 13 节） |

## 10. 编译执行流程

1. 读输入契约全部材料 → 2. 选模式（参考/首尾帧，登记决策）→ 3. 编【参考】＋图锚（先验收参考图类型）→ 4. 编【公共总规范】六块（公共事实写一次；含对白、心声或旁白的片段必须含 `画面文字纪律：` 统一句）→ 5. 编【时间轴】（镜头前置、完整动作/表演/声音）→ 6. 编【收尾】→ 7. 按逐镜内容验收和第 11 节自检 → 8. 检查不超过18000字符（不查下限、目标带、单拍字数或篇幅占比）→ 9. 跑反例审计 → 10. 全集完成后交既有独立评审，风险按[处置契约](prompt-review.md#wan风险提醒处置)留证，并过阶段4严格门。

## 12. 禁止事项

镜头项目编号、"｜"字段、箭头缩写、参数清单开场、站桩说话、打空气、无受击承接、战损跨段消失、内联与已锁参考冲突的角色卡、未获确认的388画风参数、超配额慢镜/定格、轴线错乱、角色复制、字幕水印 BGM（短剧默认）、编造台词；**三人以上人物并肩/一字排开/并排站/排成一排（两人并肩、台词比喻、影子排列除外）、五人正脸同框、4+ 人同框说话、普通反射出现清晰人物倒影、参考图多人/四视图、极缓慢、静物>2秒、空镜>2.5秒、对话单镜>6秒、看镜头、字条正面可读文字、无冻结来源的暖金逆光、正文具象名词否定句（不在画面内/不入画/不出镜/未出镜，见 4.2 第 7 块）**。实际暖光不按词汇一律禁止，依第6节处置。

## 13. 按任务编写与编辑附则

完整操作见 [任务编译模块](wan30-task-compiler.md)。先区分：

1. **文字修订**：只修错误引用、结构冲突、缺失因果或声音／时间问题；不需要原视频，不声称画面已修改。
2. **原视频编辑**：有真实输入后，写定位对象／范围、目标变化、保留事实和必要的影子、遮挡、接触或口型联动。不要用“全部完全不变”否定本次改动；独立指令可用已上传的图／视频／音频编号，无需新写四段故事。
3. **视频延长**：写方向、原片边界状态、新内容、声音及结束状态；另外核对输入视频与输出预算，不沿用旧版总长计算，不归为“无需重排的局部编辑”。
4. **视频修复选择**：只在实际成片有偏差时权衡编辑和重生成；文本或冻结事实有错先修来源。结果复验覆盖修改点、附带变化和相邻接口。

实际请求JSON可另用 `scripts/validate_wan30_request.py` 核对官方素材组合与已知参数；没有媒体时长信息不得假报完成。它不运行四段／硬切／跨片段包契约，也不替代实际生成和验收。

服装变体片段必须先按[OUTFIT-04](outfit-variants.md#片段级着装来源解析outfit-04必须执行)解析人物与服装职责；上文默认装示例不用于已绑定变体的角色。
