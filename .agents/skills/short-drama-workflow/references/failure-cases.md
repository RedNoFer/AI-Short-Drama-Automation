# 反例归纳与防错检查

用于接收用户持续提供的提示词问题、参考图和生成视频，把可复用结论写进后续创作与评审。按下面索引只读取当前任务相关的类别；新增类别须有实际材料依据，不预先堆叠假想问题。

用户批量提供反例时，按[反例投喂契约](failure-intake-contract.md)的格式与五步处理流程执行：归类合并 → 偏差/原因/修订/验证分栏 → 接入实际检查点（机检或评审视角）→ 回写规范并按规则传播登记表逐项核对 → 给用户回执对照表。复盘本身不启动生成。

## 接收与更新

1. 以用户最新更正的提示词和真实参考映射为准，核对期望、参考素材与实际结果。只有提示词时记录文本风险，只有静帧时不推断未见的动作或声音；不要把旧版输入或上一轮诊断当事实。
2. 为案例保留可追溯的来源、有效版本和关键证据。必要的提示词、场景图与证据帧保存到资源根目录的审查/整改输出，Skill 中只留摘要、规则和链接；用户没有要求重新生成时，复盘本身不启动生成。
3. 区分「已观察的偏差」「待验证的原因解释」「可执行修订」「修订后的验证状态」。输入含糊可能增加风险，但有参考图或详细约束也不代表模型会遵循；不可将每项生成错误都声称为已证实的提示词缺陷。
4. 按问题类型合并案例，提炼适用条件、编写动作与可判定的通过条件；把检查接入相应资产、分镜或提示词评审。已有规则仍漏检时，修正触发与检查位置，不追加同义口号。
5. 用失败样例和邻近的合理样例复核新规则，避免误伤正常反打、自然遮挡、画外角色或有剧情依据的移动。保留用户已经锁定的人物、座位、对白、节奏和媒介；需要调整具体方案时说明原因，不把历史案例配置推广到所有作品。

## CONTENT-01

### 已观察案例：2026-10-27《千金重生》02—04生成审核拒绝

- **证据**：项目目录 `创作输出/千金重生_曼谷_第一章_Wan30_重新制作/内部/画面表达优化-20261027/`，含用户截图、修改前完整包、逐段修订、独立复核与版本差异。
- **已观察**：截图02、03标记 `rejected text (input)`，04标记 `rejected image (output)`；平台未返回具体命中词，也未取得被拒输出图像。原02含直接窒息伤害画面，03含前世受压回忆，04有被单与握袖动作描述。
- **原因状态**：直接伤害展示、衣着或动作歧义是排查候选，尚未由平台逐项确认；不能把遗像、丧事、妆容词或某句泰语宣布为通用禁词，也不能把输出图像拒绝等同文本输入拒绝。
- **已执行修订**：02省略直接伤害过程，改为推远当票、门内人物占住出口、前景遮挡、地面鞋影与女主反应；03/04明确完整着装及被子位置、调整握袖距离。保留母亲疑点、重生辨认和原语台词，并检查本段道具绑定与收尾。
- **验证状态**：局部独立文本复核和格式/差异检查完成；未重新生成，未验证平台审核通过。保留的泰语仍有前世袋子与受压记忆，不能称“敏感词已全部清零”。
- **接入检查点**：按[剧情保留与敏感内容表达](content-expression.md)在阶段3确定观众接收事实的方式，阶段4跨语言/参考/收尾检查，在原有独立评审中验收；自动派单纳入必读（R38）。不新增未经验证的关键词黑名单或额外评审轮次。
- **邻近正常情形**：完整穿衣的床边惊醒、日常袋子、家庭丧事本身不自动违规；只有门影、没有行为结果或可信陈述时，不能据此声称已经清楚交代了殴打或死亡。

## CHARACTER-01

### 已确认案例：三个已交付包共 17 个角色

- 预期：[资产图制作规范](asset-image-production.md) 的九块字段＋E23《角色资产提示词生成器》的「轮廓骨相 → 眉眼鼻唇关系 → 妆面 → 皮肤」质量底线，应让每个角色的脸、妆、发、饰件、服装都成为可验证项。
- 实际：逐项扫描 17 个角色的图片提示词——服装结构 14/17、材质 15/17、体态 17/17、发型 16/17 都到位；**脸型骨相 3/17、鼻 7/17、唇 9/17、妆造 2/17**。三千国道-Wan3.0 五个角色的脸只剩「五官锋利干净」一句，鼻和唇全无。三个项目的内部档案里「妆」只出现 1 次（叔叔·桂芬「妆容偏浓」）。
- 已观察：三个根因并列——①工作流的人物字段清单**没有「妆面」这一块**（E23 有、工作流没有，口径不一致，工作按工作流走）；②Wan3.0 的**图锚纪律被误用到图片资产提示词**上（图锚是给已有参考图的视频正文用的，图片板自己就是要生成的那张图，没有可锚对象）；③机检对资产图片只查「非空／画幅／版式」，字段完整性零校验，所以连续三个项目缺失无人发现。
- 状态：`asset-image-production.md` 人物字段改为九块（骨相／眉眼鼻唇相对关系／妆面与皮肤／发型与发饰／饰件／服装三层／体态／媒介画风／版式）；`policy.assets.character_prompt_groups` 加七组软检查；`validate_compact_package.py` 对每个角色报缺失组（提醒级）；`wan30-prompt-spec.md` 标明图锚适用边界；阶段 2 落盘新增**角色美工账**。

### 必须落实的编写动作

1. **妆面必须做决定，不能留空。** 素颜写「素颜，不施妆」、无饰件写「无饰品」；留空等于把美颜和随机首饰交给模型。
2. **脸写成一条连续轮廓。** 额头—鼻梁—唇—下巴在正面和侧面必须接得上；只写「五官精致、眼神深邃」不算写了脸。
3. **发饰要能接背面。** 发簪／发夹／发带／发冠写固定位置、材质与佩戴方式；正面盘髻背面披发是四视图最常见的断裂。
4. **信物要写佩戴纪律。** 旧手绳、婚戒、工牌写「四视图全程佩戴、不得换手、不得变新」——它是跨集身份锚，不是装饰。
5. **图锚只用于视频正文。** 固定资产的图片提示词必须写全外貌；把图锚套到图片板上，等于让模型决定全剧的脸。
6. **账上要有一行。** 每个角色在 `03-资产与空间设计.md` 的角色美工账里登记五项；只写在提示词里、账上没记，算未定版。

## DIALOGUE-01

### 已确认案例：《三千国道逆己而行》10 集 45 片段定稿

- 预期：S02 第 88 行要求对白镜「按念白托底（中文约每秒 5 字），**再往上留 2-3 秒给动作和呼吸**」——5 字/秒是**镜长下限**的经验值，动作余量是配套要求。
- 实际：流水线把 5.0 登记成 `voice.max_hanzi_per_sec` 的**语速上限**（脚本判错级），「2-3 秒动作余量」整句丢失。实测 100 条带台词镜头行：按现行口径只有 **1 条**不合格；按原文口径（镜长 ≥ 台词/5+2 秒）**81 条不合格（81%）**。台词占镜内时长中位 **80%**、p75 88%，**55% 的镜头行超过 75%**——镜内几乎只剩说话，没有动作。
- 已观察：出处经验值被升格为精确到小数点的硬标准，**改造过程没有登记**；结果是检查在错误的维度上过严（4.99 通过、5.01 报错），在出处真正关心的维度上完全空转（画面已经比说话还短却不报）。同一根因也解释了该项目「对白驱动、动作行仅 15%」的视感问题。
- 状态：`policy.voice` 增 `max_hanzi_per_sec_source`／`max_hanzi_per_sec_note`／`dialogue_share_warn: 0.75`／`dialogue_share_exempt_keywords`；`validate_compact_package.py` 新增按片段的「动作余量」提醒（聚合为一条，带最紧镜的起秒与占比）；`compact-import.md`／`prompt-review.md`／`tier3-prompt-spec.md`／`wan30-adapter-v1.0.md`／`failure-cases.md` 同步标出口处与改造性质。

### 必须落实的编写动作

1. **引用 5 字/秒必须带出处与性质。** 写成「S02 念白托底，已改造为语速上限」，不得写成「规范要求 ≤5 字/秒」——把改造当成原 skill 的硬标准，下一个人就查不出偏差。
2. **阶段 4 每条含台词片段跑机检，动作余量提醒逐条处置。** 三选一：拆台词到相邻镜、补动作/反应镜、或在该行写明保留理由（情绪特写、静态压迫感）；未处置按「重要」计，不许沉默放过。
3. **长台词拆镜，不许提速。** 台词说不完时先看能不能拆到相邻镜或改成动作表达；把时长压到贴线是最后手段，且必须申报。
4. **补的是动作，不是表情。** 动作余量不足的片子常见修法是加"皱眉/眼神"，那不是动作。补镜要有人物位移、手部操作、道具接触、环境反应中的至少一项。
5. **执行账留痕。** 登记本片段的动作余量处置结果（拆了几镜/补了什么动作/保留了哪镜及理由），与字秒比检查同一行。

  1. 变体图改为**单张纯服装平铺图**：俯拍平铺或隐形模特，中性浅灰无缝背景，单画面无文字；**画面里不得有人体、人脸、模特、假人、手**。

  4. 变体片段的**第三锚换成变体上装**；镜内换装写「前半 A→后半 B」；【参考】写「PROP_xx＝本段服装唯一基准，由 CHAR_xx 穿着」，角色条目降为「身份基准（脸、发型、身形），服装以 PROP_xx 为准」。
  5. 机检新增：变体图版式与风格锚、参考行「唯一基准」、第三锚未换默认外套；服装冲突检查改为在变体绑定后仍校验文本锚。

### 必须落实的编写动作

1. 写变体提示词前，先写「真实服装产品摄影」风格锚，再写版式。
2. 只出「一套衣服平铺/隐形模特」的单张图，不生成人、脸、手或穿着态。
3. 生成后只核对衣服：件数、廓形、材质、颜色、磨损；脸由角色塑像图单独锁。
4. 绑定变体的每个片段，逐个角色改第三锚与参考行；不要只改资产、不改片段。
5. 跑 `validate_compact_package.py`，确认没有「平铺/设定板」「缺风格锚」「没写唯一基准」「仍写默认装」四类错误。

## SCENE-02

### 已确认案例：《替身千金》盐田、巷口、庭院三张场景图

- 预期：泰语写实剧情片，低饱和、自然瑕疵、哑光材质，像现场记录照，不像旅游海报。
- 实际：三张图都是高饱和、HDR、湿亮反光、金边与光晕，道具像塑料，和剧集写实调性明显不符；盐田远景还多出人影。
- 已观察：旧提示词大量写「柚木的深色纹理与油润」「青石板的湿反光」「车身与车窗出现硬边高光」「墙头强逆光把藤蔓打成金边」「灯下有一圈暖黄光晕」「粗盐结晶的反光颗粒感」；风格锚是「电影写实摄影＋暖金＋中高饱和＋暖金光斑」，没有反 HDR／非 CG／低饱和锚。模型把「电影感」读成了海报感。
- 状态（2026-10-23 落地）：`asset-image-production.md` 新增**真实感锚**；三张场景与相关道具提示词改为哑光材质、低饱和、自然瑕疵，并补反 HDR 负向；视频公共风格「中高饱和→低饱和」「暖金光斑→自然虚化」；`validate_compact_package.py` 新增油润词判错与真实感锚提醒。

### 必须落实的编写动作

1. **真人资产先写真实感锚，再写内容。** 固定开头：「真实现场照片，35mm 胶片或手机随手拍质感；不是电影海报、不是CG渲染、不是游戏场景、不是建筑效果图；自然光，低对比，低饱和，轻微噪点与灰尘，不锐化。」
2. **材质哑光优先。** 木写干哑、有灰尘与使用痕，不写「油润」；墙石写粉化、吸水、发灰，不写「湿反光」；金属写氧化、指纹、划痕，不做均匀镜面；盐/粉/土写干、粗、颗粒感，不写「反光颗粒」。
3. **只写真实光源允许的局部「柔和高光」。** 不写「硬边高光／金边／光晕／丁达尔／镜头光斑」；这些词会把图推向 HDR 和塑料感。

### 必须落实的编写动作

1. **先固定实体空间，再摆人物。** 按素材/剧情确定前后、左右、内外和不可移动地标；登记关键结构数量。车辆左右相对车头定义，房间位置相对固定门窗定义；屏幕左右随观察方向变化。原有驾驶位、门、座椅或操作台不能为了满足新动作被复制。

- 已观察的缺陷：v2 的镜头行把景别与运镜写成「大全景→远景横向缓摇」「中景过肩转拉远」这类箭头缩写与名词堆叠，读者与生成模型都要解码才能理解；台词只写「说：『……』」，未区分**口型对白／心理独白／画外旁白／画外余音／画外延续**，同一句后又出现「画外延续」字样却不说明发声者是否还在画面内、口型如何，导致「声音到底从哪里出来」无法判定。用户审计提出并要求修入规范。
- 原因状态：规范欠缺两项显式硬要求——镜头行内容的可读写法、台词的来源与口型标注；机检脚本也只查格式，不查这两项。
- 措施（2026-10-18 已回写）：① [提示词质量规范](../references/prompt-review.md) 硬性规范新增「台词声音来源逐句判明」与「镜头行自然语言成句」两条，并进入评审记录与关闭条件；② [单文件导入规范](../references/compact-import.md) 给出七个来源标签表（口型对白／心理独白／画外旁白／画外余音／画外延续／低声自语／混叠人声）与写法要求；③ [SKILL.md](../SKILL.md) 阶段 4 写明写法与标签，阶段 5 写明独立评稿；④ [阶段检查单](../references/execution-checklist.md) 把独立评稿与声音来源结论列入阶段 4 落盘、把独立回归列入阶段 5 落盘；⑤ `policy.json` 新增可机检字段，`validate_compact_package.py` 增加两项硬检查（含对白的镜头行必须带来源标签与「口型」字样；镜头行禁止「景别→运镜」箭头缩写）。
- 同时确认：**质量评审必须由 agent 完成且须独立于起草方**（脚本与生产方自检都不能代替），已写进 SKILL.md 阶段门与 prompt-review 执行位置。

### 历史版本记录（现行 Wan 规则见适配器）

> 以下是事故当时的修复记录。固定五人、每拍动作数量、统一阴天色温和公共层篇幅比例均不作为当前通用要求；现行规则以 `wan30-prompt-spec.md` 与适配器为准，当前通过条件见本节后文。

1. **视频参考图型曾按日期分两代。** 2026-10-20 的结论是「单张场景内电影剧照、3/4 侧身」；**2026-10-23 起 Wan3.0 改为单人全身塑像图**：正面（身体正对、头正、平视镜头，最多 5° 微侧）、全身入画、占高 92%–94%、中性浅灰无缝背景、无文字。四视图两代都不得作为视频参考。换图前先验收；脸稳时不要重做脸。Seedance／H3 轨仍按场景剧照口径。
2. **镜头前置。** 每个时间行以 `镜头：` 开头，景别/机位/运动写在前 30%；禁止把镜头参数堆在几百字画面描述的最后。Wan 轨此条覆盖 Seedance 轨「画面动作开场」的默认顺序，Seedance 轨不变。
3. **每拍 2–3 个可见动作节点。** 动作必须能被摄影机拍到：起身、伸手、转身、按压、擦拭、递接、攥紧、放下、走位。内心只留 1 句，且必须落到一个外部动作上；不要用「心底波澜/寒意与悸动/像一把出鞘的刀」代替表演。
4. **静物 ≤2 秒、空镜 ≤2.5 秒。** 每段最多 1 个纯静物插入；空镜必须带前景人物、雾浪、水珠、光影变化等可见运动。超过 2.5 秒无人物、无动作、无信息变化的镜头一律删或并。
5. **删除 `极缓慢`。** 所有运动改成可量化位移：`每秒约5°环绕`、`2.5秒推进1.5米`、`后拉0.8米`。`缓慢` 可用，但必须带位移或光影变化；没有位移的 `极缓慢` 等于静止。
6. **禁止三人以上的群排。** `一字排开/排成一排/并排站` 不得用于三人以上人物；`并肩` 只允许两人自然并行或台词里的比喻，不得写成五人并列。群像用错位站位：前后景分层、各做各的事、有人背对/侧对、有人蹲下/弯腰/撑车。每个背景人物给一个持续小动作，不能定格当背景板。影子/倒影排成一排是光影构图，不是人物群排。
7. **每段写 `全员不看镜头`。** 视线落在对手、道具或远处；对话默认 3/4 侧脸或过肩，正面镜头只在有明确戏剧理由时使用一次。参考图是正面头像时，此条尤其不能省。
8. **对话单镜 ≤6 秒。** 长句拆两镜：说话镜 + 听众反应镜；画外延续要写明同一人不切正面。10 秒一张脸必然静态，再好的微表情也撑不住。
9. **道具时序写死。** 道具首次出现前写 `本拍 X 不在画面内／空手`；参考图里已有的道具会被模型提前放入。跨拍道具写清持有人、位置、开合/拆封状态。
10. **文字物理规避。** 字条、路牌、车牌不靠负向指令；只拍纸背/纸边/手指遮字，或道具本身为空白纸。`不得出现错误可读文字` 挡不住模型写字，必须让可读文字没有物理载体。
11. **光色写冷灰。** 用 `阴天散射、太阳不可见、色温约5000K、冷灰、无金色逆光`；删 `清晨低角度/金色/暖金/日出`。方向光只保留一个动机，投影浅淡。
12. **压缩公共总规范。** 5 条三锚句合并为 1 条（按姓名写发型／固定饰件／外套品类＋固有色，不写编号映射），总规范压到 ≤20%；省下的预算给动作节点，不给形容词。字数不是 KPI，有效动作密度才是。

## TEXT-01

### 已确认案例：《三千国道逆己而行》江水字条与沙地大字

- 预期：原小说里「止步于此，否则心魔噬人。」「继续向前，代价难承。」是**叙述者引文**，按评审纪律**不得改造成角色台词**；观众只能从画面接收 → 视频提示词层必须声明该行文字并要求可读。
- 实际（改前）：E02 把 PROP_03 绑成「江水字条湿软基础态（**无可读文字**）」，正文却写「纸面近摄只渲染唯一一行逐字正确的中文」——同一件东西两处相反指令，正是本轨明令警惕的**文图冲突**；E05 的 PROP_06 绑法（抽象笔画卡＋文字由提示词层声明）才是对的。资产图侧也仍写「不要：纸面出现清晰可读的汉字」——图片模型渲染中文必然出错，资产图只该给抽象墨痕。
- 已观察：三条约束叠在一起才显出正解——①叙述引文不能变台词；②资产图不能出可读汉字；③观众必须读到 → 唯一解是**分工**：资产图给形态、提示词层给文字。

1. **带字道具的资产图只给形态**：写「墨团/笔道形态，不构成可辨读的具体文字」，负向写「不要出现可读汉字」。不要要求图片模型写对中文。

## WAN30-02

### 已确认案例：2026-10-20 三千国道生成片人物分身（时间码待补）

- 用户报告：成片出现两个一模一样的人物。具体片段/秒数待补；当前最高风险拍是 E01-SH01 5.5–11 秒五人正脸同框，以及 52 段中 27 个「五人全景/五人围拢/五人站/五人并肩」类拍（最长 6 秒）。
- 已观察：每段提示词都已写「不要角色复制，每个角色在世界空间中仅有一人」，成片仍分身——**负向禁止不是人数控制**。这与此前「字条不得出现错误文字」仍乱码同构：没有物理/结构约束的否定句，模型可以忽略。
- 文本层风险：
  - 27 个五人同框/群像拍，5 人正脸同框最长 6 秒；
  - 多拍一行内连续点名 5 个角色、每人一段动作，模型要在 5 张脸之间绑定身份；
  - 部分五人同框拍同时有台词/近景（可用审计脚本列出）；
  - E02-SH03、E02-SH05、E08-SH01 等有「倒影/复刻/镜像」，其中部分是剧情需要的幻境复刻，部分只是水面反光；模型无法区分「剧情复刻」与「多生成一个人」。
- 原因状态：四视图参考图是已确认的结构性原因（一张卡含 4 个身体）；五人正脸同框 + 负面禁止是提示词层的高风险设计；本次分身的具体触发需时间码/帧确认，但修复方向不受影响。

### 必须落实的编写动作

1. **参考图必须单人。** 每张角色视频参考只能有一个人；禁止四视图、双人合影、镜面/水面倒影、背景路人、海报/照片/人台。参考图里出现第二个身体，模型就可能把它当成第二个角色。
2. **每镜最多 3 张正脸。** 一场戏需要 4–5 人时，拆成 2–3 个镜头：前景两人正脸、后景三人背影/虚焦；或左组两人、右组三人，用过肩/反应镜连接。不要在一张画面里同时给 5 个人正脸和 5 套动作。
3. **人数锁定句写在镜头句之后。** 正面写清，不靠「不要分身」：
   `本镜画面内恰好三人：左起阿泽、苏晚、老杨；每人只有一个身体、一张脸；不出现第四人。`
   禁「其余三人/四人」这类模糊指代。
   **五人镜头只点名三人、另两人按服装特征定位**（2026-10-22 裁决）：本轨「同镜具名 ≤3」与「4 人以上须有人数锁定句」直接冲突，裁决取前者优先，例
   `本镜画面内恰好五人：左起苏晚、老杨、阿泽、黑色机能马甲的年轻女性、亮蓝防风外套的少年；每人只有一个身体、一张脸；不出现第六人。`
4. **五人全景预算：每段最多 1 次，≤2 秒，无台词、无复杂动作。** 只用来交代队形/空间；正脸、对话、拆图、打斗一律拆镜。五人全景优先拍背影/剪影/远景小人，脸小到无法分辨身份反而更稳。
5. **反射纪律。** 普通场景写「水面只映山影/天光，不映人物」「玻璃只映车外雾，不映人脸」；只有剧情明确的幻境复刻才写「水下复刻倒影」，并且必须在该行标 `幻境层`，同时写「这是剧情复刻，不是第二个真人」。不要把「倒影」「镜像」当普通环境词随手写。
6. **参考图按镜绑定。** 只挂本镜真正露脸的角色的参考图；5 人全景若必须挂 5 张，脸要小/背对/虚焦。能在 2–3 人镜里讲完的戏，不要为了「都在」硬拉五人同框。
7. **场景/道具参考也要单人/空场。** 场景图不能带人；道具图不能带持道具的人；否则模型会把参考图里的人一起复制进画面。
8. **后期先数脸，再谈修。** 生成后逐帧数主要人脸；发现同脸重复，优先拆镜重生成，不要只加「不要两个阿泽」。编辑指令可用于抹掉边缘多余人影，但结构性分身必须回炉。

### 通过条件

- 样片 0 处非剧情需要的同脸重复；每个镜头主要正脸 ≤3 张。
- 五人全景每段 ≤1 次、≤2 秒、无台词；五人同框不出现 5 张清晰正脸。
- 每个 4 人以上镜头有人数锁定句和左起位置；无「其余三人/四人」模糊指代。
- 普通水面/玻璃不出现清晰人物倒影；幻境复刻行标 `幻境层` 且有「剧情复刻」声明。
- 角色参考图 5/5 单人、无镜像/背景人/海报；场景图 0 人；道具图 0 持物人。

### 复核与误判边界

| 情形 | 判断与动作 |
|---|---|
| E02-SH03 水下五个复刻倒影、E08-SH01 镜湖倒影 | 剧情需要，允许；必须标 `幻境层`，并让倒影呈半明半暗/慢半拍/水纹扰动，与真人区分 |
| 一人照镜子/水面倒影，画面明确是反射 | 允许；但倒影要虚、暗、随水面/玻璃变形，不能是第二个清晰实体 |
| 两个不同角色穿相似衣服、发型接近 | 不是分身；按脸/身份锚点判断，不按服装颜色 |
| 背景路人/群演与主角撞脸 | 是风险；场景图与群演参考要避免同脸，后期换脸或虚化 |
| 五人全景拍背影/剪影，脸不可辨 | 允许；这是控制身份预算的手段，不是「没拍清」 |
| 剧情需要双胞胎/克隆/真假身份 | 允许；必须在剧本层明确，并在该段写清「两个实体均为剧情角色」，不能靠模型即兴 |
| 模型切点准确但人物多出一个 | 判为身份预算/参考图问题，不判时间轴失败 |

**排查顺序**：先看参考图是否单人 → 再看该镜是否 4+ 正脸 → 再看行内是否有倒影/镜像词 → 最后才怀疑模型随机性。不要一上来就堆「不要分身」。

3. **状态变化用「在参考图服装基础上…」。** 淋湿、沾泥、拉起帽子、解开前襟、卷起袖口可以写；**改款式、换颜色、增减饰件一律不行**。

5. **包内不写 `@ImageN`。** 编号由应用按上传顺序生成，写死必然错位；正文用姓名点名，机检 WAN30-04 直接判错。

7. **图与词冲突时，成片不会替你选。** 近景、正脸更吃参考图，全身、远景更吃文字，结果是同一段里两套并存（许棠三套衣服就是这个机制）。所以冲突只有两个合法出口：重出图，或改表并同步改正文三锚。**用户拿来的卡是裙子，就把表和三锚改成裙子**，不许嘴上写工装裤。

- 同一片段内，同一角色的**发型、眼镜/饰件、外套颜色**三项完全不变。
- 正文出现的每个服装锚词，都能在该角色图片提示词中逐字找到。

### 复核与误判边界

| 情形 | 判断与动作 |
|---|---|
| 剧情需要角色换成另一套衣服，但镜内无换装动作 | 不算合理换装；要么补换装镜，要么绑定服装变体并在切点完成 |

- 机检 WAN30-05 零错误：包内无「只作比对／不作视频参考」否定句，参考块不出现「资产卡为四视图」。

| 情形 | 判断与动作 |
|---|---|
| 包内写「四视图只作内部存档」 | 合法——说的是四视图不进视频，不是说塑像图不进 |

### 历史措施（仅用于旧版参考模式复盘）

1. **旧版曾要求视频参考与身份板分开出图。**

2. **给视频参考定脸占比下限**：脸部（下巴到发际）高度 ≥ 画面高度的 **1/4**（1080 图约 ≥270px）；低于此值的全身像只能当存档，不能当参考。
3. **参考图的光向与成片同源**：剧照用该场景的主光方向拍，避免模型在生成时二次改光。
4. **不要用「只作身份比对、不作参考帧」的声明去补救**（见 [WAN30-05](#wan30-05)）——那只是把问题标注出来，模型该看到的还是那张小脸。

### 已观察案例：2026-10-29 Wan3.0 泰语谈判电话段整段字幕
