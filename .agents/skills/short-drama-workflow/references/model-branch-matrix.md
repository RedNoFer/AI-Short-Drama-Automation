# 生成模型分支矩阵（Seedance 2.5 / Wan3.0 / MiniMax H3）

> 本文件只定义**同一主线的模型 profile**，不是三套工作流。总流程见 [最新工作流规范](workflow-spec.md)；阶段细节以各 reference 与适配器为准。

## 1. 分支选择与边界

| 项 | 规则 |
|---|---|
| 缺省处理 | 阶段 0 必须登记唯一轨。用户未指定模型时，才可采用 `policy.json` 的 Seedance 项目默认，并明确写入输入单；运行时校验器不做隐式回退 |
| 明确指定 | 用户明确指定的轨优先于任何项目默认或示例值，逐级派单必须原样传递 |
| 登记位置 | `内部/00-项目输入单.md` 的「生成轨」；一个项目只能一个有效值 |
| 切换时点 | 阶段 0 登记；阶段 3 片段形态、阶段 3.5 A 级镜头、阶段 4 编译器、阶段 5 校验器按轨切换 |
| 禁止 | 同一片段混写 Seedance 四段、Wan 四段、H3 base/Ref2VA；用错轨的校验器给通过结论 |
| Seedance 2.0 | **独立路由族，不是本主线的 30 秒多镜分支**：S02 完整剧本精细逐镜、S07 15 秒短片段、S13 角度运镜。若要作为完整分支，另建 `seedance20` 适配器＋校验器，明确片段单位/字符/参考/包结构；不套用 2.5 的 S18 四段与字符档 |

**用户说法 → 实际路由**

| 用户说法/需求 | 走哪条 | 说明 |
|---|---|---|
| 用户明确 Seedance 2.5，或阶段 0 已登记 Seedance 2.5 | `seedance25` profile | 小墨 6.3＋S18 四段＋Seedance 分档字符 |
| 明确 Wan3.0、2–30 秒、@Image 多模态 | `wan30` profile | Wan 四段＋0.5 秒＋WAN30 审计 |
| 明确 MiniMax H3 / 海螺 H3 / Ref2VA | `h3` profile | base/Ref2VA；app 30 秒默认，official 4–15 秒 |
| Seedance 2.0 完整剧本精细逐镜 | S02 路由 | 不自动并入 30 秒精简制作包；要并入先建 `seedance20` |
| Seedance 2.0 一句想法/15 秒短片段 | S07 路由 | 单条成品提示词，不是多镜 30 秒包 |
| 只要运镜/角度命令 | S13 路由 | 补充镜头语言，不单独承担全流程 |

## 2. 三轨对照

| 维度 | Seedance 2.5 | Wan3.0 | MiniMax H3 |
|---|---|---|---|
| 默认片段 | 固定 30 秒 | 30 秒默认；允许 2–30 秒弹性/智能时长 | 30 秒应用片段默认；官方单条 4–15 秒 |
| 镜头/硬切 | 6–11 镜 / 5–10 切 | 6–11 镜 / 5–10 切为默认；按项目策略可调 | 0–6 切；FL2VA 默认单镜；不套 6–11/5–10 |
| 时间粒度 | 整数秒 | 0.5 秒 | 毫秒切点 |
| 提示词字符 | 分档 2000 / 3000（默认）/ 4500 | 仅硬上限 18000 字符；无字数下限、目标带或单拍字数配额；逐镜清晰完整、禁止注水 | 硬顶 6000；低于 1200 提醒过简；官方词数口径优先 |
| 参考语法 | 单 MD 不预写 `@ImageN`；用资产代码/资产区 | 包内零编号：只写 `代码＝职责`，正文用姓名；≤10 图＋≤5 视频＋≤5 音频；视频参考只用单人全身塑像图 | `<Subject N>/<Picture N>/<Video N>/<Audio N>`；编号按角色→场景→道具连续；未上传图不得预写 `<Picture N>` |
| 正文结构 | S18 四段：`【参考】【公共总规范】【时间轴】【收尾】` | Wan 四段：`【参考】【公共总规范】【时间轴】【收尾】`；三锚、镜头前置；动作与表演按冻结镜头职责写清，不设动作数量配额 | base 三字段或 Ref2VA 六段式；不写四段结构/「硬切，」时间行 |
| 主要校验 | `validate_compact_package.py --model seedance25 [--tier ...]` | `--model wan30` ＋ `audit_wan30_antipatterns.py` | `--model h3`；`audit_h3_prompt.py` 仅按 official 4–15 秒单条体检，app 30 秒以包校验器为准；`--tier` 不适用 |
| 评审硬规附录 | S18/小墨 6.3/Seedance 反例 | WAN30-01/02：参考图类型、镜头前置、静物/空镜、并肩词、不看镜头、对话单拍、道具时序、文字规避、冻结场景实有光源、人物分身；风险提醒按[处置契约](prompt-review.md#wan风险提醒处置)验收 | 官方字段顺序、毫秒切点递增、`[Shot N]` 连续、`(S1)` 说话人、`<d>[语言]`、标签一致/无悬空、soundscape/music 句数、资产→标签覆盖 |

## 3. 当前最容易出错的四处

1. **H3 30 秒 vs 15 秒**：4–15 秒是模型单条输出上限，不是制作包片段默认值。默认 `app` 模式走 30 秒；只有应用只接受单条输出才用 `--h3-segments official`。
2. **H3 切数**：0–6 切，不套 Seedance/Wan 的 5–10 切。阶段 3 的 6–11/5–10 是 Seedance/Wan 默认，不是 H3 默认。
3. **Wan 弹性时长**：Wan 允许 2–30 秒，但阶段 3 的 30 秒/6–11/5–10 只是默认，不是所有 Wan 项目的硬约束；缩到 2–30 秒时仍须保住动作因果与出口。
4. **参考语法**：各轨制作包一律不预写 `@ImageN`/`@图片N`；绑定代码和参考职责按[资产引用规范](asset-reference-binding.md)。应用提交后的真实槽位编号不回填包内。H3 的 `<Subject>/<Picture>` 按该轨素材映射规则执行；未上传图不得预写 `<Picture N>`。

## 4. 什么拆、什么不拆

**只拆分支层：**

- 阶段 3 的片段形态：时长、镜头/硬切带、时间粒度；
- 阶段 3.5 的 A 级镜头长度/拍点制与分支上限；
- 阶段 4 的编译器与参考语法；
- 阶段 5 的字符档、校验器、专项审计；
- 阶段 4 评审的**分支硬规附录**。

**不拆，保持一套：**

- 阶段 0–2 的输入、剧情、剧本、资产身份、服装/道具/场景 SSOT；
- 阶段 3 的小墨 6.3 视感、逐镜语法、连续性合同、站位/空间；
- 六视角评审方法与整改流程；
- 精简制作包骨架与导入字段。

拆成三套完整工作流会造成三份剧情/资产/分镜规范漂移；正确做法是「一条主线＋一个 profile 矩阵＋每轨一个编译器/校验器」。

## 5. 阶段 4 的编译纪律

1. 先读 `00-项目输入单` 的生成轨与片段单位；
2. 只打开该轨的编译器/规范，不把另外两轨模板放在同一工作区参考；
3. 同一片段只出现一种正文结构；
4. 编译后立刻用该轨校验器；`--model` 必须与登记轨一致；
5. 评审用「六视角＋该轨硬规附录」，不把三轨硬规混成一张清单；
6. 交付说明写明：轨、片段单位、字符档、校验命令、未覆盖项。

**字符目标只从登记轨的 profile 读取。** Seedance 2.5 的 2000/3000/4500 档只适用于 Seedance；Wan3.0 仅设 18000 字符硬上限，无字数下限或目标带；H3 使用自己的长度口径。一个分支的数字不能作为其他分支的默认值或压缩目标。
