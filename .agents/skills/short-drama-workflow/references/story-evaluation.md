# 剧情质量评估与写作约束

本规范从小说拆解开始使用，不等全剧剧本写完才审。每处理一个稳定章节批次、每形成一集剧本、每划定一组片段，都先按对应条款起草，再在交接到下一阶段前核对。评价依据是小说事实、用户风格、改编决定和可拍剧本；内部记录「通过 / 需修改 / 因输入缺失待定」及具体证据。需修改项在本阶段解决，不把缺陷交给视频提示词补救。

## 章节与全剧结构：事件、人物和集数

写事件表时同步记录原文章节、事件的触发—选择—结果、人物目标与知情、情绪变化、道具/伏笔状态、影视化方式，以及保留、合并、删改的理由。评价时逐项核对：

- **覆盖与忠实**：主线因果、关键关系、反转、名场面和必要伏笔有去向；新增内容不与原文事实或用户指定改编方向冲突。删改要说明对后续情节的影响。
- **因果与人物**：角色每次重要选择有已建立的动机、信息和阻碍；结果改变局面，下一场能承接，不能让角色为推动剧情突然知道或忘记事情。
- **冲突与节奏**：每集有可见目标、阻碍、升级或转折及有效结尾钩子；连续重复的信息或无变化的场景应合并或改写。集数与总时长由剧情和表演估时推导。
- **可拍性**：抽象心理、背景叙述和时间跳跃已有可见行动、对白、反应或明确的叙事手段；尚无可拍方案的事件不得直接进入片段规划。

上述任何关键项缺失，先改事件表、人物状态账或分集规划；不要靠增加镜头或形容词掩盖。

## 逐集剧本：场景和表演

写每场时先明确入场状态、人物当下目标、阻碍、行动/对白、对手反应、局面变化与出口状态，再写台词。检查原句台词的使用和说话人、知情边界、情绪触发—过程—回应、动作的受力与结果。按自然发声、停顿、反应和行动估时；对白与动作可并行时才重叠计算。每场若删掉后不损失新信息、人物变化或因果结果，应重新定位职责或合并。剧本未能在合理时长内演完时，调整场次或集界，不压缩关键表演。

## 片段规划：剧情交接

切分每条视频前，从已通过的场景确定入口事实、必须完成的剧情/表演、出口事实及下一条入口。30 秒片段要有可见变化，主要对白、反应、武打因果与 6–11 个有职责的镜头在时间内成立；5–10 次硬切不能取代剧情推进。片段之间逐对核对人物知情、站位、伤情、道具持手、空间和声音。若一条过满或只有空泛切镜，先重排节拍与片段边界，再交分镜。**H3 轨**片段时长沿用应用单位（默认 30 秒），不额外拆条；每条仍要各自成立并留出承接。片段切分时同时标出每条对应的 H3 模式（T2VA/I2VA/FL2VA/L2VA/Ref2VA）与可用参考素材，并登记资产→`<Subject N>` 映射。

## 按体裁路线评估

本项目的评估基准由 [剧本体裁路线与评估基准](script-route-and-rubric.md) 确定：**通用层恒定生效，路线层随阶段 0 选定的路线追加**。

- 通用层（本文件全部条款）：台词逐字与说话人、人物知情边界与因果、每集目标/阻碍/升级/反转/钩子、可拍性、人物/服装/道具/空间连续性。
- 路线层：R-AI 的体量与画面粒度与爽点密度（E26-A）；R-SERIES 的钩子强度 L1–L5、三尺度人物弧、配角独立视角集、余韵与反俗套（E26-B）；R-MICRO 的六层人物档案、镜像对立、不可逆代价、场景必须改变什么、结束在沉默中、反俗套（E26-C）。
- 每份评估记录首行写明本次基准（路线 + 路线层条目编号），交接与评审沿用同一基准；半途换路线须重评已产出部分。
- 路线层不豁免通用层：E26-A「忠于感觉不忠于过程」只在故事层生效，不得放宽台词逐字与连续性要求。

## 执行与复核

剧情评价执行在三个交接点：**事件表/分集规划→剧本、逐集剧本→片段规划、片段规划→小墨逐镜**。每次记录评价对象 ID、对应原文章节/事件、通过项、缺陷及修改后的版本。全剧完成时再核对原文覆盖、角色弧线、伏笔回收、集间因果和总节奏；这个总复核用于发现跨集问题，不替代写作时的逐阶段评价。剧情质量属于 agent 的语义判断；格式脚本不能证明动机、戏剧张力或表演可信。
