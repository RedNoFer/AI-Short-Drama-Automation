# Seedance 2.5 通用提示词生成适配器 v1.0

## 1. 适用边界

本适配器位于“小墨 Skill 6.3 分镜脚本”和“Seedance 2.5 生成请求”之间。

它不重新设计导演分镜，不替换人物身份、场景事实、动作因果或用户确认的风格；只做四件事：

1. 把 6.3 的多字段镜头卡压缩成模型容易读取的自然语言；
2. 把连续的微镜头合并成少量叙事时间段；
3. 把全局不变信息与镜头局部变化分层；
4. 把内部编号、导演规则和冗余形容词转换为供应商可执行的信息。

默认目标是 **Seedance 2.5 标准 2000 字模式**：建议使用 1200–1800 个中文字符，硬上限为 2000 个中文字符，超过 2000 必须压缩或拆条。这里的字符预算只计算最终 `content.text` 提示词正文，不计算 API JSON、上传素材内容或文件名。

官方 API 文档把中文 500 字、英文 1000 词写成通用提示词建议值，而不是按秒变化的硬上限。用户明确允许更详细的提示词时，使用本适配器的 2000 字模式；只有接口或工作流明确要求短文本时，才切换为可选的 `compact_500` 模式。`duration` 单独设置，Seedance 2.5 当前生成范围为 4–30 秒。若用户明确使用火山剧创的分镜编辑器，可使用其产品侧长度，但本适配器仍不得超过 2000 字。

## 2. 输入契约

从 6.3 镜头序列中读取：

- 场景名、空间事实、时间和天气；
- 角色身份、外观、服装、道具和当前站位；
- 每个镜头的画面动作、动作结果、景别、主要运镜；
- 有叙事作用的光源、色调变化和景深变化；
- 台词、人声、环境音、动作音和音桥；
- 镜头之间的视线、轴线、起始姿态和结束姿态；
- 用户已经确认的不可变项和允许修改项。

不要把 6.3 的内部统计直接当作视频提示词：

- `S1/S2/S3/S4/O1/O2/X` 先展开为空间自然语言；
- 180°轴线、30°规则、机位配比、固定镜头比例等留在内部检查；
- 精确色值、胶片型号、颗粒、halation、HDR 等只有在影响结果时才保留；
- 不把 `@p1/@p2` 当作供应商引用，必须映射到真实上传素材顺序。

## 3. 生成参数与提示词正文分离

API 参数不写进长提示词正文，单独生成：

```json
{
  "duration": 30,
  "ratio": "9:16",
  "resolution": "1080p",
  "generate_audio": true
}
```

按任务类型补充：

- 纯文生视频：只传文本；
- 参考生视频：上传参考图/视频/音频，文本中说明每个素材的用途；
- 首帧/首尾帧：按接口要求使用 `first_frame` / `last_frame`，不要把首帧说明伪装成普通参考图；
- 编辑/延长：保留源视频的角色、画幅和时间关系，按接口要求处理 `ratio` 与 `duration`。

## 4. 公共总规范与镜头时间轴

最终提示词由“公共总规范 + 参考素材映射 + 时间轴镜头段落 + 收尾承接”组成。公共内容只写一次，不能复制到每个镜头。

### 4.1 公共总规范：只写一次

公共总规范集中放整条视频或当前片段不变的信息：

```text
公共总规范：30秒，9:16竖屏，有声，电影级写实；冷青灰主色，钠灯暖橙为主光；保持人物脸型、服装、道具、空间关系和轴线连续；保留环境声、动作音和对白，不要背景音乐，不要字幕。
```

规则：

- 公共总规范必须出现在时间轴之前；
- 公共总规范默认覆盖本条提示词的全部时间轴；需要稳定执行的事实使用“全程、始终、保持”等明确范围词；
- 镜头段落中的“局部变化”只覆盖对应时间段，不会取消其他公共规则，除非明确写出“从本段起改为……”；
- 同一事实只能在公共总规范出现一次；
- 镜头段落不得重复完整角色卡、场景卡、风格、色调或声音政策；
- 镜头只有发生局部变化时，才写“局部变化：……”；
- “电影感、写实、高清、质感高级”等同义词只保留一个；
- 同一条视频包含多个场景时，公共规范只写跨场景不变的事实；场景特有的光源、色温和环境声写在发生切换的时间段；
- 如果某段没有声音变化，不重复写“有环境音”。

### 4.2 参考素材映射：一次映射，后续只用别名

```text
参考：@Image 1=雨夜巷道；@Image 2=女主；@Image 3=反派；@Image 4=钥匙。
```

映射必须包含“素材编号 + 用途”，不重复粘贴完整人物或场景描述。若用户没有提供参考素材，删除该层，不虚构素材编号。

### 4.3 时间轴镜头段落：每段只写变化

每个时间段使用以下顺序：

```text
时间：主体 + 动作；触发原因 → 可见结果；主要运镜；本段对白/旁白/表演；必要的局部声音和光影变化。
```

示例：

```text
4-9秒：女主冲到铁门前掏出钥匙；反派逼近 → 她慌乱加速，钥匙掉落；手持广角跟拍；女主急促喘息，脚步声增强。
```

每段只保留一个主要镜头意图和一个主要运镜。复合运镜只有在两个动作必须同时完成时保留。公共总规范已经说明的内容不得在这里重复，但本段发生的对白、旁白、心理独白、可见表演、动作音和局部光影必须写在本段。

### 4.4 镜头内动态内容：不能被公共规范替代

公共总规范只能承载稳定事实，不能承载镜头内发生的事件。只要 6.3 分镜中出现，以下内容必须保留在对应时间段：

- **对白**：写明说话人和原台词，必要时写声音状态，例如“女主低声说：‘别逼我。’”；
- **旁白/心理独白**：写明“角色名画外音/旁白”，保留文字内容和出现时间；
- **非声音心理**：如果原文只是人物内心想法、没有设定为可听见的声音，改写为可见的眼神、呼吸、停顿、手部动作或走位，不把抽象心理直接当作画面事实；
- **表演**：保留本镜头的具体动作、微表情、视线、呼吸和身体反应；
- **局部声音**：保留本镜头新增或变化的环境声、动作音、人声和音桥；
- **局部视觉变化**：保留本镜头新增的光源、色温、焦点、景深或色彩反差。

公共规范可以说“全程保持角色身份和服装一致”，但不能代替“本镜头女主咬住嘴唇、停顿半秒后说出这句台词”。

## 5. 时间轴压缩规则

### 5.1 先按叙事节拍合并，不按 6.3 镜头编号机械复制

相邻镜头满足以下条件时合并：

- 场景和空间关系没有变化；
- 主体没有变化；
- 动作仍属于同一个因果链；
- 运镜只是在同一动作中的轻微变化。

不能合并的情况：

- 新角色进入或离开；
- 发生关键动作结果；
- 场景、时间或空间轴线改变；
- 台词对象或情绪关系发生转折；
- 必须依靠硬切才能理解的视觉信息。

### 5.2 默认时间段数量

这是压缩建议，不是模型硬限制：

- 4–10 秒：1–3 个时间段；
- 11–20 秒：3–5 个时间段；
- 21–30 秒：4–6 个时间段。

30 秒内不为了“覆盖每个原始镜头”而强行增加时间段。一个时间段可以包含动作内部的自然切换，但必须只有一个叙事重点。

### 5.3 时间连续性

时间段必须首尾相接：

```text
0-4秒 → 4-9秒 → 9-14秒 → 14-20秒 → 20-26秒 → 26-30秒
```

禁止出现空档、重叠或没有结果的时间段。若一个动作无法在剩余时间内完成，减少镜头数量或拆成下一条视频，不用压缩成不合物理的快动作。

## 6. 字数预算与压缩优先级

### 6.1 标准 2000 字预算

`standard_2000` 模式默认目标为 1200–1800 个中文字符，硬上限为 2000 个中文字符。超过 2000 时，先执行本节压缩规则；压缩后仍超过 2000，则拆成下一条视频。

推荐预算分配：

- 生成参数和任务目标：50–120 字；
- 参考映射：50–180 字；
- 公共总规范：180–500 字；
- 时间轴：每段 80–180 字；
- 收尾承接：50–150 字。

时间轴段落数量可以根据剧情细节增加，但不能为了覆盖原始镜头而机械增加。公共总规范越完整，镜头段落越应该只写局部动作、结果和变化。

### 6.2 可选紧凑模式

只有用户或目标接口明确要求短文本时才使用 `compact_500`：目标 350–500 个中文字符，公共总规范仍然只写一次。不得因为使用紧凑模式而删除 P0 动作因果、关键台词、关键道具或承接状态。

如果超过预算，按照以下顺序删除：

1. 同义形容词和重复画质词；
2. 没有改变结果的焦段、胶片、颗粒和色值；
3. 重复出现的角色外观、场景环境和全局色调；
4. 只表示情绪、没有可见动作的心理词；
5. 没有新信息的反应镜头和过渡镜头；
6. 次要环境装饰。

不得删除：

- 主体身份和空间关系；
- 触发原因与动作结果；
- 关键道具和关键台词；
- 造成连续性变化的光线、站位和声音；
- 下一段必须承接的结束姿态。

### 6.3 信息优先级

```text
P0：谁、在哪里、做什么、为什么、结果是什么
P1：主要运镜、景别、关键光源、对白和关键音效
P2：主色、整体质感、景深和节奏
P3：胶片型号、十六进制颜色、颗粒、泛化质量词、内部导演统计
```

超出 2000 字预算时从 P3 向上删除，不从 P0 开始删。公共总规范中的重复内容优先合并，不把同一信息分散到多个镜头后再逐段删除。

## 7. 声音和风格的写法

不要把声音完全放到提示词之外，也不要在每个镜头重复完整音频规则。声音总政策统一放进公共总规范，镜头只写当前发生的声音变化。

使用以下方式：

- 全局层说明声音总政策，例如“保留环境声和动作音，不要 BGM”；
- 时间轴只写发生变化的音效、人声、对白和旁白；
- 长台词只保留对剧情有作用的句子，不补写语气解释；
- 台词和旁白必须放在实际发生的时间段，不能因为有公共声音规范而移走；
- “心理独白”只有在用户要求可听见时才写成画外音/旁白；否则转换为可见表演；
- 不把“紧张、悲伤、压迫感”当作声音，改写成可听见的喘息、停顿、门响、脚步等；
- 负向限制只保留高价值项，例如“不要字幕、不要背景音乐”，不输出冗长禁词清单。

## 8. 标准最终输出格式

适配器默认输出以下五段。它们可以使用短标签，不输出 Markdown 表格和长篇解释。

```text
【参数】时长Xs，画幅，是否有声，任务目标。
【参考】@Image 1=用途；@Image 2=用途；……
【公共总规范】整体风格、色调、主光源、角色与空间锁定、声音总政策、全局禁项。
【时间轴】0-X秒：主体动作；触发→结果；主要运镜；对白/旁白/表演；必要的局部光音。X-Y秒：……
【收尾】最后姿态、关键道具位置、环境结果、下一条承接方式。
```

`【参数】`和 API JSON 分开保存；若平台已单独设置时长、比例和声音，提示词中可以只保留“30秒叙事、9:16竖屏、有声”等必要提醒。

## 9. 30 秒标准示例

以下示例展示“公共总规范只出现一次，镜头段落只写局部变化”的最终提示词结构：

```text
生成一段30秒、9:16竖屏、有声、电影级写实短剧视频。@Image 1为雨夜巷道，@Image 2为女主，@Image 3为反派，@Image 4为钥匙。保持人物脸型、服装、道具和空间连续，冷青灰主色，钠灯暖橙为唯一主光；保留雨声、脚步、喘息和动作音，不要背景音乐，不要字幕。

0-4秒：女主在巷口奔跑，回头发现反派追来；广角全景缓慢推进，雨水溅起。
4-9秒：女主冲到铁门前掏出钥匙，反派逼近；手持广角跟拍，脚步和喘息增强。
9-14秒：钥匙掉落，反派抓住女主肩膀；中近景焦点从钥匙转到女主眼睛，钥匙落地声响起。
14-20秒：女主转身挣脱，反派撞上铁门；低机位侧45度跟随，门锁震动。
20-26秒：女主开门冲入，反派的手被门挡住，女主回头说“别逼我”；镜头横移，保留铁门撞击声。
26-30秒：铁门关闭，反派停在门外，远处警笛接近；镜头拉远并停在钥匙特写。结尾保持门外反派与门内女主的空间关系，供下一条承接。
```

## 10. 适配器执行流程

1. 读取 6.3 分镜，建立角色、场景、道具和不可变项清单；
2. 将 `@p1/@p2` 与实际上传素材顺序建立映射；
3. 把完整场景和角色描述提取到参考层，只保留别名；
4. 把公共风格、角色锁定、场景基线、声音政策和全局禁项合并为一段公共总规范；
5. 按动作因果和叙事转折合并镜头，生成连续时间轴；
6. 每段写“主体动作 → 触发 → 可见结果 → 主要运镜 → 对白/旁白/表演 → 必要的局部声音和视觉变化”；
7. 删除公共总规范已经覆盖的重复字段、空泛形容词、无结果镜头和无效禁词；
8. 检查 2000 字硬上限、时间连续性、人物身份、道具位置、台词和尾帧承接；
9. 只输出最终提示词和必要的生成参数，不输出内部压缩过程。

## 11. 输出前质量检查

适配器内部检查，不在最终提示词中展示：

- 时间轴从 0 开始，连续覆盖到目标时长；
- 每个时间段至少有一个可见动作和一个结果；
- 没有重复粘贴同一人物、场景和色调描述；
- 每个关键镜头只有一个主运镜意图；
- 角色、服装、道具、空间和光源方向没有互相矛盾；
- 每个含台词的原始镜头都保留说话人、台词内容和必要的声音状态；
- 每个含旁白或心理独白的原始镜头都明确标记为画外音/旁白，或已经转换为可见表演；
- 每个含情绪的镜头都保留至少一个具体可见表演动作；
- 台词确实属于当前说话人，且自然语速能够完成；
- 音效写成可听见的事实，不用抽象情绪词代替；
- 参考别名与上传顺序一致；
- 公共总规范只出现一次，镜头段落没有重复的公共风格、角色、场景和声音政策；
- `standard_2000` 模式提示词正文不超过 2000 个中文字符；
- `compact_500` 模式提示词正文不超过 500 个中文字符；
- 若无法在 2000 字内保留完整因果链，拆分视频条目，不继续堆字。

## 12. 禁止事项

- 不把小墨 6.3 的每个镜头逐字复制到最终提示词；
- 不在每个时间段重复写完整角色卡和场景卡；
- 不把所有焦段、机位角度和运镜名词并列堆叠；
- 不用 `S1/S2/O1` 等内部代码替代自然语言；
- 不把 `@p1/@p2` 直接当成平台已经绑定的参考素材；
- 不把公共总规范复制进每一个镜头段落；
- 不把对白、旁白、心理独白、表演和本段音效误归入公共总规范；
- 不为了满足镜头数量而增加没有新信息的切镜；
- 不用“电影感、大片质感、震撼、绝美”等形容词代替动作和结果；
- 不把 `--no` 后缀扩展成几十项通用禁词；
- 不把内部质量检查、导演理由和压缩说明交给视频模型。
