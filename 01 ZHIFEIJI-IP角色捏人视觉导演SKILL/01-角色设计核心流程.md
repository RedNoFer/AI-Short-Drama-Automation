# 角色设计核心流程

## 输入图职责

- 图1：当前编辑底稿或角色身份。
- 图2：局部特征、发型、耳朵、光影或材质参考。
- 图3：构图、动作、服装或海报参考。

任何多图任务先声明职责，再输出提示词。

## 素体轮廓

```text
去除图1角色的所有角色化元素，包括头发、眉毛、眼睛、鼻子、嘴巴、妆容、饰品、头饰及服装细节；只保留最基础的头部、脸部、耳朵、颈部、肩部和身体外轮廓。不要有头发，不要有五官。输出干净、纤细、闭合的正面素体轮廓线稿，白色背景。严格保持图1人物姿势、头肩比例、正面视角和构图范围不变；头部平直正对镜头，不要歪头。
```

## 脸型修改

```text
基于图1素体轮廓，只将脸部外轮廓修改为{脸型}：{脸型说明}。严格保持头部位置、耳朵位置、颈肩比例、正面视角和构图不变。不要生成头发、眉毛、眼睛、鼻子、嘴巴、妆容、饰品或服装细节。保持干净轮廓线稿。
```

脸型菜单：圆脸、鹅蛋脸、心形脸、方圆脸、长脸、倒三角脸。

## 完整二维角色

```text
基于图1的素体轮廓，提取图2的角色特征，基于图1进行角色设计，手绘插画风格。严格保持图1人物轮廓、头肩比例、姿势和构图；完整生成角色的眉毛、眼睛、鼻子和嘴巴。头部平直正对镜头，不要歪头。
```

## 清空五官编辑底稿

仅在需要集中重新设计全部五官时使用：

```text
将当前插画图中的眉毛、眼睛、鼻子和嘴巴去除，面部不要有任何五官；保持脸型、发型、耳朵、颈肩、服装、姿势、构图、色彩和插画风格完全不变，形成后续五官编辑底稿。
```

## 眼睛替换

```text
将图1角色的眼睛替换为图2的眼睛设计，只提取图2的眼型、瞳孔、虹膜和眼神特征。严格保持图1的脸型、眉毛、鼻子、嘴巴、发型、肤色、服装、姿势、构图和手绘插画风格不变。
```

## 嘴巴替换

```text
将图2的嘴巴设计替换到图1角色的嘴巴位置，只提取图2的唇形、厚薄、开合状态和细节。严格保持图1角色的脸型、眼睛、眉毛、鼻子、发型、肤色、表情基调、姿势、构图和插画风格不变。
```

## 头部特征迁移

```text
提取图2的发型、肤色和耳朵特征替换到图1角色身上，去除图1角色原有发型，基于图1进行生成。严格贴合图1角色轮廓，保持图1脸型、五官分布、头肩比例、姿势、构图和插画风格不变。
```

## 定稿要求

三维转换前必须完成五官、发型、耳朵、肤色、服装和构图，并清理纸纹、画布纹、错误线条和多余笔刷噪声。
