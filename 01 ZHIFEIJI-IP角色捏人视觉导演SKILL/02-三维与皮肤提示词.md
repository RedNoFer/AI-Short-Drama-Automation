# Nano Banana Pro三维与皮肤提示词

## 第一轮：二维转三维

输入必须是完整二维定稿。

```text
图1转3d，c4d渲染风格，很丰富的质感，写实的毛发，人物适当3s材质（细腻的皮肤质感，细腻可见的毛细血管，皮肤层次感强，非常细微少量的透明汗毛，皮肤略有瑕疵），电影级光影效果，极具氛围感。保持图1构图一致性。基于图1的轮廓进行生成。皮克斯三维卡通CG风格作品。耳朵与皮肤颜色一样，白粉色皮肤。
```

验收：轮廓、构图、脸型、五官、发型、耳朵和服装必须继承；不能变成普通真人。

## 第二轮：SSS皮肤与脸部特写

输入必须是第一轮最佳三维结果。

```text
基于当前三维角色图进行修改。严格保持角色原有脸型、五官分布、瞳距、眼睛设计、鼻子、嘴形、发型、耳朵及身份特征不变。皮肤转为3S（SSS次表面散射）透光粉白色皮肤质感，脸部皮肤和身体局部微微透粉红色，耳廓、鼻尖、脸颊及面部边缘呈现自然的皮下透光。皮肤具备真实的层次变化、细密毛孔、少量毛细血管、极少量透明汗毛及轻微自然瑕疵。极近距离正面脸部特写镜头，头部平直正对镜头，电影级光影效果，摄影级美感构图设计。不要改变角色设计，不要塑料感、蜡像感或过度磨皮。
```

验收：毛孔随机、区域色差自然、耳鼻局部透光；拒绝纸纹、蜂窝纹、网格、塑料感和蜡像感。

## 参考光影重打光

```text
严格按照图1的人物身份、脸型、五官、发型、耳朵、服装、姿势、构图和全部元素，对图1进行重新打光。只参考图2的主光方向、光比、色温、阴影层次、轮廓光和环境氛围，不提取图2的人物或场景元素。明暗对比清晰，电影级光影效果；皮肤呈现通透粉嫩的3S（SSS次表面散射）质感，脸颊、鼻尖、耳廓和身体局部微微泛红。严格保持图1构图和角色特征不变。
```
